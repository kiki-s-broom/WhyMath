# 작업 지시서 (AI 실행용) — P3 Release 재판정 준비

통합 게이트 `G-p3-w3-release-merged`의 FAIL을 해소하는 작업 묶음이다. 작업 번호를 받은 AI는 공통 규칙과 해당 번호의 지시만 읽고 작업한다. 지시에 없는 값은 추정하지 않고 "미확인"으로 보고한다. 이 파일이 원본이며, 지시문 파일(`p3r/지시문/`)은 task-prompt-pack 스킬의 `build_prompts.py`로 여기서 생성한다.

## 공통 규칙과 보고 형식

작업 번호를 받으면 아래 규칙을 먼저 지키고, 그다음 해당 번호의 지시를 수행한다. 규칙과 지시가 충돌하면 규칙이 우선한다.

**공통 규칙**

1. **읽을 범위:** (생성 스크립트가 표준 문장으로 바꾼다)
2. **선행 작업 확인:** (생성 스크립트가 표준 문장으로 바꾼다)
3. **저장소와 브랜치:** 작업 환경의 저장소 위치가 비어 있으면 이 세션의 작업 폴더(kiki-s-broom/WhyMath)로 본다. 세션 환경이 작업 브랜치를 지정했으면 그 브랜치를 쓴다 — 산출물 저장 규칙의 브랜치 이름보다 우선한다.
4. **claim 먼저:** 대장·git 조회 다음의 첫 행위는 `python3 scripts/harness/backlog.py start <백로그 ID>`다. claim 전에 대상 코드를 열지 않는다. 대장 태스크가 없는 작업(X1·J1의 시작 전)은 이 규칙에서 빠진다.
5. **남이 잡은 작업:** `backlog.py claims list --verbose`에 남의 claim이 있으면 그 브랜치의 마지막 커밋과 열린 PR을 본다. 24시간 안에 활동이 있으면 착수하지 않고 보고하고 멈춘다. 72시간 넘게 활동이 없고 열린 PR도 없으면 근거를 적고 `unblock` 뒤 `start`로 인수한다. 그 사이면 사용자에게 묻는다.
6. **이미 끝난 작업:** 대상 백로그 태스크가 main에서 이미 done이면 아무것도 바꾸지 않는다. 보고.md에 "결과: 완료(이미 완료 — 증적 <PR>)"만 쓰고 끝낸다.
7. **판정 기준은 main 실측:** 보고와 판정 문서 상단에 `판정 기준: main <커밋 해시>`를 적는다. 미머지 브랜치를 근거로 조건을 닫지 않는다.
8. **모르는 값은 추정 금지:** 경로·태스크 상태·게이트 상태는 저장소에서 먼저 찾는다. 못 찾으면 "내가 찾은 방법으로는 0건"이라고 검색 범위를 밝히고 "미확인"으로 적는다.
9. **대장은 CLI로만:** 새 태스크는 `backlog.py add`, 정정은 `amend`·`gates amend`로 한다. 대장 YAML을 손으로 고치지 않는다. 백틱이 든 산문은 인용 heredoc(<<'EOF')으로 파일에 써서 넘기고, 쓴 뒤 대장을 다시 읽어 내용이 남았는지 확인한다.
10. **결정은 Kiki 몫:** decision 게이트를 `gates clear --as kiki`로 대신 닫지 않는다. 결정이 필요하면 선택지 2~4개, 선택지별 영향, 권고 1개를 채팅에 표로 보여 주고 멈춘다.
11. **Phase 3 범위:** 새 Entity, 대규모 DB 스키마 변경, 새 AI Agent, 새 Subject Adapter, 대규모 UI 변경은 하지 않는다. 필요해 보이면 Release Blocker 여부를 결정 요청으로 올린다. 대표 과정(미적분Ⅰ 미분 10개 개념) 밖의 콘텐츠는 채우지 않는다.
12. **수학·콘텐츠 규율:** LLM은 학습 상태를 바꾸지 않는다. LLM 호출은 라우터(`l3/router.py`) 경유와 Langfuse 추적이다. 정답·동치는 SymPy로만 검증한다. 승인된 문항 은행은 제자리 수정하지 않는다. 라벨만 바꿔 지표를 올리지 않는다.
13. **동결 자산:** 범위 명세(`data/corpus/phase3_scope_v1/scope_spec.yaml`), 오개념 코퍼스, 크로스링크 서명(검수:kiki)은 게이트 evidence에 Kiki 결정이 있을 때만 바꾸고, 그 결정을 PR 본문에 인용한다.
14. **보호는 주입으로 증명:** 새 가드·테스트·계측기는 막으려는 상태를 주입해 RED, 원본에서 GREEN을 확인한다. 주입 적용(mutated != original)과 원복 바이트 동일을 단언한다.
15. **판정은 exit code로:** 출력을 `-q`나 `| tail`로 잘라 판정하지 않는다. 백엔드 코드를 건드렸으면 전체 스위트를 돌리고, 못 돌렸으면 그렇다고 적는다. 측정 실패와 표본 0은 "측정 불가"로 적는다.
16. **푸시 전 CI 미러:** `python3 scripts/harness/ci_mirror.py run`이 exit 0일 때만 푸시한다. 3(미실행 검사)과 4(실행 중 트리 변경)는 통과가 아니다. 검증이 도는 동안 작업 트리를 바꾸지 않는다.
17. **완료는 PR과 대장:** 커밋이 있으면 PR을 연다. 백로그 태스크 완료는 `backlog.py done <ID> --artifact <PR> --artifact <머지 커밋> --no-verdict "판정 무관: <무엇>을 재판정 입력으로 넘긴다"`다(J1만 예외). 태스크가 done이 아닌 채 세션을 끝내면 `unblock`으로 claim을 놓는다.
18. **Kiki PC 실행 안내:** 명령 블록 앞에 6항목 브리핑(과제·목적·절차와 예상 시간·성공 기준과 실패 시 대처·실행 환경·창 구분)을 준다. Windows PowerShell, 작업 장소 `C:\Users\kiki\Desktop\__AI\WhyMath`, `git worktree add --detach`에서 실행, 자리표시자 0개, 쓰기 블록은 단일 `if … else`로 스스로 거부한다.
19. **채팅 형식:** 사용자에게 보내는 코드 펜스는 실행용이며 언어 태그를 붙인다. 해시·식별자는 인라인 백틱, 명령 결과는 요약 문장과 인용문으로 쓴다.
20. **헌법 래칫 보고:** 완료 보고의 "완료 기준 확인"에 `python scripts/constitution/audit_ratchet.py`의 종료 코드와 차단 건수를 넣는다.

## X1: 외부 선행 확인

PED-17 묶음은 이 묶음 밖에서 진행된다. 학습 화면 코드(`api/study.py`)를 함께 고치는 L1이 PED-17과 충돌하지 않도록, PED-17의 진행을 확인하는 관문만 이 묶음에 둔다.

### X1. PED-17 학습 화면 변경 완료 확인 (관문 ①)

- **목적:** L1(콘텐츠 열람 기록)은 PED-17 묶음과 같은 학습 화면 코드를 고친다. PED-17이 그 코드를 다 고친 뒤에 L1이 시작하게 한다. 이 작업은 확인만 한다.
- **선행 산출물:** 이 묶음 안에는 없다. 외부 입력은 main의 `ped17/산출물/B6/보고.md`·`C1`·`C2`·`C3`의 `보고.md`와 커밋 로그다.
- **할 일:**
  1. 이 작업에는 백로그 태스크가 없다. claim 없이 읽기만 하고, 보고.md 한 파일만 커밋한다.
  2. `git fetch origin main` 뒤 판정 기준 해시를 적는다.
  3. `ped17/산출물/B6`·`C1`·`C2`·`C3`의 `보고.md`가 main에 있는지, 각 결과가 "완료"인지 읽는다.
  4. `git log origin/main --oneline -- src/backend/whymath_backend/api/study.py src/backend/whymath_backend/l4/content_supply.py`로 그 작업들이 main에 머지됐는지 확인한다.
  5. 참고값: 실 PG(PostgreSQL 16 + pgvector · `alembic upgrade head` · `WHYMATH_RUN_INTEGRATION=1`)를 띄울 수 있으면 `tests/backend/api/test_release_gate_a_chain.py`를 돌려 `GATE_A_CHAIN_VERDICT` 줄을 적는다. 못 띄우면 "미측정"이라고 적는다.
  6. 3과 4가 모두 충족이면 go, 아니면 no-go와 빠진 번호를 적는다.
- **산출물:** `p3r/산출물/X1/보고.md`(판정 포함).
- **완료 기준:** 네 보고.md의 존재·결과와 머지 커밋을 근거로 go 또는 no-go가 적혀 있다.
- **하지 말 것:** PED-17 작업을 대신 하지 않는다. 코드를 고치지 않는다. 근거가 하나라도 빠졌는데 go로 적지 않는다.
- **막히면:** PED-17 묶음의 번호 체계가 바뀌어 B6·C1~C3가 없으면, 학습 화면 응답을 고치는 PED-17 작업을 산출물 폴더와 대장에서 찾아 그 목록으로 판정하고 바꾼 근거를 적는다.
