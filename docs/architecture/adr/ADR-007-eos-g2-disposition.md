## 맥락

EOS 전환 선언(2026-08-30) §6·부록 B~E는 G2(10/25)를 **중등 2앵커**로 정의한다 — A3(중2 확률)·A4(중3 이차방정식) 각 60 CU, HIT 중앙값 ≤8분, 자동검증 ≥70%.

그러나 2026-09 감사(`docs/reviews/eos_anchor_asset_audit_2026-09.md`)와 2026-10-19 재감리가 다음을 실측했다.

| 사실 | 값 | 출처 |
|---|---|---|
| G1~G5의 `backlog/gates.yaml` 등재 | **0건** | 재감리 W-01 |
| A3 매칭 문항 | **0건** (`[9수04-05]`·`[9수04-06]`) | 앵커 자산 감사 |
| A4 문항 | 691건(승인 378건, 전부 결정형, LLM 저작 0) | 앵커 자산 감사 |
| 9/22 이후 입력 | 전부 Phase 3 대표 과정(`12미적Ⅰ` 02-01~02-10 = A6 부분집합) | 재감리 W-02 |
| A4 생산 기록(9/22 이후) | **0건** | 재감리 W-02 |
| HIT 유효 측정 | **0건** (카나리 15건은 재입력 세션) | 재감리 W-06 |
| 잔여 작업 시간 | ~260h (25h × 10.4주) | 재감리 |
| Phase 3 구현 마감 | 2026-11-14 | 계획서 |

즉 10/25 시점에 G2 원문 조건을 판정할 재료가 **존재하지 않는다**. A3는 문항이 없고, A4는 LLM 생산이 0건이며, HIT는 유효 표본이 0건이다. 그대로 두면 G2는 "미달"이 아니라 **판정 불능**이 되고, 12/31 G5의 F-Ⅰ(A3·A4 HIT >12분)·F-Ⅳ(6앵커 중 3개 미달)도 같은 이유로 판정 불가가 된다.

동시에 2026-09-22 이후 모든 생산 입력이 Phase 3 대표 과정으로 고정되어 **A6(고2 도함수의 활용 = `12미적Ⅰ` 02-01~02-10)만이 실제로 생산 가능한 앵커**다. A6는 Phase 3의 대표 과정이자 이미 입력이 들어오고 있는 유일한 축이다.

F-Ⅰ~F-Ⅴ 실패 정의는 2026-09-27 동결됐다 — 12월에 수정하지 않는다. 이 ADR은 **조건을 개정**할 뿐 실패 정의를 건드리지 않는다.

## 결정

**이 결정은 기준 완화다.** 원문 G2의 앵커·CU 조건을 실제 생산 가능한 축으로 낮추고, 판정 시점을 11/8로 미룬다. 완화 사실을 숨기지 않고 12/31 판정문에도 함께 기록한다.

1. **G2(10/25 → 11/8 재판정).** 앵커를 A3·A4에서 **A6**으로 교체한다. 개정 조건은 "**A6 LLM 저작 회차 1회 ≥30 CU 산출물이 저장소에 커밋됨(GenerationLog 포함) + HIT 측정 체계(OPS-90 하한 가드) 착지**"다. 10/25 시점은 **판정 불능(미등재·미측정)**으로 기록하고, 11/8에 재판정한다.
2. **G3(11/22).** "**A6 ≥30 CU + HIT 유효 표본 ≥15 + 자동검증 1차 통과율 산출됨**"으로 개정한다. A3·A4·A1·A2·A5의 "각 60 CU"는 **2027-01로 이월**한다.
3. **G4(12/13).** "**누적 ≥60 CU(두 번째 앵커 포함) + 자동검증 1차 통과율 ≥70% + 내부 테스트 계정 표본 ≥20(EOS-135) + P0 결함 0**"으로 개정한다. 학생 표본은 ARCH-66 ⑥(학생 참여 12/31 이후)에 따라 내부 테스트 계정으로 대체한다.
4. **G5(12/27 데이터 동결 → 12/31).** 조건은 **불변**이다. F-Ⅰ~F-Ⅴ는 선언 원문 그대로 판정하며, 12/31 판정문은 "**F-Ⅰ·F-Ⅳ 미달(A3·A4 미생산)**"을 명시적으로 기록한다. 개정된 G2~G4 기준 충족과 원 실패 정의 미달을 **둘 다** 적는다.
5. **등재.** `G-eos-g1`은 9/27 판정을 사후 등재한다(cleared, evidence = `schema/subject_adapter.py` 2026-09-27 Frozen(unexercised) + lint-imports 4 KEPT + `G-required-tier-caller-recheck` cleared). `G-eos-g2`~`G-eos-g5`는 pending, assignee=kiki로 등재한다. 등재 주체는 Kiki이고 트리거는 이 ADR이다.

## 채택하지 않은 대안

- **(b) 10/20~11/8에 A3·A4 LLM 생산을 2회차 돌리고 Phase 3을 그 뒤로 미루는 안.** A3는 매칭 문항이 0건이라 저작 전에 성취기준 매핑부터 새로 만들어야 하고, A4는 9/22 이후 입력이 전부 A6라 생산 파이프라인을 되돌려야 한다. 잔여 ~260h에서 Phase 3 구현 마감(11/14)을 넘긴다 — 일정이 아니라 **내용**이 성립하지 않는다.
- **(c) G2를 "판정 불능"으로만 기록하고 선언 §6을 다시 쓰는 안.** 선언 본문 수정은 12월 동결 원칙과 충돌하고, G3·G4의 CU 조건이 그대로 남아 같은 판정 불능이 11/22·12/13에 반복된다. 조건 개정을 ADR 한 장에 모으는 편이 추적 가능하다.

## 한계

- 이 ADR은 **기준을 낮춘다.** A3·A4의 60 CU 목표는 달성된 것이 아니라 2027-01로 미뤄진 것이다. 12/31 판정문과 2027-01-15 재확인에서 이 사실을 반복해 적는다.
- A6 ≥30 CU는 "생산 파이프라인이 한 회차 돈다"는 증명이지 "6앵커가 준비됐다"는 증명이 아니다. F-Ⅳ(6앵커 중 3개 미달)는 원문대로 미달로 남는다.
- HIT 유효 표본 ≥15와 자동검증 통과율은 OPS-90(하한 가드) 착지에 의존한다. OPS-90이 착지하지 않으면 G2·G3는 조건 자체를 판정할 수 없다.
- 내부 테스트 계정 표본 ≥20은 실제 학생 표본이 아니다. ARCH-66 ⑥이 학생 참여를 12/31 이후로 미룬 결과이며, 학생 대면 검증은 2027로 이월된다.

## 재검토 조건

- **2026-11-08:** G2 재판정. A6 30 CU 산출물 커밋과 OPS-90 착지 여부를 확인한다. **둘 중 하나라도 없으면 G2를 FAIL로 기록**하고 12/31을 Conditional Go 이하로 준비한다.
- **2026-11-22:** G3 판정. A6 ≥30 CU·HIT 유효 표본 ≥15·자동검증 1차 통과율 산출을 확인한다.
- **2026-12-13:** G4 판정. 누적 ≥60 CU(두 번째 앵커 포함)·자동검증 ≥70%·내부 테스트 계정 표본 ≥20·P0 결함 0을 확인한다.
- **2026-12-31:** G5 판정. 개정 기준 충족 여부와 원 F-Ⅰ·F-Ⅳ 미달을 함께 기록한다.
- **2027-01-15:** A3·A4 생산 재확인. 이월된 60 CU 조건의 착수 여부를 판정하고, 착수하지 않았으면 2027 계획에서 재배치한다.
