## 결정 (D1 = (a))

**이 결정은 기준 완화다.** 선언이 10월에 요구한 중등 기준선을 12월 안에 채울 시간이 없다는 사실을 인정하고, 측정 대상을 실제로 자산이 있는 앵커로 옮긴다. 완화라는 사실을 숨기지 않기 위해 이 단어를 첫 줄에 쓰고, **원문의 어느 조건이 삭제·이동·이월·유지됐는지 §조건 명세표에 전부 적는다.**

1. **G2(10/25 → 재판정 11/8)**: 앵커 A3·A4 → **A6(고2 도함수의 활용)**. 조건 = "A6 LLM 저작 회차 1회 ≥30 CU 산출물(GenerationLog 포함)이 저장소에 커밋됨 + HIT 측정 체계(OPS-90 하한 가드) 착지". 10/25 시점에는 **미측정**으로 기록하고(등재는 이 ADR로 완료되므로 '미등재'는 사유가 아니다) 11/8을 재판정일로 둔다.
2. **G3(11/22)**: "A6 ≥30 CU + HIT 중앙값 ≤8분(유효 표본 ≥15, G2에서 이동) + 자동검증 1차 통과율 산출됨 + 힌트 의미 누설 0 + 메타 누락 0". 원문의 '폭 확장(앵커 전부 60 CU+)' 목적은 **이 개정으로 소실된다** — G3는 '계측 가능성 확인'으로 성격이 바뀐다.
3. **G4(12/13)**: "누적 ≥60 CU(A6 30 + **두 번째 앵커 A4** 30 — A4는 결정론 691건·승인 378건이 있어 LLM 재저작 시드가 존재한다) + 자동검증 1차 통과율 ≥70%(G2에서 이동) + A6 깊이앵커 무개입 루프 3연속(원문 유지 — Phase 3 Gate A 측정과 동일 회차로 판정) + 내부 테스트 계정 표본 ≥20(원문 G4·EOS-135 기확정, 신규 결정 아님) + P0 결함 0".
4. **G5(12/27→12/31)**: **원문 불변.** 제목·조건은 선언 원문(2027 범위 결정 포함, 판정 3택 Go / Conditional / No-Go)을 그대로 쓴다. F-Ⅰ~Ⅴ도 원문 그대로 판정한다 — 12/31 판정문에 "F-Ⅰ·F-Ⅳ 미달(A3 미생산)"이 기록된다. 완화는 G2~G4 진입 조건에만 적용된다.
5. **등재 방식**: 5건 모두 `backlog.py gates add`(G1은 `--no-inputs` 사후 등재 후 `gates clear --evidence <판정 기준 커밋·PR>`), 손편집 금지. 입력 간선: G2·G3 → `OPS-90`, G4 → `EOS-155`, G5 → `ARCH-67`. 등재 책임자 = Kiki, 트리거 = 이 ADR.

## 대안과 기각 이유

- **(b) 10/20~11/8 A3·A4 LLM 저작 회차 2회(각 60 CU)를 Phase 3보다 우선**: 기각. A3는 시드부터 만들어야 하고(선언 추정 약 1주), 120 CU 검수 HIT를 1인이 11/8까지 낼 수 없다. Phase 3 사슬(11/14)도 함께 놓친다.
- **(c) G2를 판정 불능으로 기록하고 선언 §6 전체 재작성**: 기각. 12월 "실패정의 수정 금지" 취지와 충돌하고 재작성 자체가 1주를 먹는다.

## 결과

- WP-C(A6 30 CU)·WP-F(A4 30 CU + 자동검증·비용)·WP-G(G5 증거)의 기준이 이 ADR이다.
- 12/31 판정문은 "G2~G4 개정 기준 충족 여부"와 "원문 F-Ⅰ·F-Ⅳ 미달"을 **둘 다** 적는다. Go가 나와도 "중등 기준선 미검증"이 2027-01 첫 안건이다.
- 2027-01-15 재확인: A3 생산 착수 여부, G3 폭 확장 조건 복원 여부.
