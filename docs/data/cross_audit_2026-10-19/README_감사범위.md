## 판정 기준 (쉬운 설명)
- **고아 오개념**: 오개념의 `개념ID`가 개념 시트 846개에 없는 것. → 0건. 대신 (a) 성취기준코드가 성취기준 목록에 없는 것(MEDIUM), (b) 매핑점수 0.5 미만 준고아(LOW)를 보고.
- **순환**: 선수관계가 A→B→…→A로 되돌아오는 것. Tarjan SCC 알고리즘으로 검사(인위 순환 주입으로 탐지기 동작 확인 완료). 개념·원자 그래프 모두 0건. 서술형(이름 기반) 엣지 1,007건은 ID가 아니라 제외.

## 핵심 발견
1. **대학교 개념 409개 전부 오개념 0건** — 3번 LOW 409건이 정확히 대학 개념 집합. 오개념 DB가 초·중·고(파일3-노드 437)까지만 커버. 원자 쪽도 대학 원자 513개는 `연결성취기준`이 비어 있어 성취기준 조인 자체가 불가.
2. **docx 원자ID 표기 불일치 49건(패턴 24개)** — 미적분Ⅰ 원자 ID의 하이픈 문자가 xlsx와 다름(정규화하면 100% 존재). 실제 미존재 원자는 0건. 문서가 "88/119 조인"이라고 쓴 것도 이 표기 문제로 보임.
3. **메타 패턴 3개(A9-01·A9-03·A9-04)는 성취기준·원자 노드가 전혀 없음** — 메타 전략이라 의도된 것일 수 있으나 근거 노드 0개는 사실.
4. **부록 성취기준 93개 중 25개는 어떤 패턴도 근거로 쓰지 않음**(INFO) — Track A 범위 커버리지 공백 후보.
5. **오개념 807건은 개념ID·성취기준코드 모두 100% 유효** — 코드를 하나씩 쪼개 대조하면 성취기준 목록에 없는 코드 0건. 준고아(매핑점수 <0.5)는 4건뿐(M0019·M0020·M0037·M0119, 전부 '중간' 신뢰도).
6. **원자 핵심 노드 27개가 오개념 0건** — 전부 대학 과정이며 `연결성취기준`이 비어 있어 조인 불가. 27개 모두 노드 안에 ①오개념 텍스트는 있음.
