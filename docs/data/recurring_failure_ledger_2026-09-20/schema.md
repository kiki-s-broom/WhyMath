# 반복 실패 추출 공통 스키마 (모든 추출 에이전트 공통)

출력: JSON Lines (한 줄 = 사고/실수/실패 1건). 필드:
- src: 출처 파일 (예: MEMORY.md / CLAUDE.md / docs/reviews/xxx.md)
- line: 출처 줄 번호(정수, grep -n 기준)
- date: 사고 발생일 (YYYY-MM-DD, 모르면 등재일·헤더 날짜)
- title: 한 줄 요약 (≤80자, 한국어)
- cat: 아래 대분류 코드 1개 (A~K)
- sub: 소분류 자유 라벨 (≤30자, 예: "출력 억제(-q/tail)", "잡 누락", "자리표시자 실행")
- cause: 근본 원인 1줄 (≤100자)
- damage: 피해 정량 (있으면 숫자 그대로: 왕복 N회·폐기 N줄·red N일·방치 N일·공전 N회·PR N건 폐기; 없으면 "0" 또는 "미정량")
- damage_class: none | wasted_round | discarded_work | ci_red | latent_days | false_pass | data_loss
- fix_form: rule | code | task | rule+code | rule+task | none | unknown  (rule=CLAUDE.md 산문 규칙, code=테스트·가드·훅·CLI 게이트, task=백로그 태스크 등재)
- fix_ref: 대책 식별자 (규칙명·테스트 파일·태스크 ID·PR 번호 — 없으면 "")
- series: 명시된 회차 문자열 그대로 (예: "반복 실수 8회차", "미병합 고립 4회차", "동일 유형 2회차", 없으면 "")
- who_caught: 발견 주체 — self | kiki | bot(Codex/Claude Code Review) | ci | luck | unknown
- quote: 근거 인용 ≤120자

대분류 (cat):
A 검증 판정 무효화 — 검사 출력 억제·절단, 래퍼가 exit code 가림, 부분 스위트로 전체 통과 주장, CI 스텝/잡 누락(skipped), 검증 도중 트리 변경, 변별력 없는 검증 스텝, 간접 신호(pid·/health)로 성공 판정, 로컬 green인데 CI red
B 보호 장치 자기위장 — 가드가 정상 입력에서만 초록, 뮤테이션 주입 미적용, 픽스처가 절을 안 밟음, fail-open이 상시 실패, 정본화≠집행(서빙 경로 미호출), 테스트/게이트를 만들고 CI 배선 미확인, 스캔 0건 통과, 이진 판정이 다치 현실 접음
C 미머지 고립·병렬 충돌 — 완료 산출물 PR 미생성·고립 브랜치, 중복 구현(두 세션), claim 순서 위반, 미머지 근거로 충족 판정, 회수 시 acceptance 재대조 누락, 원격 claim 실패
D 부재·존재 오판 — trunk 부재를 미구현으로 단정, 식별자 부재를 기능 부재로 단정, 설정 부재를 설정 가능으로 단정(미제공 기능), 환경 사실 추론 등재, 부분 성공을 전체 정상으로 해석
E Kiki 런북·안내 결함 — 자리표시자 그대로 실행, 증거를 펜스에 넣어 실행됨, PowerShell 제어 흐름 파서 함정, 침묵 가드, 브랜치 자가검증 누락, 시크릿 예시 등록, 진입 경로 누락, 서버 창 혼입, 실행기 단독 호출(pip), 실기기 백엔드 미선결, 미머지 항목 CLI 안내
F 인코딩·플랫폼 — cp949/UTF-8 손상, PowerShell 디코딩 왕복, Windows 커밋 한도, venv 혼재, 로케일 의존 파일
G 대장·하네스 조작 결함 — 셸 백틱 치환 소실, 태스크 ID 중복 배정, depends_on 산문만 기재, 제자리 편집 절단(파일 잘림), 거부(deny) 우회 시도, YAML 손편집
H 관측·측정 도구 결함 — 침묵 실패(무타입 로그), SaaS 단일 의존 위장 0건, 측정 도구가 성공 경로만 설계(증거·원인 유실·시간 필터 없음·무한 대기), 자리표시자 키로 관측 0건, 측정 회차 공전
I 외부 의존성·SDK 표면 — 시임 테스트로 정합 선언, 무상한 pin(v2/v4 혼재), API 제약 미확인 처방
J 알고리즘 무작동·정상 응답 오인 — 알고리즘 부착 후 작동 비율 없음, 200 응답을 작동으로 오인, docstring 계획을 백로그 대체
K 기타·설계 판단 — 과공학·중복 프레임워크 시도, 저작권/교수학 원칙 위반 시도, 그 외

규칙: (1) 같은 사고가 여러 곳에 언급되면 **발생 1건**으로 세되 quote는 가장 정량적인 것 (2) 사고가 아닌 단순 결정·구현 기록은 제외 (3) 확신 없으면 cat=K, sub에 "분류 불확실" (4) 추정 금지 — 문서에 없는 숫자를 만들지 않는다.
