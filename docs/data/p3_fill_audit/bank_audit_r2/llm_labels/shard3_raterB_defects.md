# shard3 판정자 B 결함 근거

51문항을 발문만 보고 직접 새로 풀었다(손계산, 도함수·부호표·미분계수 정의 모두 재계산). 정답 값은 51건 전부 문항 값과 일치했다. 결함으로 표시한 것은 아래 2건이다.

## 1. 3b736de4-5a12-5747-97d9-9ffc4ed52cb1 — 해설 — 확신도: 중간
- 발문: "함수 f(x) = |x^2 - 1| + 2x^2 - 2x에 대하여 x = -1에서의 우미분계수에서 좌미분계수를 뺀 값을 구하시오."
- 직접 푼 값: -1 < x < 1에서 |x^2-1| = 1 - x^2이므로 f = x^2 - 2x + 1, f'(-1) = -4(우). x < -1에서 f = 3x^2 - 2x - 1, f'(-1) = -8(좌). 차 = -4 - (-8) = 4. 정답 4는 맞다.
- 결함: 해설이 "x > -1에서 f(x) = x^2 - 2x + 1"이라고 썼다. x > 1에서는 |x^2-1| = x^2 - 1이라 f = 3x^2 - 2x - 1이므로 이 서술은 수학적으로 틀리다(올바른 서술은 -1 < x < 1). 우미분계수 값에는 영향이 없는 국소 구간 서술 오류다. 같은 문항 군의 |x+1| 꼴(예: 9bf95bbd)은 x > -1 전체에서 식이 성립해 문제가 없다.

## 2. 6a60e1d9-2f2c-5f73-9500-0f434810b798 — 해 불명확 — 확신도: 불확실
- 발문: "함수 f(x) = x - x^2 + x^3 + ... + x^5에 대하여 f'(2)의 값을 구하시오."
- 직접 푼 값: 부호가 번갈아 바뀌는 것으로 읽으면 f = x - x^2 + x^3 - x^4 + x^5, f'(2) = 1 - 4 + 12 - 32 + 80 = 57로 문항 값과 같다.
- 의심: 생략 기호 앞의 연결 부호가 "+"라서, 생략된 항(x^4)의 부호가 발문만으로는 정해지지 않는다. "+ ..."로 읽으면 x^4 항이 +가 되어 f'(2) = 1 - 4 + 12 + 32 + 80 = 121이다. 번갈아 바뀌는 부호 규칙을 발문이 명시하지 않았다. 규칙이 보이는 앞 세 항으로 추론은 가능하므로 확신은 낮다.
