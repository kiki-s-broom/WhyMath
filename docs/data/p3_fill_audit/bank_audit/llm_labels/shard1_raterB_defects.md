# shard1 판정자 B 결함 근거 (51문항 전수 직접 풀이, sympy 미설치로 손계산)

## 6d39046a-ec57-5804-ae8d-4e30cf844524 (10번째 줄) — 문장 표기 — 확신도: 중간
- 발문: "함수 f(x) = -x^2 + 2x - 4에서 x = -1에서의 미분계수 f'(-1)의 값을 구하시오."
- 조사 "에서"가 연달아 두 번(함수 ...에서 / x = -1에서의) 쓰인 조사 중복이다. 같은 묶음의 다른 기본 문항은 "곡선 ... 위의 x좌표가 -1인 점에서의 ..."처럼 한 번만 쓴다.
- 계산은 문제 없음: f'(x) = -2x + 2, f'(-1) = 4 = 문항 정답. 결함은 문장 표기뿐.

## 7cf324d5-dd5e-5808-83eb-e21e7ea3429b (48번째 줄) — 미분 없이 풀림 — 확신도: 확실
- 발문: "공이 던진 지 3초 후와 7초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오." (성취기준 [12미적Ⅰ-02-10], 속도·가속도 문항군)
- 직접 풀이: h(3) = h(7)에서 3u - 45 = 7u - 245, 4u = 200, u = 50 (문항 정답 50과 일치). 풀이 전체가 일차방정식뿐이며 속도(도함수)를 한 번도 쓰지 않는다. 해설도 도함수를 쓰지 않는다. 같은 문항군의 다른 문항(11, 15, 36번 줄 등)은 v(t) = h'(t) = 0을 쓰는 것과 대조된다.
- 인지 행동(미분으로 속도를 구함)이 없이 정답에 도달하므로 결함.

## 검토했으나 결함으로 보지 않은 것 (참고)
- 거듭제곱 도함수 귀납형(2, 22, 33, 38, 39, 43, 46번 줄): 예시 값에서 규칙을 귀납하는 설계가 해설에 명시되어 있고 정답은 모두 손계산으로 일치했다. 33, 38번은 부호 교대와 크기 n 패턴만으로도 풀릴 여지가 있으나 문항군 설계로 보아 결함으로 표시하지 않았다.
- 25번 줄(방정식 f'(x)=0의 실근을 발문이 제시): 극값 여부 판단에는 f' 부호 분석이 여전히 필요하다. 정답 -57 일치.
