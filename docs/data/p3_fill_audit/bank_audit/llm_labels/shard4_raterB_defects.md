# shard4 판정자 B 결함 근거

## a7a6f2b3-06ba-56e8-9b2e-f6a4c04e3ae2 — 미분 없이 풀림 — 확신도: 중간
발문: "h(t) = ut - 5t^2 ... 공이 던진 지 2초 후와 5초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오."
직접 푼 값: h(2)=h(5) 에서 2u-20 = 5u-125, 3u=105, u=35 (문항 값 35와 일치, 정답 자체는 맞음).
문제점: 이 문항은 성취기준 [12미적Ⅰ-02-10](속도·가속도 등 미분 활용)에 속하는데, 풀이 경로(해설 포함)가 도함수·속도를 전혀 쓰지 않고 두 시각의 높이를 같다고 놓는 일차방정식 하나로 끝난다. 미분 인지 행동 없이 현실적으로 정답에 닿는다.

## d51edab8-bafd-50f6-ac2f-f4798afe0ee9 — 해설 — 확신도: 불확실
발문: "f(x) = |x - 3| + 2|x - 8| + x^2 - 4x + 4에 대하여 x = 3에서의 우미분계수에서 좌미분계수를 뺀 값을 구하시오."
직접 푼 값: 3 근방에서 2|x-8|은 매끄럽고 |x-3|만 꺾이므로 우미분계수 1, 좌미분계수 -1, 차는 2 (문항 값 2와 일치).
문제점: 해설이 "x > 3에서 f(x) = x^2 - 5x + 17"이라고 쓰는데, 이 식은 3 < x < 8에서만 성립하고 x > 8에서는 틀리다(x > 8이면 2|x-8| = 2x-16). 구간 한정 없는 수학적으로 틀린 서술. 결론에는 영향이 없어 불확실.
