# shard4 판정자 A 근거 (결함 4건 / 51문항)

51문항 전부 발문만 보고 직접 새로 풀었다. 정답 불일치는 0건이었다. 해설의 중간 식과 값도 전수 대조했고 틀린 곳이 없었다. 아래 4건은 모두 "미분 없이 풀림"(결함 3) 계열이다.

## a7a6f2b3-06ba-56e8-9b2e-f6a4c04e3ae2 — 미분 없이 풀림 — 확신도: 확실(중간 이상)
- 발문: "공이 던진 지 2초 후와 5초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오." (h(t) = ut - 5t^2)
- 직접 푼 값: h(2) = h(5)에서 2u - 20 = 5u - 125, 3u = 105, u = 35. 문항 정답 35와 일치한다.
- 근거: 풀이가 일차방정식 하나로 끝난다. 속도(도함수)·v(t)=0 같은 성취기준 [12미적Ⅰ-02-10]의 인지 행동을 한 번도 쓰지 않는다. 해설과 `verify`에도 미분이 없다. 같은 성취기준의 다른 문항(정지 시점 v=0, 최고점 v=0)과 달리 순수 대입과 연립으로 해결된다.

## e8088d4a-9919-5058-97e6-405ee54dd89b — 미분 없이 풀림 — 확신도: 불확실
- 발문: "a(3) = 3, a(4) = -4, a(5) = 5일 때, a(3)부터 a(10)까지의 합을 구하시오." (a(k)는 x^k의 x=-1에서의 미분계수)
- 직접 푼 값: a(k) = k(-1)^(k-1)이고 3 - 4 + 5 - 6 + 7 - 8 + 9 - 10 = -4. 문항 정답 -4와 일치한다.
- 근거: 발문이 a(3), a(4), a(5)를 알려 주는데 3, -4, 5는 부호가 번갈아 바뀌는 자연수열이다. 도함수를 구하지 않고 규칙을 추측해 a(6) = -6, ..., a(10) = -10을 이어 쓰면 답에 닿는다. 틀린 점은 없고, 핵심 값을 알려 줘서 미분이 필수가 아닐 수 있다는 의심이다.

## e22a243d-bf84-517e-b6f6-8cc946a31f49 — 미분 없이 풀림 — 확신도: 불확실
- 발문: "a(1) = 1, a(2) = -2, a(3) = 3일 때, 처음 13개 항의 합 a(1) + a(2) + ... + a(13)의 값을 구하시오."
- 직접 푼 값: 1 - 2 + 3 - ... + 13 = 7. 문항 정답 7과 일치한다.
- 근거: 위 문항과 같은 계열이다. 제시된 세 항 1, -2, 3만 보아도 a(k) = (-1)^(k-1)k라는 규칙이 바로 읽혀, 미분계수를 구하지 않고 교대합으로 답이 나온다. 이쪽이 더 뚜렷하다.

## db45ee46-b123-592e-83d5-2a8416271f02 — 미분 없이 풀림 — 확신도: 불확실
- 발문: "사차함수 f(x) = 3x^4 + 16x^3 + 3에 대하여 방정식 f'(x) = 0의 실근은 x = -4와 x = 0이다. f(x)의 극값을 구하시오."
- 직접 푼 값: f(-4) = 768 - 1024 + 3 = -253이고, x = 0은 f'의 부호가 바뀌지 않아 극값이 아니다. 문항 정답 -253과 일치한다.
- 근거: 발문이 극값 후보의 위치(f'(x) = 0의 근)를 이미 알려 줘서 도함수와 방정식 풀이 단계가 사라진다. 남는 것은 f(-4) 계산과 x = 0의 부호 판단이다. 후자는 f'의 부호 판단이라 미분이 아주 없지는 않으므로 확신이 낮다.
