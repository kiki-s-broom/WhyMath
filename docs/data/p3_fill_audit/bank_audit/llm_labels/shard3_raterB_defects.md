# shard3 판정자 B 결함 근거

## 6c87f82d-7966-58ea-a8c8-31281a65efd9 · 문장 표기(조사 중복) · 확신도 중간
- 발문 인용: "함수 f(x) = 2x^2 + 6x + 5에서 x = 3에서의 미분계수 f'(3)의 값을 구하시오."
- 근거: 조사 "에서"가 한 문장에 연달아 두 번 쓰여(함수 ...에서 / x = 3에서의) 어색한 조사 중복이다. 수학 값은 직접 푼 결과 f'(x)=4x+6, f'(3)=18로 answer와 일치하므로 정답 결함은 아니고 문장 결함만 의심한다. "함수 f(x) = ...에 대하여 x = 3에서의 미분계수"처럼 쓰는 것이 맞다. 같은 묶음의 다른 문항은 "에 대하여" 또는 "함수 f(x)에서 x의 값이 a에서 b까지 변할 때"의 정상 용법이라 이 문항만 중복으로 보인다. 불확실 요소: 생성기 서식으로 허용된 표현일 수 있음.
