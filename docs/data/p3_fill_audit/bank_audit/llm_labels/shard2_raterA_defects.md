# shard2 판정자 A 결함 근거 (51문항 중 결함 3건)

51문항 모두 발문만 보고 직접 새로 풀어 정답 일치를 확인했다(전건 일치). 해설의 중간 식·조사·표기·verify 대응도 대조했고, 아래 3건만 결함으로 표시한다.

## 1. fd249044-051f-58b9-8093-8a3e0e130a25
- 분류: 미분 없이 풀림
- 확신도: 불확실
- 근거: 발문 "h(t) = -5t^2 + 20t (m)이다. 공이 가장 높이 올라갔을 때의 지면으로부터의 높이는 몇 m인가?" 이 식은 위로 볼록한 이차함수라 꼭짓점 공식(t = -20/(2·(-5)) = 2, 높이 -20 + 40 = 20)이나 완전제곱식만으로 끝난다. 직접 푼 값 20은 정답 20과 일치하지만 속도(도함수) 개념 없이도 닿는다. 성취기준 02-10(속도·가속도)의 인지 행동을 강제하지 못한다.

## 2. 959bcc89-c9a7-511c-a7bc-82be548da67a
- 분류: 미분 없이 풀림
- 확신도: 불확실
- 근거: 발문 "s(t) = -3t^2 + 36t (m)이다. 이 자동차는 브레이크를 밟은 지 몇 초 후에 멈추는가?" 멈추는 시각은 이차함수 s의 꼭짓점 t = -36/(2·(-3)) = 6이므로 꼭짓점 공식만으로 풀린다. 직접 푼 값 6은 정답 6과 일치하지만 도함수·속도 개념이 필요 없다.

## 3. 6e27328e-ba04-51e6-99d7-03c93a618c06
- 분류: 미분 없이 풀림
- 확신도: 중간
- 근거: 발문 "공이 던진 지 1초 후와 5초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오." h(1) = h(5)를 세워 일차방정식 u - 5 = 5u - 125, 4u = 120, u = 30으로 끝난다(해설도 미분을 쓰지 않음). 대칭축 t = 3이 꼭짓점이라는 이차함수 성질로도 풀린다. 직접 푼 값 30은 정답과 일치하지만, 속도·도함수 개념(02-10)을 전혀 쓰지 않는다.
