# shard1 판정자 A 결함 근거 (51문항 중 defect 7건)

모든 문항의 정답은 발문만 보고 직접 새로 풀어 확인했다. 정답 값 불일치·모순·해설 계산 오류는 발견하지 못했다. 아래 7건은 정답 오류가 아니라 "미분 없이 풀림" 또는 "문장 표기" 의심이다.

## 7cf324d5-dd5e-5808-83eb-e21e7ea3429b — 미분 없이 풀림 — 확신도: 확실
- 발문: "공이 던진 지 3초 후와 7초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오." (성취기준 02-10, 속도와 가속도)
- 직접 풀이: h(3) = h(7)이므로 3u - 45 = 7u - 245, 4u = 200, u = 50. 문항 값 50과 일치한다.
- 결함: 풀이가 도함수나 속도를 한 번도 쓰지 않는다. 해설도 "h(3) = h(7)"로 등식만 세우고, 검산 재료(`verify`)에도 Derivative가 없다. 이 성취기준의 인지 행동(속도 = 위치의 도함수)이 필요 없는 문항이다.

## ed88da80-d138-5af0-bebb-d3e587e7aca3 — 미분 없이 풀림 — 확신도: 불확실
- 발문: "x^3의 도함수는 3x^2, x^4의 도함수는 4x^3, x^5의 도함수는 5x^4이다. 같은 규칙으로 함수 x^9을 미분한 도함수를 h(x)라 할 때, h(2)의 값을 구하시오."
- 직접 풀이: h(x) = 9x^8, h(2) = 9 × 256 = 2304. 문항 값과 일치한다.
- 의심: 발문이 거듭제곱 미분 규칙을 사례로 모두 알려 줘서, 미분법을 몰라도 사례의 패턴을 따라 하면 답에 닿는다. 사례에서 규칙을 귀납하는 것이 의도된 행동일 수는 있다. 그래서 불확실로 표시한다.

## 015ce283-b381-5de5-9fbd-90662b836c4f — 미분 없이 풀림 — 확신도: 불확실
- 발문: "x^3의 도함수는 3x^2, x^4의 도함수는 4x^3, x^5의 도함수는 5x^4이다. 같은 규칙으로 함수 x^7을 미분한 도함수를 h(x)라 할 때, h(3)의 값을 구하시오."
- 직접 풀이: h(x) = 7x^6, h(3) = 7 × 729 = 5103. 문항 값과 일치한다.
- 의심: 위 ed88da80과 같은 틀이다. 규칙이 발문에 사례로 주어져 있다.

## 196b9252-dbc8-529d-a2f5-177e28bd9bea — 미분 없이 풀림 — 확신도: 불확실
- 발문: "f(x) = x^n의 x = -1에서의 미분계수를 a(n)이라 하자. a(2) = -2, a(3) = 3, a(4) = -4일 때, a(8)의 값을 구하시오."
- 직접 풀이: a(n) = n(-1)^(n-1)이므로 a(8) = -8. 문항 값과 일치한다.
- 의심: 주어진 세 값(-2, 3, -4)만 보고 "크기는 n, 부호는 번갈아"로 추측하면 도함수 없이 -8에 닿는다. 해설도 사례의 패턴을 먼저 쓰고 f'(x)로는 나중에 확인한다.

## d8643e5f-4782-5cec-9130-37f8a50e4219 — 미분 없이 풀림 — 확신도: 불확실
- 발문: "f(x) = x^n의 x = -2에서의 미분계수를 a(n)이라 하자. a(2) = -4, a(3) = 12, a(4) = -32일 때, a(9)의 값을 구하시오."
- 직접 풀이: a(n) = n(-2)^(n-1)이므로 a(9) = 9 × 256 = 2304. 문항 값과 일치한다.
- 의심: 주어진 값에서 n × (-2)^(n-1)을 귀납하면 도함수 없이 풀린다. 해설이 사례에서 규칙을 읽어 내는 경로를 그대로 적고 있다.

## 7e3f286c-dcb9-5b8d-8cf6-866b70f02b37 — 미분 없이 풀림 — 확신도: 불확실
- 발문: "f(x) = x^k의 x = -1에서의 미분계수를 a(k)라 하자. a(5) = 5, a(6) = -6, a(7) = 7일 때, a(5)부터 a(10)까지의 합을 구하시오."
- 직접 풀이: a(k) = k(-1)^(k-1)이므로 5 - 6 + 7 - 8 + 9 - 10 = -3. 문항 값과 일치한다.
- 의심: 주어진 세 값이 "부호가 번갈아 바뀌는 k"를 그대로 보여 준다. 도함수 없이 a(8) = -8, a(9) = 9, a(10) = -10으로 이어 쓰면 된다.

## 6d39046a-ec57-5804-ae8d-4e30cf844524 — 문장 표기 — 확신도: 불확실
- 발문: "함수 f(x) = -x^2 + 2x - 4에서 x = -1에서의 미분계수 f'(-1)의 값을 구하시오."
- 직접 풀이: f'(x) = -2x + 2이므로 f'(-1) = 4. 문항 값과 일치한다. 수학적 오류는 없다.
- 의심: "…함수 f(x)에서 x = -1에서의 …"로 처격 조사 "에서"가 연달아 나와 어색하다. 다른 문항은 "함수 f(x)에 대하여"를 쓴다. 조사 중복으로 볼지는 불확실하다.
