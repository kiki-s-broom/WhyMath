# shard2 판정자 B 근거 (결함 4건 / 51문항)

나머지 47문항은 발문만 보고 직접 새로 풀어 정답·해설 계산·검산 재료 일치를 확인했고 결함을 찾지 못했다.

## 6e27328e-ba04-51e6-99d7-03c93a618c06 · 미분 없이 풀림 · 확신도 확실
- 발문: "h(t) = ut - 5t^2 (m)이다 ... 공이 던진 지 1초 후와 5초 후에 같은 높이에 있었다고 할 때, u의 값을 구하시오."
- 직접 푼 값: h(1)=h(5)에서 u-5 = 5u-125, 4u=120, u=30. 문항 값 30과 같아 정답은 맞다.
- 문제: 대입과 일차방정식만으로 끝난다. 속도·도함수(성취기준 02-10의 인지 행동)를 전혀 쓰지 않는다. 해설도 "같은 높이이므로 h(1)=h(5)"뿐이다.

## 11f99bd4-de25-506c-a4b6-e6bc135907a2 · 문장 표기 · 확신도 중간
- 발문: "같은 규칙으로 함수 x^5을 미분한 도함수를 h(x)라 할 때".
- 문제: 5는 "오"로 읽혀 모음으로 끝나므로 목적격 조사는 "를"이어야 한다. "x^5을"은 수 뒤 조사 오류다. 값은 맞다(h(-1) = 5·(-1)^4 = 5).

## fd249044-051f-58b9-8093-8a3e0e130a25 · 미분 없이 풀림 · 확신도 불확실
- 발문: "h(t) = -5t^2 + 20t (m) ... 공이 가장 높이 올라갔을 때의 지면으로부터의 높이는 몇 m인가?"
- 직접 푼 값: 꼭짓점 t=2, 높이 20. 문항 값 20과 같다.
- 문제: 이차함수 꼭짓점(완전제곱) 공식만으로 미분 없이 현실적으로 풀린다. 불확실(성취기준이 속도를 도함수로 보는 맥락이라 의도된 해법은 미분이지만, 발문은 미분을 요구하지 않는다).

## 959bcc89-c9a7-511c-a7bc-82be548da67a · 미분 없이 풀림 · 확신도 불확실
- 발문: "s(t) = -3t^2 + 36t (m) ... 브레이크를 밟은 지 몇 초 후에 멈추는가?"
- 직접 푼 값: 거리 s의 최댓값이 되는 꼭짓점 t=6. 문항 값 6과 같다.
- 문제: 이차함수 꼭짓점 공식만으로 미분 없이 풀린다. 불확실(위와 같은 이유).
