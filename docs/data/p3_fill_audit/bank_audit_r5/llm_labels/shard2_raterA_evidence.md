- 판정 51건, defect 0건.
- 방법: 51건 모두 발문만 보고 SymPy(`check.py`)로 정답을 새로 풀었다(극한 정의·좌우 미분계수는 h→0± 극한으로,
  극값은 f'=0과 2계 도함수 부호로, 증감 범위는 부등식 풀이로). 51건 모두 직접 푼 값이 `answer`와 일치했다.

## 결함으로 올리지 않은 경계 사례(기록용)

- 14, 23번 계열(`|x - c|·g(x)`가 x = c에서 미분가능 → g(c) = 0)은 지름길이 있으나, 그 지름길 자체가 미분가능성
  판단(좌우 미분계수 비교)에서 나오는 성취기준 고유의 행동이고, 연속성 등 다른 오답 경로로는 a가 정해지지 않으므로
  '미분 없이 풀림'으로 보지 않았다(문항 d301587a-…, c365ba10-…).
- 급수형 다항식 해설의 "짝수만 커진다/홀수만 커진다"(0cf7067e-…, 78f8158a-…, f77e1161-…)는 표현이 다소 어색하지만
  의미 전달에 오류가 없어 결함으로 올리지 않았다.
- 2599a68d-… 해설의 "곡선의 식을 y = f(x)라 하자"는 발문의 "함수 y = …"를 곡선으로 부른 것으로, f를 소개하고 쓰므로
  결함으로 보지 않았다.
