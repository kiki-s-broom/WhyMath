## 판정 방법

- 문항마다 발문만 보고 SymPy(`solve.py`)로 새로 풀었다(극한식은 limit, 절댓값 함수는 좌우 극한, 극값은 f' 부호 변화로 판정).
- 해설의 중간 값(도함수 식, f(c) 값, 연립방정식, 합산 값)을 손계산으로 대조했다. 틀린 중간 값은 없었다.
- verify 조건식과 정답 맵이 발문과 같은 함수·수치·대상을 가리키는지 대조했다(2계 도함수 부호 조건 포함). 불일치는 없었다.
- 학생 대면 텍스트에서 코드 표기(`*`, `<=`, `>=`, `sqrt(`), 부호 깨짐(`+ -`, `- -`, `1x`), 조사 중복을 기계로 찾았다. 걸린 것은 없었다. 수·변수 뒤 조사도 눈으로 확인했다.
- 경계 사례였지만 결함으로 보지 않은 것: `|x+1|(x^2+a)`, `|x+1|(2x+a)` 미분가능 조건 문항(14, 23). g(-1)=0이라는 지름길도 미분가능성 판정 지식이어서 미분 없이 풀린다고 보지 않았다. 31번의 `- x^2 (a는 상수)이`는 괄호 앞 x^2(제곱)에 맞춘 조사라 정상으로 봤다.
