## 결함 1

- 문항 id: `11f6e0f3-f6a3-508c-acd2-883426685cc5`
- 분류: 문장 표기
- 확신도: 불확실
- 근거: 해설의 첫 문장 「|x - 2|^3의 차분몫은 크기가 |x - 2|^2이라 x가 가까워지면 0에 한없이 가까워진다.」에서 x가 *어디에* 가까워지는지가 빠졌다. "x가 2에 가까워지면"이어야 문장이 완결된다. 수학 내용(차분몫의 크기 |x-2|^2 → 0)은 맞다.
- 직접 푼 값: x > 2 쪽 도함수 3x^2 - 14x + 17, x < 2 쪽 도함수 -3x^2 + 10x - 7은 x = 2에서 모두 1이다. 그래서 f'(2) = 1이고 문항 정답 1과 같다. 결함은 문장에만 있다.

## 결함 2

- 문항 id: `90aa2875-103e-5ac5-b1b0-2b4670164a77`
- 분류: 해설
- 확신도: 불확실
- 근거: 발문은 「(f(1 + h) - f(1)) / h의 극한값이 2이다. 상수 a의 값을 구하시오.」로, 극한값을 주고 a를 묻는다. 그런데 해설 첫 문장은 「구하는 극한값은 f'(1)이다.」라고 해서, 주어진 조건인 극한값을 구하는 대상처럼 적었다. 발문과 해설이 가리키는 대상이 어긋난다. "주어진 극한값은 f'(1)이다"가 맞다.
- 직접 푼 값: f'(x) = 6x^2 + 2ax + 2이고 f'(1) = 2a + 8 = 2이므로 a = -3이다. 문항 정답 -3과 같다. 결함은 해설 서술에만 있다.
