# shard3 판정 근거 (판정자 B)

판정 51건 · defect 1건. 51건 전부 발문만 보고 SymPy로 다시 풀었고, 직접 푼 값은 51건 모두 문항 정답과 같았다. 결함 1건은 해설 문장의 조사 오류다.

## 7a4ed3d4-d49e-5f3a-8b3b-11e56b9072ae

- 분류: 문장 표기 (수 뒤 조사 오류)
- 확신도: 중간
- 근거: 해설에 "지수가 2, 4, 6, ...로 짝수만 커진다."라고 적혀 있다. 줄임표 바로 앞의 수 6은 '육'으로 읽혀 받침이 ㄱ이므로 조사는 "으로"여야 한다("6, ...으로"). 같은 묶음의 다른 문항은 같은 틀에서 마지막 수를 기준으로 조사를 골랐다. 1, 3, 5 뒤에 "로", 1, 2, 4, 8 뒤에 "로", 1, 2, 3 뒤에 "으로"를 썼다. 이 문항만 그 규칙과 어긋난다. 정답은 문제가 없다. 발문 f(x) = x^2 + x^4 + ... + x^18에서 f'(-1) = -(2 + 4 + ... + 18)을 직접 풀면 -90이고, 문항 값 -90과 같다. 줄임표 뒤의 조사를 무엇에 맞추느냐는 관례가 갈릴 수 있어서 확신도를 '중간'으로 둔다.
