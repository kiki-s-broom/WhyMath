### 1. `2b4b4a95-cdb5-5a43-8a5e-4912f74bb2bc` — 문장 표기 · 확신도: 중간

- 발문: "함수 f(x) = |x + 2|^3 + x^2 - 4x + 2에 대하여 f'(-2)의 값을 구하시오." 문항 정답 -8, 직접 푼 값 -8(좌·우 미분계수 모두 -8). 정답은 맞다.
- 결함 위치(해설 첫 문장): "|x + 2|^3의 차분몫은 크기가 |x + 2|^2이라 **x가 가까워지면** 0에 한없이 가까워진다."
  - 무엇에 가까워지는지가 빠져 있다. "x가 -2에 가까워지면"이어야 문장이 성립한다. 지금은 극한의 대상이 정해지지 않은 불완전한 수학 서술이다.
  - "차분몫"은 고교 교육과정 용어가 아니다(교과서 용어는 "평균변화율"). 정의 없이 쓰였다.
- 뒤이은 구간별 전개(x > -2: x^3 + 7x^2 + 8x + 10, x < -2: -x^3 - 5x^2 - 16x - 6)와 도함수 값은 맞다.

### 2. `77bcc36d-9bf1-56a8-88b6-a732c55dfe6c` — 문장 표기 · 확신도: 중간(불확실 쪽에 가까움)

- 불확실 사유: "제곱초"로 읽으면 "였다"도 성립한다. 읽는 방식에 따라 판정이 갈린다.
