## 결함

### 017bc0d7-d1ab-58fc-bf29-32e6b52d7e26
- 분류: 문장 표기
- 확신도: 불확실
- 근거: 해설 첫 문장이 "|x + 1|^3의 차분몫은 크기가 |x + 1|^2이라 x가 가까워지면 0에 한없이 가까워진다."이다. "x가 가까워지면"에는 x가 어디에 가까워지는지(-1에)가 빠져 있어 문장이 성립하지 않는다. 또 고교 교육과정 용어가 아닌 "차분몫"을 정의 없이 쓰고, 어느 점에서의 몫인지도 적지 않았다.

- f'(x) = 0이지만 부호가 바뀌지 않는 점을 묻는 두 문항(d357f439…, 179bbadd…)은 verify가 "가장 큰 근"(`answer_selection: largest`)으로 답을 고른다. 발문의 기준(부호 불변)과 다르지만 같은 함수, 같은 값 0을 가리키므로 다른 문제를 가리키는 불일치로 보지 않았다.
- 우미분계수에서 좌미분계수를 뺀 값을 묻는 문항(dd9d086c…, efac563d…)은 다항식 부분이 상쇄되어 값이 절댓값 항의 계수만으로 정해진다. 그래도 절댓값 항의 한쪽 미분계수를 판단해야 하고 오답 경로(절댓값 무시 → 0, 부호 반전 → 음수)와도 갈리므로 "미분 없이 풀림"으로 보지 않았다.
- |x - p|g(x)가 x = p에서 미분가능한 조건(g(p) = 0)으로 바로 푸는 지름길은 미분가능성 개념 자체의 적용이라 결함으로 보지 않았다.
