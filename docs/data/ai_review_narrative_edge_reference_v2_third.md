## 구조 관찰(판정 외 참고)

- reject 3건 중 2건(E044·E171)은 '바로 앞 개념이 다른 소단원에 있어 replace로 표현할 수 없는' 경우다 — E044는 CALC2-P08「다변수 연쇄법칙」, E171은 TOPO1-C02「기저」가 직접 선수다. 꾸러미 규칙상 reject로 적었으나 후속 후보 생성 시 이 두 엣지를 별도 검토할 가치가 있다.
- E147 hold는 소단원 '라플라스 변환'에 변환 정의 원자가 없고 합성곱 정리 원자만 있는 구조 공백에서 온다. 같은 공백이 E046(호몰로지군)에도 있으나 그쪽 원자는 대상 자체(호몰로지군)의 성격을 서술해 대리 노드로 승인했고, E147은 특정 성질(합성곱) 원자라 승인하지 않았다.
- 도착 원자의 기존 선수가 무관한 순서 엣지인 사례가 다수다(E031 R04 중간값→최대최소, E059 P18 곡면적→부분적분, E078 P10 라그랑주 승수→극변환, E118 C10 심슨→부분피벗팅 등). 이번 꾸러미 범위 밖이라 판정에 반영하지 않았다.
