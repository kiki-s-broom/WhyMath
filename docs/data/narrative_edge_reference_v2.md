## 3. 합의 승인 90건의 처분 — 3인째 블라인드 검수 (③) · 사전 등록

**사전 등록 시각: 2026-10-20T23:34Z(UTC) — 검수자 C의 결과가 나오기 전에 적었다.**

- 대상 = KG-11 합의 승인 90건 ∩ 가드 통과 = **66건**(그중 2건은 두 검수자가 같은 코드로 replace한 "교체 승인").
- 검수자 C는 KG-11의 A·B 판정과 가드 결과를 모르는 상태에서 66건을 같은 판정 질문("출발 원자가 도착 원자의 직접 선수인가")으로 판정한다. 꾸러미는 KG-11 꾸러미의 해당 행을 그대로 잘라 낸 것(행 번호 유지).
- **C 승인** = 승인 합의 행에 C가 `approve`, 또는 교체 합의 행에 C가 같은 코드로 `replace`. 그 밖(reject·hold·다른 코드 replace·approve↔replace 불일치)은 **불승인**.
- **게이트**: Wilson 95% 단측 하한(C 승인 수 / 66) ≥ 0.80 → C 승인분만 승격(불승인분은 보류·원장 기록). 하한 < 0.80 → **승격 0건**(66건 전건 보류). n=66에서 하한 0.80을 넘는 최소 승인 수는 **59**(59/66 → 0.8154 · 58/66 → 0.7974).
- 게이트는 KG-11과 같은 함수(`whymath_backend.harness.wilson.wilson_lower_bound`)·같은 임계 0.80이며, 결과를 보고 완화하지 않는다(태스크 acceptance ③).
- 승격되면: `evidence "KG-12 서술형 낱말매칭 승격 v2"` · `strength 0.8` · `relation_subtype 정규화`로 정본 엣지가 되며, 병합은 `narrative_promotion_merge`(sha 검사·멱등·1:1 대조)로만 한다. 승격 엣지는 모두 v1 원장이 순환 없음을 보장한 쌍이므로 DAG 검사는 병합기의 `validate_promotion`이 재확인한다.
