# shard4 판정 근거 (판정자 B)

판정 63건 · defect 1건. 나머지 62건은 발문만으로 직접 다시 풀어(손계산 + SymPy) 정답, 해설 계산, 오답 선지–오개념 연결, verify가 모두 맞는 것을 확인했다.

## 6c404b8c-ab67-564e-a6ea-12d2ba5c1152
- **분류**: 해 불명확(정답이 하나로 정해지지 않음)
- **확신도**: 불확실
- **근거**: 발문은 "y = (-2x + 1)(2x^2 - 3)의 도함수의 모든 계수의 합으로 옳은 것은?"이고 선지는 -8, -4, -2, 2, 정답은 -2이다.
  직접 구한 도함수는 y' = -12x^2 + 4x + 6이다. 상수항을 계수에 넣으면(x = 1을 대입) 합은 -2로 문항 정답과 같다.
  그런데 교과서는 '계수'를 문자에 곱해진 수로, 상수항을 계수와 따로 정의한다. 이 정의를 따르면 상수항을 빼고 -12 + 4 = -8이 되고, -8도 선지에 있다(①).
  게다가 ①은 곱의 미분 오개념(f′·g′ → -8x)과 연결된 선지라서, 미분은 바르게 하고 상수항만 뺀 학생도 오개념 선지를 고르게 된다.
  '상수항을 포함한' 같은 말이 발문에 없어서 답이 -2와 -8 두 갈래로 갈릴 여지가 있다. 관례상 "모든 계수의 합 = x = 1 대입값"으로 읽는 경우가 많아 확신은 낮다.
