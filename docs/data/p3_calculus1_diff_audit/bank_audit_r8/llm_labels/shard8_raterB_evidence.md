# shard8 판정 근거 (판정자 B)

- 판정 문항: 63건, `defect` 0건.
- 결함으로 판정한 문항이 없다.

## 검토 방법 (기록용)

- 문항마다 발문만 보고 SymPy(`check.py`)와 손계산으로 정답을 새로 구해 `answer`와 대조했다. 63건 모두 일치했다.
- 객관식 17건은 연결된 오개념의 절차(거듭제곱 미분 단계 누락, 곱의 미분 f′·g′, 임계점=극값 단정,
  극값·극점 혼동, 롤의 정리 혼동)로 해당 선지 값이 실제로 나오는지 다시 계산했다. 모두 나왔고, 정답 선지에 연결된 오개념은 없었다.
- 미정 계수·구간 조건(양수, b > 0, 열린구간 등)이 해를 하나로 정하는지, 극값 판정에서 부호 변화를 따졌는지,
  실근 개수 문항은 실제 실근 개수(SymPy real_roots)로 확인했다.
- 해설의 중간 값(도함수, 인수분해, 극값, 평균변화율, 접선 식)과 조사·표기도 확인했다. 결함으로 판단할 근거를 찾지 못했다.
- 경계 사례로 따져 본 것(결함으로 보지 않음): 1f03b9a9(f(x) = x의 f′(−5))와 22b844cc(g = f + 2일 때 g′ − f′)는
  계산이 짧지만 도함수 규칙 자체가 진단 대상이다. 151f9307의 `verify`는 n = 2로 정해진 뒤의 f(x) = x^2를 쓰지만, 발문과 같은 문제를 가리킨다.
