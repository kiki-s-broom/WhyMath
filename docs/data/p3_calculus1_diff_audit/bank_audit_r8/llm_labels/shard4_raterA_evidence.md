  (예: 069b8d4a… p=−3 일차식, 2ad6490a… 접선 하나, c8a92c31… a=−3 배제로 k=7, 5727df4d… a=−4 배제).

- 학생 대면 텍스트: 코드 표기(`<=`, `>=`, `*`, `sqrt(`), 부호·계수 표기 깨짐, 조사 중복이 없고, 수·변수·괄호 뒤 조사도
  읽기 기준으로 맞았다(`particles.py`로 걸러 사람이 확인).
