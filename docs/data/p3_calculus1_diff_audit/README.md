## 3회차에서 드러난 구조 원인

결함 대부분이 "미분 없이 선수 계산으로 풀린다"(`bad_tag`) 한 부류다. 생성기가 기계 검증을 위해 정수 중근·
깔끔한 인수를 가진 다항식을 고르는데, 바로 그 성질이 인수분해·판별식 우회로를 연다. 1·2회차 교정은 지적된
부류를 지우는 방식이라 이 원인을 막지 못했다. 4회차 전 교정은 우회로를 **생성 시점에 코드로 차단**한다.
