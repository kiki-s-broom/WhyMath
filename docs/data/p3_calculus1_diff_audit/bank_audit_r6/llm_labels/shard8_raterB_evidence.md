# shard8 판정 근거 (판정자 B)

결함 없음 — 판정 63건, defect 0건.

## 판정 방법 (기록용)

- 63건 전부 발문만 보고 정답을 새로 풀었다(손계산 후 SymPy로 재계산: 극값·극값 위치, 실근 개수, 평균값 정리의 c, 롤의 정리의 c, 접선 기울기·교점, 속도·가속도, 미정계수). 직접 푼 값이 63건 모두 `answer`와 일치했다.
- 유일성: 양수·구간·열린구간·"하나뿐" 조건이 적힌 문항은 그 조건이 실제로 해를 하나로 정하는지 확인했다(예: 평균값 정리 문항은 다른 근이 구간 끝점이나 구간 밖에 있음, "하나뿐이다"라고 적힌 문항은 실제로 실근이 하나뿐임). 답 형식(자연수·정수·분수·실수)과 정답 값도 모두 맞았다.
- 미분 필요성: 발문이 극값 위치·평균변화율·최솟값 위치 같은 핵심 값을 미리 알려 주는 문항은 없었다. 오답 경로(곱의 도함수를 도함수의 곱으로 계산, 지수 단계 누락, 원함수를 대입)는 정답과 다른 값을 낸다.
- 문장·표기: 수·변수·식 뒤 조사(받침 유무에 따른 은/는·이/가·을/를·와/과)를 스크립트로 전수 추출해 확인했고 오류가 없었다. 학생이 보는 텍스트에 코드 표기(`<=`·`>=`·`*`·`sqrt(`), `+ -`·`- -`·`1x`가 없었다.
- 해설: 중간값(도함수 식·인수분해·평균변화율·극값)을 모두 다시 계산했고 오류가 없었다.
- 오개념 연결(객관식 8건): 연결된 선지가 그 오개념의 절차로 실제로 나오는지 확인했다(예: 지수 단계 누락 → 4^6, 7·4^7, x^2의 경우 a=5·a=50 / 임계점을 극값으로 단정 → 0 / 극값과 극점의 x좌표를 혼동 → 교점 0개). 정답 선지에 연결된 오개념은 없었다.
- 발문–검산 대조: 63건 모두 `verify`의 함수·수치·묻는 대상이 발문과 같은 문제를 가리켰다. 일부는 보조 미지수를 미리 대입했는데(b=-4, b=-9, n=2, n=8 등), 이는 발문 조건에서 나오는 값과 같았다.

## 검토했으나 결함으로 보지 않은 경계 사례 (기록용)

- 곱의 미분 진단 문항 2건(f(x)=(x-6)(x+1)과 f(x)=(x-1)(x-2)의 k): 해설이 "곱의 미분법에 따라 f'(x)는 2x-5(또는 2x-3)이므로"라고만 하고 곱의 법칙을 전개한 식은 적지 않는다. 다만 지침 5가 핵심 중간 단계로 드는 도함수 식은 적혀 있으므로 결함으로 보지 않았다.
- 평균값 정리 진단 문항(f(-3)=-79, f(2)=6, k=17): 답이 평균변화율 계산이지만, k를 그 값으로 정하는 근거가 평균값 정리의 결론 자체이며 발문이 평균변화율을 미리 알려 주지 않으므로 "미분 없이 풀림"으로 보지 않았다.
