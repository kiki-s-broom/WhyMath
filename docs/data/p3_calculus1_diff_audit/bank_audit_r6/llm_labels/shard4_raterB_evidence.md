# 판정 근거 — shard4 (판정자 B)

**결함 없음** — 판정한 건수 63건, 이 가운데 defect 0건.

## 판정 방법 (기록용)

- 63건 전부 발문만 보고 정답을 새로 풀었다. 손계산 뒤 SymPy로 다시 계산했고, 63건 모두 문항 정답과 같았다.
  - 극값·증감 문항은 f'(x)를 인수분해한 뒤 근 좌우의 부호를 판정했다.
  - 실근 개수 문항(교점·위치가 특정 값이 되는 시각)은 실근을 직접 세었다.
  - 평균값 정리·롤의 정리 문항은 열린구간에 속하는지 확인했다.
- 해의 유일성은 양수·0이 아님·열린구간·t ≥ 0 같은 조건으로 확인했다. 답 형식(자연수·분수·실수)과 정답 값이 맞는지도 확인했다.
- 객관식 9건은 오개념이 연결된 선지마다 그 오개념의 절차로 값을 다시 만들어 보았다. 모두 그 절차에서 나오는 값이었고, 정답 선지에 연결된 오개념은 없었다.
  - 거듭제곱 미분 단계 누락: 지수를 내리고 줄이지 않은 경로와, 줄이기만 하고 내리지 않은 경로를 둘 다 계산했다.
  - 곱의 미분 오류: f′·g′로 계산했다.
  - 임계점 극값 단정: f′=0인 점을 모두 극값으로 보았다.
- 발문 표기를 점검했다.
  - 수·변수·프라임 뒤 조사를 전수 대조했다(받침 규칙).
  - `+ -`·`1x`·`*`·`<=` 같은 깨진 표기와 코드 표기가 있는지 정규식으로 찾았다. 해당하는 것은 없었다.
- 해설은 도함수 식·세운 방정식·부호 판단이 있는지, 중간 값이 맞는지 보았다.
- `verify`의 조건식·정답 맵이 발문과 같은 함수·수치를 가리키는지 대조했다. 함수를 바꿔 쓴 인코딩도 발문과 같은 문제였다.
  - 두 시각의 속도 합: x(t)+x(t+3)으로 바꿔 썼다.
  - 실수배 문항: f, g를 일차함수로 대입했다.
  - cx^m 문항: x=2를 대입한 식으로 바꿔 썼다.
