## 경계 판단 메모 (결함으로 보지 않은 근거)

- 평균값 정리 진단형 2건(f(0)·f(3)만 주고 k를 묻는 문항): 계산은 평균변화율 하나지만, 그 값이 f′(c)와 같다는 것을 아는 일이 곧 평균값 정리라는 인지 행동이다. "평균값 정리에 의하여"라는 문구가 k를 하나로 정한다.
- f(x) = x의 f′(2) 진단형: 거듭제곱 미분의 n = 1 경우를 확인하는 문항이다. 흔한 오답 경로(f′(x) = x → 2, 상수 혼동 → 0)가 다른 값을 내므로 변별이 있다.
- 가속도가 상수인 문항(t = 5에서의 가속도): 두 번 미분하는 일이 필요하다. 한 번만 미분한 오답(16)은 다른 값이다.
- "모든 계수의 합": 국내 교육과정 관례대로 상수항을 포함해 해석했다(도함수 12x²+2x+9 → 23).
