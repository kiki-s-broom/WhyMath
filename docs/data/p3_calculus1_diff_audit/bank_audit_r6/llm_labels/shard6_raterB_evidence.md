## 검토했으나 결함으로 보지 않은 의심
- 도함수 계수합 문항(dy/dx의 모든 계수의 합 = 0): "지수를 1 줄이지 않음" 오류로 풀어도 계수합이 같다. 이 문항이 겨냥하는 합의 미분법 오류(상수항 미소거 → -7)는 구별되므로 결함으로 보지 않았다.
- 도함수 상수항 문항(f'(x)의 상수항 = -5): 일차항 계수만으로 답이 정해진다. 그래도 항별 미분 지식이 필요하고 상수항 미소거 오류(→ 0)는 구별되므로 결함으로 보지 않았다.
