## 판정 방법 (기록)

- 63건 전부 발문만 보고 손으로 새로 푼 뒤, SymPy로 다시 독립 계산해 `answer`와 대조했다(`solve_check.py`). 63건 모두 직접 푼 값과 문항 정답이 같았다.
- 해 유일성: 양수·구간·`t > 0`·"하나뿐이다"·"작은 값" 조건이 필요한 문항마다 그 조건으로 해가 하나로 정해지는지 확인했다(예: 접선이 원점을 지나는 문항은 a = 2, a = -4(중근) 가운데 양수 조건으로 2 하나). 답 형식(자연수·정수·분수·실수)과 정답 값도 전건 맞았다.
- 미분 없이 풀림: 실근 개수 문항 5건(방정식 4차·3차)은 유리수 범위에서 인수분해되지 않아(`factor` 결과 불변), 대입·인수분해만으로는 풀리지 않는다. 평균값 정리·극값·접선·속도 문항은 모두 도함수 또는 미분계수 계산이 필요하다. g(x) = f(x) + 2 문항은 상수의 도함수가 0이라는 성질 자체가 성취기준의 인지 행동이고, "상수의 도함수 = 그 상수" 오개념이면 2가 나와 변별된다.
- 오답 선지–오개념 연결 8문항: 연결된 선지 값을 오개념 설명의 절차로 직접 재현했다 — 롤의 정리 혼동(f'(c) = 0의 근 1/3, -1/3), 거듭제곱 미분 단계 누락(지수 내리기 누락 4·-36·224, 지수 줄이기 누락 154·-176·822), 극값·극점 혼동(0개), 임계점 극값 단정(x = 0). 정답 선지에 오개념이 연결된 문항은 없다.
- 문장 표기: 수·문자·괄호 뒤 조사의 받침 일치를 기계적으로 전수 검사해 불일치 0건이었다(`josa.py`). 코드 표기(`<=`·`*`·`sqrt(`), 부호 깨짐(`+ -`·`- -`·`1x`), 제로폭·비표준 공백도 0건이었다.
- 해설: 인수분해 결과·평균변화율·극값·대입값 등 중간 값을 전건 검산해 틀린 값이 없었다. 계산이 짧은 기본 문항도 도함수 식은 적혀 있었다.
- 발문–검산 일치: `verify`의 함수·수치는 발문과 같았다. 상수를 미리 대입한 축약형(예: k = -18을 넣은 속도식, y절편 조건식 -p - 2 = 0)과 `answer_selection`(smallest/largest)으로 근을 고른 형태는 같은 문제를 가리키므로 불일치로 보지 않았다.
