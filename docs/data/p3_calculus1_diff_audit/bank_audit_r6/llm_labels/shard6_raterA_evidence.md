## 결함

### 3294c5cf-877c-58e9-b8e7-0cc158342dc1
- **분류**: 미분 없이 풀림
- **확신도**: 불확실
- **근거**: 발문은 "수직선 위의 점 P의 시각 t에서의 위치가 x = t^2일 때, t = 2에서의 점 P의 가속도를 구하시오."이다. 직접 풀면 v(t) = 2t, a(t) = 2이므로 답은 2이고, 문항 값 2와 같다(정답 오류는 아님). 문제는 가속도가 상수라서 "t = 2"가 답을 정하는 데 아무 역할을 하지 않는다는 점이다. 그 결과 2계 미분을 쓰지 않는 여러 경로가 같은 값 2에 닿는다.
  - 물리의 등가속도 공식 x = (1/2)at^2에서 a = 2
  - '가속도 = 속도 ÷ 시간'이라는 소박한 이해: v(2)/2 = 4/2 = 2
  - 개념을 바꿔 쓴 오답 경로인 평균속도: (x(2) - x(0))/(2 - 0) = 2
  
  진단(diagnostic) 슬롯이 겨냥한 '속도와 가속도 혼동'(v(2) = 4)은 구별하지만, 'a = dv/dt'를 쓰는 학생과 위 경로를 쓰는 학생은 구별하지 못한다. 그래서 변별력이 약하다고 판단했다. 성취기준의 인지 행동(위치 → 속도 → 가속도 미분)을 거치지 않고 정답에 닿는 현실적 경로가 있다는 의심이며, 확신은 낮다.
