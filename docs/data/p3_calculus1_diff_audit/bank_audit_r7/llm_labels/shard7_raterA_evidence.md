## f832f55b-0c6e-5c88-97cd-c67635aae594
- 분류: 문장 표기
- 확신도: 불확실
- 근거: 발문은 "방정식 f'(x) = 0의 해 중에서 함수 f(x) = -3x^4 - 12x^3 + 5가 극값을 갖는 x좌표는?"이다. f'(x)를 f(x)가 정의되기 전에 먼저 쓴다(같은 문장 안에서 순서가 거꾸로임). "극값을 갖는 x좌표"도 "극값을 갖는 x의 값"이라고 써야 할 자리에 '좌표'를 쓴 어색한 표현이다. 수학 내용은 맞다. 직접 푼 값: f'(x) = -12x^2(x + 3)이고, x = -3에서 부호가 양에서 음으로 바뀌어 극대가 되며 x = 0에서는 부호가 바뀌지 않는다. 따라서 답은 -3이고 문항 값 -3과 같다. 표기·서술 순서만 문제 삼은 낮은 확신의 의심이다.
