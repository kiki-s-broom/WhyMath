# shard2 판정 근거 (판정자 A)

63건 전부 발문만 보고 SymPy(`check.py`)와 손계산으로 다시 풀었다. 63건 모두 정답 값이 문항의 `answer`와 같았다.
객관식 오답 선지와 오개념 연결(문항 8·25·39·52·61·62, 선지 번호는 0부터 센다)도 모두 그 오개념의 절차로 실제로 나오는 값이었다.
결함으로 표시한 2건은 정답 값은 맞지만 미분을 쓰지 않고도 풀린다는 의심 때문이다.

## a4f83881-b066-5179-acb9-1d8616927972
- 분류: 미분 없이 풀림
- 확신도: 불확실
- 근거: 발문 "함수 f는 닫힌구간 [0, 3]에서 연속이고 열린구간 (0, 3)에서 미분가능하며 f(0) = 1, f(3) = 88이다. 평균값 정리에 의하여 f'(c) = k인 c가 이 열린구간에 존재할 때, k의 값을 구하시오." 직접 푼 값은 (88 − 1)/3 = 29이고 문항 값도 29로 같다. 그러나 함수식이 없어서 도함수를 구하거나 미분계수를 계산할 일이 없다. 주어진 두 함숫값을 넣어 평균변화율을 내기만 하면 끝난다(대입만으로 끝남). 평균값 정리의 결론이 무엇인지 기억하는지만 묻고, f'(c) = k를 실제로 풀어 쓰는 단계가 없다. 진단 문항이라 의도한 설계일 수 있어 불확실로 둔다.

## 846b97d1-54d0-5b77-bc18-f5aa033bab4f
- 분류: 미분 없이 풀림
- 확신도: 불확실
- 근거: 발문 "함수 f는 닫힌구간 [0, 3]에서 연속이고 열린구간 (0, 3)에서 미분가능하며 f(0) = 1, f(3) = 97이다. 평균값 정리에 의하여 f'(c) = k인 c가 이 열린구간에 존재할 때, k의 값을 구하시오." 직접 푼 값은 (97 − 1)/3 = 32이고 문항 값도 32로 같다. 위 문항과 같은 틀이다. 함수식 없이 두 함숫값의 평균변화율만 계산하면 답이 나오므로 미분 계산이 전혀 필요 없다. 진단 문항 설계일 수 있어 불확실로 둔다.
