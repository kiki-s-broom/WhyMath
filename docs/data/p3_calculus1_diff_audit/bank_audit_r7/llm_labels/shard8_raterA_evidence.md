# shard8 판정 근거 (판정자 A)

판정 63건 · defect 2건. 63건 모두 발문만으로 SymPy(`check.py`)와 손계산으로 다시 풀었고, 문항 정답과 모두 일치했다. 오개념 선지 연결(4·7·9·12·14·35·53·60번째 문항)도 각 오개념 절차로 실제로 나오는 값임을 확인했다. 아래 2건은 해설만 문제 삼는다.

## 2e2868aa-4295-58dc-b0e4-5581ccd3abdc
- 분류: 해설
- 확신도: 불확실
- 근거: 발문 "함수 f(x) = (x - 6)(x + 1)의 도함수가 f'(x) = 2x + k일 때, 상수 k의 값을 구하시오." 직접 푼 값: f'(x) = (x + 1) + (x - 6) = 2x - 5이므로 k = -5이고, 문항 값 -5와 같다. 정답은 맞다.
  해설 전문은 "곱의 미분법에 따라 f'(x)는 2x - 5이므로 k는 -5이다."뿐이다. 이 문항은 도함수를 구하는 것 자체가 풀이의 전부인데, 곱의 미분법을 실제로 적용한 식(1·(x + 1) + (x - 6)·1)이 없어 결론만 남았다. 같은 성취기준의 문항 9e8337d1(곱의 미분법)은 이 식을 전개해 보여 준다. 핵심 중간 단계가 빠진 것으로 보지만, 결과인 도함수 식은 적혀 있으므로 확신은 낮다.

## 4882cd3f-48f8-5777-847a-fe2361bf68d3
- 분류: 해설
- 확신도: 불확실
- 근거: 발문 "함수 f(x) = (x - 1)(x - 2)의 도함수가 f'(x) = 2x + k일 때, 상수 k의 값을 구하시오." 직접 푼 값: f'(x) = (x - 2) + (x - 1) = 2x - 3이므로 k = -3이고, 문항 값 -3과 같다. 정답은 맞다.
  해설은 "곱의 미분법에 따라 f'(x)는 2x - 3이므로 k는 -3이다."뿐이다. 곱의 미분법을 적용한 중간식이 없이 결론만 적혀 있다. 판단 근거와 확신이 낮은 이유는 위 문항과 같다.
