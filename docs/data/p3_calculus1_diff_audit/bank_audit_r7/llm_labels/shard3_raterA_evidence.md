# shard3 판정 근거 (판정자 A)

- 판정 문항: 63건 / defect: 0건
- 방법: 63문항 모두 발문만 보고 손계산으로 새로 풀었다. 그중 계산이 긴 27문항(평균값 정리, 극값, 최솟값, 실근 개수, 접선, 미정계수)은 SymPy로 따로 다시 풀었다(`check.py`). 계산값은 모두 `answer` 및 객관식 정답 선지와 일치했다.
- 객관식 9문항의 오개념 연결 선지는 설명에 적힌 잘못된 절차로 다시 계산했고, 모두 그 값이 나왔다(예: 4번 −30·−7, 25번 16384·524288, 11번 4√3, 43번 5√3, 12번 −2/3, 3번 9, 28번 −6, 20번 0).
- `verify`의 조건식·정답 맵이 발문과 같은 함수·수치·대상을 가리키는지 대조했고, 불일치는 없었다.
- 문장·표기 검사: 조사 중복, `+ -`·`- -`·`1x`·`1*`, `<=`·`>=`·`*`·`sqrt(`, 비정상 문자를 자동으로 찾아본 결과 해당 사항이 없었다(`scan.py`). 수·변수 뒤 조사는 직접 읽어 확인했다.
