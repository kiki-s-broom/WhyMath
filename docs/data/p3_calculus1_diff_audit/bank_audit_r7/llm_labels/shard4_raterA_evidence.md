# shard4 판정 근거 (판정자 A)

- 판정 문항 63건, defect 0건.
- 결함으로 판정한 문항이 없으므로 결함별 근거 항목은 없다.

## 판정 방법 (기록용)

- 발문만 보고 63건 전부를 SymPy(`solve.py`)와 손계산으로 다시 풀었다. 모든 문항에서 직접 푼 값이 `answer`와 같았다.
- 유일성 조건(양수·0이 아닌 수·열린구간·x좌표가 양수인 점 등)을 확인했다. 해가 둘 이상 남는 문항은 없었다.
  예: #13·#56 c = -3, 5/3 → (0, 3)에 드는 값은 5/3, #43 c = -5, -1/3 → (-2, 1)에 드는 값은 -1/3, #23 a = -3, 2 → 양수 a = 2.
- 근의 개수 문항은 실근을 직접 셌다: #37은 2개, #41은 1개, #54는 1개로 문항 값과 같았다.
- 객관식의 오개념 연결 선지를 해당 절차로 다시 계산했다. 9개 문항에서 모두 그 값이 나왔다.
  예: #1 x²−1→8, 3x³−x→78, #9 2⁷=128, 8·2⁸=2048, #28 4와 584, #6·#49·#50 f′·g′ 값 −8·−8·−24, #8 임계점 0.
- 발문·해설에서 조사, 부호 표기, 코드 표기(`*`, `<=`, `sqrt(`), 중간 계산을 확인했다. 결함은 찾지 못했다.
- `verify`의 조건식과 정답 맵이 발문과 같은 문제를 가리키는지 확인했다. 불일치는 없었다.
