# shard6 판정 근거 (calc_shard6_A)

판정 건수 63, defect 0건.

## 결함 문항

없음. 63건 모두 발문만 보고 직접 다시 풀었고(손계산과 SymPy `check.py`), 직접 구한 값이 문항의 정답과 모두 같았다.

## 확인한 범위 (기록용)

- 정답: 63건 모두 직접 푼 값과 `answer`가 같다. 실근·교점 개수 문항 9건(1, 4, 5, 22, 30, 31, 37, 41, 53번째 줄)은 `real_roots`로 개수를 다시 셌다. 극값·최솟값 문항(13, 36, 38번째 줄 등)은 임계점과 함숫값을 다시 계산했다.
- 유일성: 평균값 정리 문항과 속도 문항은 구간·`t > 0` 조건으로 근을 하나로 좁힌다. 극값 문항은 "작은 값 / 큰 값" 조건으로 근을 하나로 좁힌다.
- 오개념 연결: 객관식에서 연결된 선지마다 적힌 잘못된 절차로 다시 계산했다. 계수 누락이나 지수 미감소로 16, 160, 72, 6, 15625, 546875, 1, 3, 0, 120이 나온다. 롤의 정리 혼동으로 1, 1, -2/3가 나온다. 극점 x좌표를 극값으로 쓰면 0개가 나온다. 임계점을 극값으로 단정하면 0이 나온다. 곱의 미분 오류로 -64가 나온다. 모두 실제로 해당 선지 값이 나오며, 정답 선지에 연결된 오개념은 없다.
- 해설: 중간 식(도함수, 인수분해, 평균변화율 수치, 부호 판단)을 모두 다시 계산했고 틀린 곳이 없다.
- 표기·조사: 수·변수 뒤 조사(예: "-2/3는", "11/3은", "22를", "-19를")를 점검했고 오류가 없다.
