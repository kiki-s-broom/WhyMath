## 왜 이 단계가 먼저인가

은행은 측정되지 않은 LLM 감사 4회에 불합격했고(`../README.md` 회차 요약), 사람 표본 검수 경로는 시작 전에
철회됐다(2026-10-08). 두 경로의 공통 결함은 같다 — **감사자 자신의 검출률·오경보율을 잰 적이 없는 채로** 그
판정을 승인 근거로 쓰려 했다(4회차 κ 0.412). 그래서 순서를 바꾼다: 정답을 아는 결함을 은행 사본에 심은
시험지로 **감사자를 먼저 시험**하고, 측정을 통과한 감사 프로토콜의 판정만 은행 S5 근거로 쓴다.

◆ = GT를 확정한 규칙과 **같거나 겹치는 규칙**을 쓰는 기계 게이트가 있는 변이(정답지 `gate_overlap`). 그 변이의
기계 검출은 구성상 보장되거나 그에 가깝다 — 아래 "순환" 절.

생성 시 단언(`GroundTruthError`): 결함마다 ① 변조가 실제로 적용됐는지(`변조본 ≠ 원본`) ② GT가 성립하는지
③ **의도하지 않은 기계 소견을 만들지 않았는지**(예: 점을 바꾸다 'f'(-1)를'처럼 조사를 틀리게 만들면 기계가
엉뚱한 이유로 '검출'한다 — 점은 받침이 같은 수로만 옮긴다)를 선택 뒤 다시 확인한다.

블라인드 처리: 문항 id는 `q001…q240`로 재부여하고 순서는 seed로 섞는다. 은행 `problem_id`·`slug`는 싣지
않는다. ③의 단서는 은행 발문의 관례 꼴 `(단, …)`로 붙인다(은행에 없는 꼴은 그 자체가 결함 표지가 된다).
오답 선지에는 판정자가 연결을 판단할 수 있게 오개념 설명(`misconception_statement`)을 싣는다.

발문에 `f(x) = …` 정의가 없어 판정기 E-derivative가 적용되지 않은 문항이다. 이 수치가 프로토콜에 LLM 이중
판정이 필요한 이유이고, 동시에 **LLM 판정자의 검출률이 ◆ 아닌 변이에서 어떻게 나오는지가 측정의 핵심**이다.

## LLM 판정자 요건 (프로토콜의 일부 — 어기면 측정이 무효)

- 판정자는 **`blind_240.jsonl`의 내용만** 받는다. 저장소·은행·코드·기계 라벨·이 README의 결함 종류 표에 접근하지
  않는다(은행과 대조하면 원본을 찾고, 코드를 돌리면 정답지를 재생성할 수 있다).
- 판정자 2명 이상은 서로의 라벨을 보지 않는다(독립).
- 판정 지침은 **자격 측정과 은행 감사에서 같아야 한다** — 다르면 측정한 검출률이 은행 감사로 옮겨 가지 않는다.
  지침은 판정 시작 전에 이 디렉터리에 사전 등록한다(미작성 — 후속).
- 라벨 형식: 판정자별 JSONL 1개, 줄마다 `{"item_id", "verdict": "ok"|"defect", "defect_class"}`. 240건 전부·중복 없이.
  `defect_class`는 판정자의 어휘(기록용 — 채점은 `verdict`만 본다).

### S5 보정 — 근거

감사 프로토콜이 결함 문항 하나를 잡을 확률을 d, 은행의 실제 결함률을 p라 하자. 504건 감사에서 관측되는 결함
판정 수 k는 결함을 잡은 수(기대 504·p·d)에 오경보를 더한 것이다. 오경보는 k를 키우기만 하므로 무시해도 p를
과소평가하지 않는다(보수 쪽). 그러면

- U = Wilson 95% 단측 상한(k, 504)은 p·d의 상한이다.
- 자격 측정이 d ≥ L(검출률 Wilson 95% 단측 하한)을 보증한다.
- 따라서 p ≤ U / L. 이 값이 0.02 이하면 은행 결함률 상한 2%(초인간 검증 S5)를 만족한다.

**합성 신뢰도는 95%가 아니라 90% 이상이다.** 두 단측 95% 경계를 함께 쓰므로 Bonferroni로 1 − 0.05 − 0.05다.
CLI 출력에도 그렇게 적는다.

**가정과 한계(정직 표기).**

1. *이전 가능성* — 주입 결함에서 잰 검출률이 은행의 자연 결함에도 성립한다고 가정한다. 7종은 1~4회차 감사에서
   실제로 나온 결함 부류에서 골랐지만, 주입 꼴(예: `(단, …)` 단서)이 자연 결함보다 쉽거나 어려울 수 있다.
2. *종류 혼합* — L은 전체 검출률 하한이다. 자연 결함이 검출이 약한 종류에 몰려 있으면 실제 d는 L보다 작다.
   종류별 점추정 ≥ 0.80 기준이 최악을 제한하지만(그 경우 보정 상한은 U / 0.80 수준까지 커질 수 있다) 제거하지는 않는다.
3. *상상 못 한 결함* — 7종 밖의 결함은 이 측정이 보증하지 않는다(초인간 검증 §3.2 ④와 같은 한계).
4. *as-found* — 은행 감사에서 결함을 찾아 교정한 뒤 같은 504건을 다시 채점해 FAIL을 PASS로 바꾸지 않는다
   (초인간 검증 §4.5). 교정 후 재판정은 새 측정으로 한다.
5. *정상 문항의 GT* — 정상 120건의 정답지는 "은행 그대로"이지 "결함 없음이 증명됨"이 아니다. 판정자가 정상 문항을
   결함으로 보면 오경보로 세지만, 그중 일부는 은행의 실제 잔여 결함일 수 있다. 채점 뒤 라벨을 고쳐 오경보를 줄이는
   것은 금지다(사후 재라벨 = 재채점). 다툼이 있으면 그 문항을 기록하고 새 시험지로 다시 잰다.
