# Kiki PC(Phaiakes9) 실행 표준 — 저작·검수·측정 런북 공통 실행 규약 색인 (EOS-221)

> **판정 기준: main `57d05c55`**(이 문서를 쓴 시점). 이 문서는 **새 규칙을 만들지 않는다**(EOS-221 ②) — 저작·검수·
> 측정 런북이 Kiki PC에서 공통으로 지키는 규약을 한곳에 모은 **색인**이다. 각 행의 정본은 오른쪽 「출처」 칸이며,
> 출처와 이 문서가 다르게 읽히면 **출처가 맞다**(CLAUDE.md는 코딩 헌법 아래 정본 · 이 문서는 그 아래). 출처가 바뀌면
> 이 색인을 고친다 — 이 문서를 고쳐서 규칙을 바꾸지 않는다.
>
> **쓰는 법**: Kiki PC용 런북을 새로 쓰거나 Kiki에게 명령 블록을 줄 때, 아래 표를 위에서부터 훑어 해당 행을 지켰는지
> 본다. 블록 자체의 기계 검사는 `scripts/ops/check_runbook_blocks.py`(런북 `docs/ops/*runbook*.md` 전수 · CI
> `infra-contracts` 잡)가 한다 — 그 검사가 보는 축은 표의 「기계 검사」 칸에 적었다. 검사가 보지 않는 행은 사람 규율이다.
