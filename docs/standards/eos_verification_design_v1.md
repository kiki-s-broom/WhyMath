## §3. 측정 단위 CU(콘텐츠 단위) — 정의와 스키마 좌석

**CU = 문제 지문 + 정답 + 단계별 풀이 + 3단계 힌트 + concept/skill 매핑 + 난이도 +
예상 오답 3개(op-code 라벨) + 성취기준 코드.** 문항 수만 세면 CU가 아니다.

**스키마 판단(동결)**: CU는 **기존 스키마 조합으로 표현한다 — 신설 스키마 금지**(이중 진실
원천·과공학 방지). 좌석 대응과 그 동결 테스트 = `tests/backend/schema/test_generation_failure_code.py`
`TestContentUnitSeatContract`:

| CU 구성요소 | 좌석 (실측) | 상태 |
|---|---|---|
| 문제·정답 | `schema/problem.py` Problem 본문·정답류 필드 | ✅ |
| 단계별 풀이 | `SolutionPath`/`SolutionStep`(S4-09 착지)·인접 단계 동치 검증 `l3/verify_step.py` | ✅ |
| 3단계 힌트 영속 | **미착지 — `S4-11`(todo)이 좌석** (graded 1~3·정답 누출 게이트) | ⚠ 유일 공백 |
| concept/skill 매핑 | 원자 백본·crosswalk·`achievement_standard_codes` | ✅ |
| 난이도 | `difficulty_overall`(저작) + IRT 축(실측 보정) — authored/empirical 분리 | ✅ |
| 예상 오답+op-code | `distractor_map` + `DistractorEntry.op_code`(kebab 10종 체계) | ✅ |
| 성취기준 코드 | `achievement_standard_codes`(2022 개정) | ✅ |

**CU 완결(published) 판정**은 콘텐츠 DoD(선언 정본 §0-6 불변 계약·N1)를 따른다 — 판정
파이프라인의 집행은 `EOS-50`(publish gate)·`ARCH-23`(QA CI 강제) 몫(정본화≠집행).

## §5. 실패의 사전 정의 F-Ⅰ~F-Ⅴ — 동결·12월 수정 금지

하나라도 해당하면 **AI-first 콘텐츠 전략 실패**로 판정한다. No-Go는 프로젝트 중단이 아니라
전략 변경(AI 보조 저작 도구 전환 또는 외부 라이선싱+오케스트레이션)이다.

- **F-Ⅰ**: 중등 기준선 앵커(A3·A4)에서조차 HIT 중앙값 > **12분/CU**
- **F-Ⅱ**: 인간 검수를 통과한 CU의 수학적 오류율 > **2%**
- **F-Ⅲ**: 실패 분포에서 판단형(F3+F6+F7) 합 > **60%** (자동화로 흡수 불가한 실패가 지배)
- **F-Ⅳ**: 앵커 **6개 중 3개 이상** 기준 미달 (2개면 Conditional Go) — 원안 "8개 중 4개"를
  6앵커 체제로 비례 환산(50% 선 유지·2026-08-30 확정)
- **F-Ⅴ**: 힌트의 의미적 정답 누설(자동 검사 밖)이 표본 검수에서 ≥ **10%**

**판정 체계(12/27 동결 → 12/31 판정)**: Go = 주 기준 충족(HIT 중앙값 ≤4분) + 깊이앵커
폐쇄루프 완결 + 학교급 3개 중 2개 이상 품질 기준 충족 / Conditional Go = 학교급 일부만 성립
→ 출시 범위 축소 확정 / No-Go = F-Ⅰ~Ⅴ 중 1+ 해당.

## §6. KPI — 지표 정의·측정 방법(동결) · 목표값(G2 재조정 가능)

**기술 KPI 6종**:

| 지표 | 목표값 | 측정 방법 (동결) |
|---|---|---|
| HIT (CU당 인간 개입 시간) | 중앙값 ≤4분 · P90 ≤8분 | 검수 타이머 이벤트(시작·종료·중단 — `EOS-54`) 전수 자동 수집 |
| 자동검증 1차 통과율 | ≥85% | Deterministic Gate pass ÷ 전체 생성 (수용 게이트 로그) |
| 재작업률 | ≤15% (2회+ 재생성 ≤3%) | Run 로그 재생성 카운트(`EOS-55`) |
| 처리량 | ≥30 CU/h (인간 기준) | 검수 완료 CU ÷ 검수 소요 시간 |
| 단위 비용 | ≤250원/CU (상한 400원) | 토큰 로그 × 단가 + 로컬 전력비 환산(`GenerationLog.cost_usd`·`ops/cost_probe` 이중 회계) |
| 실패 유형 분포 | 기계형(F1+F2) ≥60% | F1~F8 집계 — **가장 중요한 예측 지표**(F-Ⅲ의 역) |

**내용 KPI 6종**: 수학적 오류율 ≤0.5%(SymPy 전수+독립 모델 심판 전수+층화 인간 검수 앵커당
25 CU) · 교육과정 정합률 ≥92%(앵커당 20 CU 블라인드 역매핑) · 난이도 타당도(깊이 Spearman
ρ≥0.5·폭은 전문가 순위 ρ≥0.6 — 12/31까지 완전 검증 불가 유일 항목·보고서에 "미검증" 명시) ·
오개념 연결(op-code 라벨 정확도 ≥85%·실오답 매칭 ≥40%) · 풀이 비약 지적률 ≤10%(3점 루브릭
앵커당 20 CU·LLM 심판 κ≥0.5일 때만 전수 확장) · 힌트 누설률 L1·L2 **0%**(무관용 — 전수 자동
+LLM 심판+인간 30건).

**판정 형식(불변)**: 모든 KPI·게이트 판정은 검증 권위 서열
(`docs/standards/superhuman_verification_standard.md`)대로 **CLI exit 0/1(Wilson 단측
경계)** — 점추정·인상 판정 금지. 주간 7지표의 집계 배선은 `OPS-56`(이 문서 §6이 인용원).

## §7. 한계 명기 (정직 — acceptance ④)

1. **목표값은 실측 벤치마크가 아니다** — HIT 4분·자동검증 85%·오류율 0.5%는 산술 손익분기
   (주 8h×20주=9,600분 콘텐츠 예산 가정)와 통상 기준의 도출값이다. **G2(10/25) 기준선
   실측에서 목표값 재조정이 정상 경로**다(지표 정의는 불변).
2. **손익분기 산식의 물량 가정은 재검산 대상** — 원안 "545노드×4문항≈2,180 CU"의 노드 수는
   실측과 다르다(원자 리프 1,823 — EOS-52 §2). 최소 출시 물량은 2027 출시 범위 결정(학교급)
   에 종속되므로, **G5 판정 시 통과 학교급 기준으로 재산출**해 4분/CU 선의 타당성을 함께
   보고한다.
3. **표본 설계의 검출력 한계** — 검수 185 CU(층화: 자동검증 실패분 전수+통과분 무작위)는
   "치명적으로 나쁨"(오류율 8%+)을 높은 확률로 잡지만 0.5% 수준의 정밀 추정은 못 한다 —
   보고서에 이 한계를 명기해야 판정이 정직하다.
4. **폭 앵커 난이도 타당도는 12월 내 미검증** — 학생 반응은 깊이앵커(A4)만 수집(I3).
