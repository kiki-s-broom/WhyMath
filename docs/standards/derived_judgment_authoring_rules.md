## 0. 용어 풀이 (초보자용)

| 용어 | 뜻 |
|---|---|
| **파생 판정 문항** | 그래프 개형을 그림으로 고르게 하는 대신, 개형에서 나오는 값(증감 경계·극값의 x좌표·극값의 값)을 묻는 문항 |
| **위장(SHAM)** | 정답도 오답도 통과하는 형태 — 검증기가 둘을 못 가른다. "검증됨"이라 부를 수 없다 |
| **정답 오거부** | 맞는 답이 오히려 fail로 나오는 형태 |
| **`answer_selection`** | "작은 근/큰 근 중 어느 쪽인가"를 검증기에 알려 주는 저작 필드(`smallest`/`largest`) |
| **x 고정** | 문항 본문이 극값의 x좌표를 상수로 못 박는 것 — "x=2에서의 극솟값" |

## 1. 규칙 5종

| 규칙 | 대상 문항 | 요구(위반하면 적재 거부) | 왜 |
|---|---|---|---|
| **B3** | 극대·극소의 **x좌표**를 구별해 묻는다("극댓값을 갖는 x좌표") | `verify.answer_selection`이 `smallest`/`largest`로 있다 | 극대점과 극소점 모두 f'=0의 근이라 selection이 없으면 극소점을 극대점이라 답해도 통과한다(프로브 B3 위장) |
| **C3** | 극값의 **값·점**을 묻는다("x=2에서의 극솟값" · 점 (x, f(x))) | 본문에 극값 x좌표를 고정(`x=2`)하고 `verify.answer_map`에 `x`가 있다 | 점을 답으로 받으면 곡선 위 임의의 점이 통과한다(프로브 C3 위장). x 없이 값만 받으면 정답도 fail이다(C4) — x 고정이 둘 다의 해법이다 |
| **A4 제외** | 증감 구간을 **구간 기호**로 답하게 한다 | (허용하지 않음) | 검증 재료를 만들 방법이 없다(불가) |
| **A3 제외** | **경계 포함 여부**를 묻는다("닫힌 구간"·"경계 포함"·답이 `x ≥ 2`) | (허용하지 않음) | 엄격 부등식의 경계점은 검증기가 skip해 오답이 걸러지지 않는다 |
| **A5 제외** | 구간을 **함수식 단독 조건**으로 검산한다(`verify.conditions`에 등호·부등호 없음) | 조건은 관계식이다 | 정답도 fail로 나와 오염으로 위장된다 |

## 2. 허용되는 7형태 (프로브 '가능')

| 형태 | 문항 예(`f(x) = x³ − 3x² + 2`) | verify 요지 |
|---|---|---|
| A1 증감 경계점 | "증가·감소가 바뀌는 점의 x좌표 중 큰 값" | `f'(x)=0` · `answer_map x` |
| A2 증가 구간 소속 정수 | "증가하는 구간에 속하는 정수 하나" | `f'(x) > 0` |
| A2d 감소 구간 소속 정수 | "감소하는 구간에 속하는 정수 하나" | `f'(x) < 0` |
| B1 극값 x좌표 중 큰 값 | "극값을 갖는 x좌표 중 큰 값" (극대·극소를 구별하지 않음) | `f'(x)=0` |
| B2 극댓값의 x좌표 | "극댓값을 갖는 x좌표" | `f'(x)=0` + **`answer_selection=smallest`** |
| C1 x 고정 극솟값 | "x=2에서의 극솟값" | `y = f(x)` · `answer_map {x, y}` |
| C2 같은 문항 | 부호 뒤바꿈 오답까지 거름 | 위와 같음 |

## 3. 단서 — 이 규칙이 보증하지 **않는** 것 (acceptance ⑥)

1. **B2의 `answer_selection`은 작성자가 사전 계산한 조건이다.** 검증기가 극대·극소를 판별한 것이 아니다. 이 모듈은 selection의 **존재**만 강제하고 **옳음**은 보지 못한다. 최고차항 계수가 음수인 삼차함수에서 같은 방식으로 `smallest`를 달면 극대·극소가 뒤바뀌어 **정답을 오답으로 만든다**(추론 — 프로브는 계수가 양수인 함수 하나만 시험했다). 저작자는 selection을 달 때 극대가 작은 근인지 큰 근인지 직접 확인한다.
2. **C2는 x가 묶여 있는 동안만 가능하다.** 극값의 값을 안전하게 검증하려면 극값 x좌표를 문항에 고정해야 한다 — 그래서 규칙 C3이 x 고정을 요구한다.
3. **A1·B1은 같은 검증이다**(`f'(x)=0`의 근인가). 증감 구간이라는 종류가 새로 가능해진 것이 아니라 극값 x좌표 검증의 재사용이다.
4. **A2·A2d는 점 하나만 본다.** 학생이 구간 일부만 답해도 통과한다 — **증감 구간 전체를 맞혔는가는 기계가 보증하지 못한다**(분모 7을 유지하는 대가).
5. **프로브는 형태마다 오답 1개뿐이다.** "가능"은 "이 형태·이 오답은 가려낸다"이지 종류 전체의 증명이 아니다.

## 4. 한계 — 규칙이 잡지 못하는 것 (정직 표기)

이 규칙은 문항 **본문 문자열**과 `verify` 구조를 보는 휴리스틱이다. 다음은 잡지 못한다(이름 짓는 방식만 바꿔도 통과할 수 있다):

- 본문이 "극값"을 직접 말하지 않고 "함수의 가장 높은 지점의 x좌표" 같은 **우회 표현**으로 극대를 묻는 문항(B3 우회) — 키워드(`극대`·`극소`·`극댓값`·`극솟값`)가 본문에 없으면 B3 대상으로 읽히지 않는다.
- x 고정을 `x=2`가 아닌 다른 표기(`x가 2일 때`)로 쓴 문항 — 규칙 C3이 **오탐**(거부)한다. 저작자는 `x=2`로 쓴다.
- 구간 기호가 아닌 말로 구간을 답하게 하는 문항("0 이상 2 이하")은 A4로 읽히지 않는다.
- `answer_selection`의 **옳음**(§3-1).

잡지 못하는 표현이 코퍼스에서 발견되면 이 절에 사례를 추가하고 `derived_form_rules.py` 패턴을 넓힌다(코드와 문서를 함께 고친다).

## 5. 이 규칙의 범위

`achievement_standard_codes`에 `[12미적Ⅰ-02-08]`이 있는 문항만 대상이다. 그 밖의 문항은 영향받지 않는다. 문항 형태를 허용하는 **결정**은 게이트(Kiki)의 몫이고 이 문서는 그 결정의 집행 사양이다 — 허용 형태를 바꾸려면 게이트 판정을 먼저 다시 받는다.
