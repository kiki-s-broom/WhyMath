# 저작권 그라데이션 — WhyMath

> **출처**: MathScope PRD v1.1 §13.2(저작권 그라데이션)를 WhyMath 골격에 통합. PRD의 "MathScope" 표기는 "WhyMath"로 치환.
>
> ⚠️ **법률 단정 금지**: 이 문서는 *데이터·콘텐츠 활용 시 위험 등급을 분류한 운영 기준*이며 법률 자문이 아니다. "페어유즈(공정이용)에 해당한다"는 식의 *단정은 하지 않는다*. 각 등급의 경계, 특히 *교과서 학습목표·기출 문제의 활용 한계*는 **변호사 자문을 거쳐 확정**한다.
>
> **자매 문서**: `docs/data/licensing_safety.md`는 자원별 라이선스 매트릭스·결정 트리의 *정본*이다. 이 문서는 그것을 *4단계 위험 그라데이션*으로 재조직하고, *교과서 매핑 자산의 저작권 정책*을 명시한다. 자원별 가부 판정은 `licensing_safety.md`를 따른다.

---

## 1. 왜 "그라데이션"인가

저작권은 ⭕/❌ 이분법이 아니다. *공공 도메인부터 명백한 침해까지* 연속적인 위험 스펙트럼이 있고, WhyMath는 **데이터·콘텐츠를 위험 등급에 따라 다르게 취급**한다.

CLAUDE.md 의사결정 우선순위 2번(법적·윤리적 준수)에 따라, **위험 등급이 높을수록 보수적으로** 처리한다. "아마 괜찮을 것"이라는 낙관(`risks.md` 함정 6)을 *제도적으로 차단*하는 것이 이 문서의 목적이다.

```
[등급 1] 공공·합법          → 자유 활용 (출처 표시)
[등급 2] CC BY-SA           → 활용 가능하나 Share-Alike 의무 → 자체 풀과 분리 관리
[등급 3] 라이선스 협상 필요   → 협상 타결 전 사용 금지
[등급 4] 위험 영역           → 절대 금지 (CLAUDE.md 절대 금기)
        낮은 위험 ←──────────────────→ 높은 위험
```

---

## 2. 4단계 그라데이션 (PRD §13.2)

### 등급 1 — 공공·합법 (자유 활용)

**성격**: 공공 도메인, 정부 공개 자원, 상업적 활용·가공이 명시적으로 허용된 라이선스.

| 대표 자원 | 라이선스 | 비고 |
|---|---|---|
| NCIC 성취기준 | 공공누리 1유형 | WhyMath의 truth source(MEMORY.md 2026-05-13 결정 로그) |
| 학교알리미 | 공공 | PII 처리 주의 |
| OpenStax | CC BY 4.0 | 상업·가공 자유 |
| Siyavula | CC BY (**명시 표기 자료 한정**) | 사이트 기본값은 closed copyright — CC 표기가 붙은 자료만 · 귀속 문구 지정(`From siyavula.com` 등) |
| Illustrative Math | 초판 2019–2021=CC BY 4.0 · **v.360(2024·2025)=CC BY-NC** | **v.360은 상업 금지** — 상용 서비스인 우리는 초판만 · 귀속 3조건(저자·라이선스 링크·변경 표시) |
| NuminaMath-CoT · OmniMath · OlymMATH | Apache 2.0 / 공개 | LLM 학습 데이터 |
| miniF2F · Mathlib4 | 둘 다 **Apache 2.0**(miniF2F는 폴더별 상이 — 우리가 쓰는 `lean`이 Apache 2.0) | Lean 형식화 |

**처리 원칙**: 자유롭게 활용하되 **출처 표시 의무는 반드시 이행**(`licensing_safety.md` 출처 표시 표준 — 인앱 표시 + 내부 로그).

### 등급 2 — CC BY-SA (Share-Alike 의무, 자체 풀과 분리 관리)

**성격**: 활용·가공·상업적 사용은 가능하나, **2차 저작물도 같은 라이선스로 공개해야 하는 Share-Alike(동일조건변경허락) 의무**가 따르는 자원.

| 대표 자원 | 라이선스 |
|---|---|
| LibreTexts | CC BY-SA |
| AoPS Wiki | CC BY-SA |

**핵심 처리 원칙 — 자체 풀과 *분리 관리***:

- CC BY-SA 자원에서 파생한 콘텐츠는 **WhyMath 자체 제작 콘텐츠 풀과 물리적·논리적으로 분리**해 관리한다.
- 이유: Share-Alike 의무가 *섞이면* WhyMath 자체 콘텐츠까지 CC BY-SA 공개 의무에 *전염*될 위험이 있다. 분리 관리는 이 전염을 차단하는 방어선이다.
- 콘텐츠 메타데이터에 `license: CC-BY-SA` 및 `pool: external-sharealike` 태그를 *반드시* 부여. 자체 풀은 `pool: whymath-original`.
- CC BY-SA 풀 콘텐츠를 학생에게 노출할 때는 라이선스·출처를 명시(`licensing_safety.md` 인앱 표시).
- **변호사 자문 필수**: "분리 관리"가 Share-Alike 전염을 *법적으로 충분히 차단하는지*, 어느 수준의 결합이 2차 저작물 판정을 유발하는지는 전문가 검토로 확정.

### 등급 3 — 라이선스 협상 필요 (협상 타결 전 사용 금지)

**성격**: 자원 자체는 가치 있으나, 상업적 활용·가공을 위해서는 *권리자와의 별도 라이선스 협상*이 필요한 자원. **협상이 타결되기 전에는 사용하지 않는 것이 기본값.**

| 대표 자원 | 현재 상태 | 비고 |
|---|---|---|
| NRICH (Cambridge MMP) | 비상업 무료 / 상업 라이선스 협상 필요 | `partnerships.md` 3순위, Phase 3+ |
| EBS (본문·교재) | 메타데이터(단원·차시명)만 사용 가능 / 본문은 협상 영역 | `licensing_safety.md` 회색 영역 |
| CK-12 | CC BY-NC (비상업) — 상업 활용은 협상 필요 | 비상업 한정 |
| Khan Academy | CC BY-NC-SA (비상업) | 비상업 한정 |
| AoPS Korea | 한국 진출 협력 형태 | Phase 4+ |
| 검정교과서 출판사 (매핑 공식 제휴) | B2B 영업 시 협상 | 아래 §3 참조 |

**처리 원칙**:
- 협상 *전*에는 `licensing_safety.md` 결정 트리에 따라 **"명시 X → 사용 안 함이 기본"** 원칙 적용.
- 협상은 `partnerships.md`의 순위·시점(대부분 Phase 3+, 사용자·매출 검증 후)을 따른다.
- 협상 타결 시 *계약 범위*를 콘텐츠 메타데이터에 기록하고, 계약 범위를 *벗어난 활용*은 금지.

### 등급 4 — 위험 영역 (절대 금지)

**성격**: CLAUDE.md 절대 금기에 해당하는 자원. *어떤 경우에도 데이터화·복제·활용하지 않는다.*

| 금지 대상 | 근거 |
|---|---|
| **검정 교과서 본문·예제·풀이** | CLAUDE.md 절대 금기 / `licensing_safety.md` 절대 금지 목록 1 |
| **EBS 영상 자막·교재 본문** | CLAUDE.md 절대 금기 / 절대 금지 목록 2 |
| **학원·인강 자료** (메가스터디·시대인재·콴다·이투스 등) | CLAUDE.md 절대 금기 / 절대 금지 목록 3 |
| **출판사 풀이집·문제은행 복제** | 절대 금지 목록 4 |
| 라이선스 *미명시* 자원의 무단 활용 | `licensing_safety.md` 결정 트리 — 명시 X는 사용 안 함 |
| 3Blue1Brown·Mathigon 등 *영감만* 표기 자원의 직접 사용 | `licensing_safety.md` — "영감만, 직접 사용 X" |

**처리 원칙**: 등급 4는 *협상 대상도 아니다*(검정교과서 본문 등). `.github/workflows/ci.yml`의 `policy-guard` job이 검정교과서 본문 인용 패턴을 *기계적으로 사전 차단*(MEMORY.md 2026-05-14 `main` 보호 결정 로그)하는 것과 같은 맥락 — 사람 실수에 의존하지 않는다.

## 3. 교과서 매핑 자산의 저작권 정책

WhyMath는 검정 교과서와 NCIC 성취기준·자체 콘텐츠를 연결하는 *교과서 매핑 자산*을 만든다(`docs/data/textbook_mapping.md`, PRD의 교과서 매핑 파이프라인). 이 자산의 저작권 처리가 *가장 민감*하므로 별도로 명시한다.

### 3.1 핵심 원칙 — **구조 메타데이터만**

> 교과서 매핑 자산은 교과서의 **구조 정보(메타데이터)만** 담는다. 교과서의 **본문·예제·풀이·이미지 등 표현물은 일절 담지 않는다.**

| 담아도 되는 것 (사실정보·구조 메타데이터) | 담으면 안 되는 것 (저작물·표현물) |
|---|---|
| 출판사명, 교과서명, 학년·과목 | 본문 문장, 설명 텍스트 |
| 단원명·목차 구조 (사실정보) | 예제 문제·풀이 |
| 단원 ↔ NCIC 성취기준 코드 매핑 | 삽화·그래프·표 이미지 |
| 단원 ↔ WhyMath 자체 콘텐츠 연결 | 연습문제 |
| 페이지 번호·차시 구분 (사실) | 교과서 특유의 *표현·구성·편집* |

- "이 교과서 3단원이 `[10공수1-02-03]` 성취기준을 다룬다"는 **사실정보·구조 메타데이터**이며, `licensing_safety.md`에서 "검정 교과서 목차 = 사실정보 = ✅ 단원명만"으로 분류된 범위 안.
- "이 교과서 3단원 본문에 이렇게 쓰여 있다" 또는 예제·풀이를 옮기는 것은 **등급 4(절대 금지)**.

### 3.2 경계가 모호한 사례 → 변호사 자문

- 단원명이 *그 자체로 창작적 표현*인 경우(예: 출판사 고유의 작명)와 *관용적 단원명*의 구분 → **변호사 자문 필수**.
- 목차의 *세부 구조·배열*이 어느 수준부터 "편집저작물"로 보호되는지 → **변호사 자문 필수**.
- 교과서 매핑 자산을 *B2B 라이선싱*(MEMORY.md 핵심 인사이트 3)할 때, 출판사 권리와의 관계 → **변호사 자문 필수**, 가급적 출판사와의 *공식 제휴*(`partnerships.md` 4순위) 경로로.

### 3.3 기출 문제(평가원) 처리

- 평가원 기출은 `licensing_safety.md`에서 "교육적 인용 / ⚠️ / 본문 재배포 금지"로 분류.
- WhyMath는 기출 *문항 본문을 재배포하지 않는다*. 기출과의 연결은 *메타데이터*(성취기준 코드·출제 연도·단원) 수준으로 한정.
- **변호사 자문 필수**: 기출 문제의 *교육적 인용* 한계, 학생에게 보여줄 수 있는 범위.

## 4. 운영 규칙

### 4.1 새 자원 도입 절차

```
새 데이터·콘텐츠 자원 검토
   ├─ 1. licensing_safety.md 결정 트리 적용 → 가부 1차 판정
   ├─ 2. 본 문서의 4단계 그라데이션 중 어디인지 분류
   ├─ 3. 등급 3·4이거나 경계가 모호하면 → 변호사 자문 (사용 보류)
   ├─ 4. 등급 1·2면 → 콘텐츠 메타데이터에 license·pool·sources 기록
   └─ 5. licensing_safety.md에 자원 카드 추가 (즉시)
```

### 4.2 분리 관리 강제

- 콘텐츠 풀은 메타데이터 `pool` 필드로 구분: `whymath-original` / `external-sharealike` / `external-licensed`(협상 타결분).
- CI 또는 데이터 파이프라인 검증 단계에서 `pool` 필드 *누락 콘텐츠*를 차단(L1 데이터 + 횡단 검증).

### 4.3 출처 표시

- 모든 등급(1~3)에서 출처 표시 의무 이행 — `licensing_safety.md` 출처 표시 표준(인앱 표시 + 내부 로그)을 따른다.

## 5. 변호사 자문 필요 사항 (체크리스트)

- [ ] 단원명·목차 구조가 "사실정보"인 범위와 "편집저작물"인 범위의 경계 → **변호사 자문 필수**
- [ ] CC BY-SA "분리 관리"가 Share-Alike 전염을 법적으로 충분히 차단하는지 → **변호사 자문 필수**
- [ ] 평가원 기출의 *교육적 인용* 한계, 학생 노출 가능 범위 → **변호사 자문 필수**
- [ ] 교과서 매핑 자산의 *B2B 라이선싱* 시 출판사 권리 관계 → **변호사 자문 필수**
- [ ] NRICH·EBS 등 등급 3 자원의 협상 *계약서 검토* → **변호사 자문 필수**
- [ ] "공정이용" 주장 가능 여부 — *단정하지 말고* 전문가 의견 확보 후 판단 → **변호사 자문 필수**
- [ ] LLM 학습 데이터셋(Apache 2.0 등)으로 학습한 모델의 *출력물* 저작권 지위 → **변호사 자문 필수**
