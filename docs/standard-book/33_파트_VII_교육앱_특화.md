# 파트 VII. 교육앱 특화

파트 VII은 일반 소프트웨어 책에는 없는, **교육 콘텐츠와 학습자**에게서 생기는 구조적 결함을 다룹니다. 교육앱의 결함은 두 가지 점에서 특별합니다. 첫째, 결함이 **학생의 학습 자체**를 틀리게 만듭니다. 틀린 정답이나 잘못된 선수 관계는 오류 화면 없이 조용히 잘못 가르칩니다. 둘째, 사용자가 **아동·청소년**이므로 법적·윤리적 보호 기준이 높습니다.

| 장 | 주제 | 6축 | WhyMath 연결 자산 |
|---|---|---|---|
| 20 | 교육과정 그래프 무결성 | ①흐름 ②진실 | 545개 개념 노드, 2022 개정 성취기준 |
| 21 | 콘텐츠도 코드처럼 | ④변경 ⑤확신 | 문항·오개념 DB의 버전 관리 |
| 22 | 정답 정확성 | ⑤확신 | derive-verify, SymPy, KaTeX |
| 23 | 학습자 모델 재현성 | ②진실 ④변경 | BKT/AKT, 숙달 게이트 P ≥ 0.95 |
| 24 | 문항 품질 측정 | ⑤확신 | 오답 op-code 8종, CAT/IRT |
| 25 | AI 튜터 안전 | ⑤확신 ③경계 | 소크라테스 발문 엔진 |
| 26 | 아동·학생 개인정보 | ③경계 | 만 14세 미만, OCR 풀이 이미지 |
| 27 | 저작권과 출처 추적 | ②진실 | 4-Tier IP, 저작권 종합가이드 v2.0 |
| 28 | 교과 확장 구조 | ③경계 | EOS Core / Subject Contract / Math Adapter |
| 29 | 교실·기기 현실 | ⑥회복 ⑤확신 | 학교 와이파이, 보급형 태블릿, 접근성 |

헌법 조문으로는 제8조(학생 보호)와, 개정안 A0002에 제안된 **제8조의2(교육적 타당성)**가 이 파트의 근거입니다.
