# 17장. 회고

한 줄 요약: **사고는 사람을 탓할 일이 아니라 구조를 고칠 재료다. 모든 회고는 '이제 무엇이 막는가'를 규칙 ID로 끝낸다.**

#### ① 증상

- 같은 종류의 사고가 반복됨
- 회고가 자책으로 끝남: "내가 부주의했다, 다음엔 조심하자" (L1 기억)
- 교훈이 채팅 기록 속에 흩어져 다시 찾을 수 없음
- 교훈이 문서(L2)에 한 줄 추가되는 것으로 끝남

#### ② 근본 결함

사고에서 **구조 개선으로 이어지는 경로**가 없습니다. 개인의 주의력을 원인으로 지목하면 해결책도 "더 주의하기"가 되고, 이는 통제 강도 사다리의 맨 아래(L1)입니다.

#### ③ 업계 표준

| 표준 | 핵심 |
|---|---|
| 비난 없는 사후 분석 (blameless postmortem) | John Allspaw(Etsy, 2012), Google SRE 15장. 사람이 아니라 **사람이 실수할 수 있게 만든 구조**를 분석 |
| 표준 양식 | 요약 · 영향 · 타임라인 · 근본 원인과 기여 요인 · 잘 된 점 · 조치 항목(담당·기한) |
| 5 Whys | 도요타 생산방식(오노 다이이치). "왜?"를 반복해 뿌리까지. 단, 원인을 하나로 몰아가는 한계가 있어 기여 요인을 여러 개 허용 |
| 조치 항목의 질 | "조심한다"는 조치가 아님. 조치는 **장치**여야 함 (이 책의 기준: L4 이상) |

#### ⑤ WhyMath 적용 — 판례 체계

헌법 체계에서 회고는 `constitution/precedents/`의 **판례**가 됩니다. 혼자 운영하므로 양식은 가볍게, 대신 끝맺음은 엄격하게 합니다.

| 판례를 쓰는 경우 (하나라도 해당) | 양식 (P0001과 같음) |
|---|---|
| 학생에게 노출된 결함 (정답 오류, 개인정보, 화면 오류)<br>데이터 손실·손상<br>같은 증상 2회째<br>30분 이상 헤맨 디버깅<br>게이트 우회(bypass) 또는 일시 예외(헌법 제2조 ③) | 무엇이 일어났나 (관찰만)<br>왜 일어났나 (구조 결함, 표준북 장 번호)<br>**이제 무엇이 막는가 (규칙 ID 필수)** |

**판례 검사 (Python)**

```python
# scripts/constitution/check_precedents.py — 판례가 규칙으로 끝나는지 검사 (R17-01)
import re
import sys
from pathlib import Path

PREC_DIR = Path("constitution/precedents")
RULE_ID = re.compile(r"\bR\d{1,2}-\d{2}\b")          # 예: R2-02, R19-01

def main() -> int:
    errors = []
    for f in sorted(PREC_DIR.glob("P*.md")):
        text = f.read_text(encoding="utf-8")
        _, sep, tail = text.partition("## 이제 무엇이 막는가")
        if not sep:
            errors.append(f"{f.name}: '## 이제 무엇이 막는가' 절이 없음")
        elif not RULE_ID.search(tail):
            errors.append(f"{f.name}: 막는 장치가 규칙 ID로 연결되지 않음 (L1 회고)")
    for e in errors:
        print(f"⛔ {e}")
    print(f"판례 {len(list(PREC_DIR.glob('P*.md')))}건 검사")
    return 1 if errors else 0

if __name__ == "__main__":
    sys.exit(main())
```

분기마다 한 번 판례를 모아 읽으면 **반복 패턴**이 보입니다. 같은 축(예: ⑤확신)의 판례가 쌓이면 그 축의 게이트 설계 자체를 다시 봐야 한다는 신호입니다. 이 분기 검토가 헌법 개정(제11조)의 주된 입력이 됩니다.

#### ⑥ 자동 검사와 목표 강도

| 장치 | 강도 |
|---|---|
| 판례마다 규칙 ID 연결 검사 | L5 |

| 분기 판례 검토 | L3 (체크리스트) |
