# 파트 IV 정리 — 점검표 겸 헌법 이식 규칙

이 파트의 ⑥칸을 헌법의 법률(rules.yaml)로 옮긴 목록입니다. 규칙 9개 중 6개가 L5(자동 차단)입니다. 각 행을 "이 규칙이 지금 지켜지고 있는가?"라는 점검 질문으로 읽으면 그대로 점검표가 됩니다. '단계'는 헌법 이식 단계(constitution/STAGE)이며, 그 단계에 도달하기 전까지 위헌 심사에서 "예정"으로 표시됩니다.

| ID | 규칙 (점검 질문) | 강도 | 단계 | 근거 조문 |
|---|---|---|---|---|
| R12-01 | 단위 테스트는 네트워크에 접속하지 않는다 | L5 | 3 | 제7조의4 |
| R12-02 | fix: 커밋에는 재현 테스트 변경이 함께 있어야 한다 | L4 | 3 | 제7조의4 |
| R12-03 | 단위 테스트 전체 실행 시간은 60초 이내여야 한다 | L4 | 4 | 제7조의4 |
| R13-01 | 정답 재도출 검증은 생성 단계의 정답을 입력으로 받지 않는다 (블라인드) | L5 | 3 | 제7조의4 |
| R13-02 | 재도출 검증은 생성과 다른 방법(CAS) 또는 다른 모델 계열을 쓴다 | L5 | 3 | 제7조의4 |
| R13-03 | 검증 층 간 일치율이 4주 연속 100%이면 경고한다 (복사 의심) | L4 | 6 | 제7조의4 |
| R14-01 | 저장소의 모든 .py 파일은 린트 검사 범위 안에 있어야 한다 | L5 | 3 | 제7조의4 |
| R14-02 | 검사 도구(ruff·mypy·pytest 등) 버전은 잠금 파일로 고정한다 | L5 | 3 | 제7조의4 |
| R14-03 | Dart 분석은 info 수준까지 실패로 처리한다 | L5 | 3 | 제7조의4 |

> **rules.yaml에 넣는 방법**
>
> 이 표의 규칙은 별도 파일 `rules_additions_v1.1.yaml`에 집행 장치 경로·실행 명령까지 포함해 정리되어 있습니다. 헌법 제11조에 따라 **사람이** 개정 기록(A0002)과 함께 rules.yaml에 반영합니다.
>
> 근거 조문 중 `제7조의2~5`, `제8조의2`는 현행 헌법에 없는 새 조문입니다. 개정안 초안(A0002)에 들어 있습니다.
