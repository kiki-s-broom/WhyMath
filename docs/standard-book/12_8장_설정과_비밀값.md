# 8장. 설정과 비밀값

한 줄 요약: **환경마다 달라지는 값은 코드 밖(환경 변수)에 두고, 비밀은 저장소·앱에 절대 들어가지 않게 기계로 막는다.**

#### ① 증상

- API 키를 코드에 적었다가 그대로 커밋 — 비공개 저장소라도 한번 커밋된 비밀은 이력에 영원히 남음
- 개발용 DB와 운영용 DB 주소를 코드 안 if문으로 전환하다 실수로 운영 DB에 테스트 데이터 적재
- 모바일 앱 빌드에 서버용 키를 넣음 — 앱 파일은 누구나 풀어볼 수 있음
- 필수 설정이 빠진 채 서버가 떠서, 첫 요청이 들어올 때에야 오류
- 백업 암호화 키를 백업 파일과 같은 폴더(같은 클라우드)에 보관

#### ② 근본 결함

**설정**(환경마다 다른 값)과 **코드**(환경과 무관한 논리)가 분리되지 않았고, **비밀**의 경계가 정의되지 않았습니다. 비밀이 어디에 존재해도 되고 어디에는 절대 없어야 하는지가 규칙으로 없습니다.

#### ③ 업계 표준

| 표준·도구 | 핵심 |
|---|---|
| The Twelve-Factor App, III. Config | Adam Wiggins(Heroku), 2011. 설정은 환경 변수에. 판별법: "지금 이 저장소를 공개해도 비밀이 새지 않는가?" |
| pydantic-settings | 환경 변수·.env를 타입 검사하며 읽고, 필수값이 없으면 시작 시점에 즉시 실패(fail-fast). `SecretStr`로 로그 출력 시 가려짐 |
| SOPS + age | 설정 파일의 **값만** 암호화해 git에 보관. 이미 백업에 쓰는 age 키 체계와 같은 도구 |
| gitleaks | 커밋 직전·CI에서 비밀 패턴을 찾아 차단 (pre-commit 훅 제공) |
| GitHub 비밀 스캔·푸시 보호 | 공개 저장소는 무료. 비공개 저장소는 요금제에 따라 다름 → 로컬 gitleaks로 대체 가능 |
| 모바일 앱 원칙 | 앱에는 **공개돼도 되는 값**만. 서버용 키가 필요한 호출은 반드시 자체 서버를 거침 |

> **백업 키 주의**
>
> 암호화 비밀키를 백업과 같은 곳에 두면 **암호화가 무의미**하고(둘 다 유출), 비밀키를 한 곳에만 두면 그 PC가 고장 났을 때 **모든 백업을 복원할 수 없습니다.** 비밀키는 백업과 다른 곳 두 군데 이상에 보관하고, 보관 위치를 `docs/ops/KEYS.md`에 **위치만** 기록합니다(키 자체는 절대 기록하지 않음). 16장 복원 훈련 때 이 키로 실제 복원이 되는지 함께 확인합니다.

**pydantic-settings (Python)**

```python
# infra/settings.py — 설정은 환경 변수에서, 필수값이 없으면 시작 즉시 실패
from pydantic import SecretStr
from pydantic_settings import BaseSettings, SettingsConfigDict   # 설치: pip install pydantic-settings

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_prefix="WHYMATH_", env_file=".env", extra="ignore")
    env: str                           # "dev" | "prod" — 기본값 없음 → 누락 시 즉시 오류
    database_url: SecretStr            # 로그에 찍혀도 '**********'로 가려짐
    anthropic_api_key: SecretStr
    ollama_url: str = "http://localhost:11434"   # 비밀 아닌 설정은 기본값 허용

settings = Settings()   # 서버 시작 시 1회 생성. 필수 환경 변수가 없으면 여기서 ValidationError
```

**gitleaks 등록**

```yaml
# .pre-commit-config.yaml 중 일부 — 비밀 커밋 차단
repos:
  - repo: https://github.com/gitleaks/gitleaks
    rev: vX.Y.Z            # ← 설치 시점의 최신 릴리스 태그로 고정 (버전 고정 = 14장)
    hooks:
      - id: gitleaks
```

`.env`는 `.gitignore`에 넣고, 대신 값이 비어 있는 `.env.example`을 커밋해 "어떤 설정이 필요한가"만 공유합니다. 앱 빌드 산출물(APK·IPA)은 빌드 후 스크립트로 `sk-ant-` 같은 서버용 키 패턴을 검색해 발견 시 실패시킵니다(R8-02).
