# 27장. 저작권과 출처 추적

한 줄 요약: **모든 문항과 에셋에 출처를 필수 필드로 붙이고, 기존 문항과의 유사도 검사를 게시 게이트로 둔다. 판단 기준 자체는 저작권 가이드 원본을 따른다.**

#### ① 증상

- 어떤 문항이 어디서 왔는지(직접 작성·AI 생성·기출 변형) 기록이 없음
- 기출 문항에서 숫자만 바꾼 변형이 원본과 지나치게 비슷함
- AI가 학습 데이터 속 문제집 문항을 거의 그대로 재생산
- 앱에 쓴 이미지·폰트의 라이선스를 모름
- 저작권 판정이 게시 **후에** 이루어짐

#### ② 근본 결함

출처(provenance)가 **데이터 필드로 강제되지 않고**, 유사도 검사가 **게이트로 연결되지 않았습니다.** 1장에서 지적한 대표적인 '섬 노드'입니다.

#### ③ 업계 표준

| 표준 | 핵심 |
|---|---|
| W3C PROV (2013) | 출처 정보의 표준 데이터 모델: 무엇이(개체) 어떤 활동으로 누구에 의해 만들어졌나 |
| C2PA (콘텐츠 자격 증명) | 이미지·영상 등 미디어의 생성 이력을 서명된 메타데이터로 첨부하는 산업 표준 |
| SPDX 라이선스 식별자 | 코드·에셋 라이선스를 `MIT`, `OFL-1.1`처럼 표준 이름으로 기록 |
| 준복제 탐지 (MinHash/LSH) | Andrei Broder(1997). 문서 조각의 집합 유사도를 빠르게 추정 |
| 수식 골격 비교 | 숫자·변수 이름을 자리표시자로 바꾼 '골격'을 비교해 "숫자만 바꾼 변형"을 탐지 |

#### ④ 원전

- W3C, "PROV-DM: The PROV Data Model" (2013) · SPDX License List (spdx.org/licenses)
- 「MathScope 저작권 종합가이드 v2.0」(2026-05-27) — **WhyMath의 저작권 판단 원본** (4-Tier 기준)

#### ⑤ WhyMath 적용

판단 기준(어느 등급이 게시 가능한가)은 저작권 종합가이드가 원본이며, 이 장은 그 기준이 **빠짐없이 적용되게 하는 구조**만 다룹니다. 모든 문항은 21장 문항 파일의 `provenance` 필드를 가져야 합니다.

| 필드 | 값 예시 | 비고 |
|---|---|---|
| origin | `original_ai` / `human_authored` / `derived` / `licensed` | 필수 |
| source_ref | 변형 원본의 식별자 (파생일 때 필수) | 원문 전체가 아니라 식별자만 |
| generator | `모델명@프롬프트버전` | AI 생성일 때 필수 (25장 프롬프트 버전과 연결) |
| license | `own` 또는 SPDX 식별자·계약 번호 | 필수 |
| similarity | `{max: 0.41, nearest: "…", corpus: "2026.10"}` | 게시 게이트 입력 (R27-02) |
| tier | 가이드의 등급 | 저작권 게이트(2장)가 기록 |

**수식 골격 지문 (Python)**

```python
# subject_math/fingerprint.py — 수식 골격 지문: '숫자만 바꾼 변형' 탐지
import hashlib
import re

def skeleton(latex: str) -> str:
    """한 글자 변수 → V, 숫자 → N, 공백 제거. 구조만 남긴다.
    순서 주의: 숫자를 먼저 N으로 바꾸면 '5x'가 'Nx'가 되어 x가 변수로 인식되지 않음."""
    s = re.sub(r"\s+", "", latex)
    s = re.sub(r"(?<![\\a-zA-Z])[a-z](?![a-zA-Z])", "V", s)   # \frac 같은 명령어는 유지
    s = re.sub(r"\d+(\.\d+)?", "N", s)
    return s

def fingerprint(stem_latex: str) -> str:
    return hashlib.sha1(skeleton(stem_latex).encode("utf-8")).hexdigest()[:16]

# 예: "x^2-5x+6=0" 과 "y^2-7y+12=0" → 골격 "V^N-NV+N=N" 동일 → 같은 지문 → 사람 확인 대상
# 비교 코퍼스(기출·교재)도 저작물이므로 전문 대신 '지문'만 보관하는 것을 원칙으로 한다
```

골격이 같다고 모두 문제는 아닙니다. 이차방정식의 기본 형태는 원래 흔하기 때문입니다. 따라서 골격 일치는 **차단이 아니라 사람 확인 대상 표시**로 쓰고, 문장 유사도(MinHash·임베딩)와 함께 종합해 저작권 게이트에 입력합니다. 이미지·폰트는 `assets/LICENSES.yaml`에 파일별 라이선스를 등록하고, 목록에 없는 에셋이 추가되면 CI가 실패합니다(R27-03).
