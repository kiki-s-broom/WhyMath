# 20장. 교육과정 그래프 무결성

한 줄 요약: **개념 그래프가 지켜야 할 성질(불변식)을 목록으로 선언하고, 그래프가 바뀔 때마다 전부 기계로 검사한다.**

#### ① 증상

- A가 B의 선수이고 B가 다시 A의 선수 — 선수 관계 순환 → 진단 게이트가 무한히 돌거나 어느 쪽도 시작 불가
- 어떤 성취기준에도 연결되지 않은 고아 노드
- 고1 개념이 중1 개념의 선수로 연결된 학년 역전
- A→B→C가 있는데 A→C 직접 간선도 있어, 진단이 불필요하게 길어짐
- 성취기준 코드 오타, 또는 2015 개정과 2022 개정 코드가 섞임
- 노드를 지우고 같은 ID를 다른 개념에 재사용 → 과거 학습 기록이 엉뚱한 개념을 가리킴

#### ② 근본 결함

그래프가 **데이터로만** 존재하고, 그래프가 만족해야 할 **불변식이 선언·검사되지 않습니다.** 545개 노드 규모에서는 사람이 눈으로 순환이나 학년 역전을 찾을 수 없습니다.

#### ③ 업계 표준

| 표준 | 핵심 |
|---|---|
| 지식 공간 이론 (Knowledge Space Theory) | Jean-Paul Doignon·Jean-Claude Falmagne, 1985. 선수 관계를 수학적으로 다루는 이론. 적응형 학습 시스템 ALEKS의 기반 |
| 선수 관계 = 부분 순서 | 선수 관계는 순환이 없어야 함 → 반드시 DAG (1장) |
| 추이적 축소 (transitive reduction) | Aho·Garey·Ullman, 1972. 도달 관계를 유지하면서 중복 간선을 제거한 최소 그래프 |
| 성취기준 코드 체계 | 2022 개정 교육과정의 `[9수01-01]` 형식 코드 (학년군·교과·영역·순번). 원본은 교육부 고시 |
| CASE 표준 | 1EdTech(구 IMS Global)의 Competencies and Academic Standards Exchange. 성취기준을 기계가 읽는 형식으로 교환하는 국제 표준 → 과목 확장·타 시스템 연동 시 참고 |

**개념 그래프 검사기 (Python + networkx)**

```python
# scripts/constitution/concept_graph_check.py — 개념 그래프 불변식 검사 (pip install networkx pyyaml)
# 전제 형식: content/concept_graph.yaml
#   nodes: [{id, grade, standards: ["[9수01-01]"], auxiliary: false, deprecated: false}, ...]
#   edges: [{pre: 선수ID, post: 대상ID}, ...]
import re
import sys
import networkx as nx
import yaml

CODE = re.compile(r"^\[\d{1,2}[가-힣]+\d{2}-\d{2}\]$")   # 예시 형식 — 원본 코드표로 최종 확정
GRADE_EXCEPTIONS: set[tuple[str, str]] = set()                 # (선수, 대상) 학년 역전 허용목록

def load(path="content/concept_graph.yaml"):
    try:
        with open(path, encoding="utf-8") as f:
            return yaml.safe_load(f)
    except (OSError, yaml.YAMLError) as e:
        sys.exit(f"⛔ 개념 그래프를 읽을 수 없음: {e}")

def check(data, valid_codes: set[str] | None = None, redundant: bool = False) -> list[str]:
    errors = []
    nodes = {n["id"]: n for n in data["nodes"] if not n.get("deprecated")}
    g = nx.DiGraph()
    g.add_nodes_from(nodes)
    for e in data["edges"]:
        if e["pre"] not in nodes or e["post"] not in nodes:           # I7
            errors.append(f"[I7 누락] {e['pre']} → {e['post']}")
            continue
        g.add_edge(e["pre"], e["post"])
    if not nx.is_directed_acyclic_graph(g):                           # I1
        cycle = nx.find_cycle(g)
        errors.append("[I1 순환] " + " → ".join(u for u, _ in cycle) + f" → {cycle[0][0]}")
    for nid, n in nodes.items():                                      # I2·I3
        codes = n.get("standards", [])
        if not codes and not n.get("auxiliary"):
            errors.append(f"[I2 고아] {nid}: 성취기준 연결 없음")
        for c in codes:
            if not CODE.match(c):
                errors.append(f"[I3 형식] {nid}: '{c}'")
            elif valid_codes is not None and c not in valid_codes:
                errors.append(f"[I3 실재] {nid}: '{c}' 는 원본 성취기준 목록에 없음")
    for pre, post in g.edges:                                         # I4
        if nodes[pre]["grade"] > nodes[post]["grade"] and (pre, post) not in GRADE_EXCEPTIONS:
            errors.append(f"[I4 학년 역전] {pre}(학년 {nodes[pre]['grade']}) → {post}(학년 {nodes[post]['grade']})")
    if redundant and nx.is_directed_acyclic_graph(g):                 # I5 (경고용)
        extra = set(g.edges) - set(nx.transitive_reduction(g).edges)
        errors += [f"[I5 중복 간선] {u} → {v} (다른 경로로 이미 도달)" for u, v in sorted(extra)]
    return errors

if __name__ == "__main__":
    errs = check(load(), redundant="--redundant" in sys.argv)
    for e in errs:
        print(e)
    print(f"개념 그래프 검사: 오류 {len(errs)}건")
    sys.exit(1 if errs else 0)
```

I6(ID 불변)은 이 스크립트의 `--id-history` 옵션으로, 직전 릴리스 매니페스트(21장)에 있던 ID가 현재 파일에서 **사라졌는지** 비교해 확인합니다. 사라진 ID는 삭제가 아니라 `deprecated: true`로 남아 있어야 합니다. 과거 학습 기록과 숙달 판정이 그 ID를 가리키고 있기 때문입니다.
