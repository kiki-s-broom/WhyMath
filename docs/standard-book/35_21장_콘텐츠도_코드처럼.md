# 21장. 콘텐츠도 코드처럼

한 줄 요약: **문항·개념 설명·오개념 데이터를 코드와 같은 수준으로 버전 관리·린트·검토·릴리스하고, 학습 기록은 어느 버전의 콘텐츠에 대한 것인지 함께 남긴다.**

#### ① 증상

- 문항 오타를 DB에서 바로 고침 → 누가·언제·왜 바꿨는지 이력 없음
- LaTeX 괄호가 하나 빠진 문항이 학생 화면에서 깨진 채 발견됨
- 콘텐츠 한 줄 수정이 앱 새 버전 배포를 기다려야 함 (또는 반대로 콘텐츠가 앱 배포에 섞여 함께 되돌아감)
- 문항 선지를 고쳤는데, 고치기 전 응답과 고친 후 응답이 한 통계에 섞여 난이도가 왜곡됨

#### ② 근본 결함

콘텐츠가 코드보다 **약한 관리 체계**에 있습니다. 교육앱에서 콘텐츠는 코드만큼 — 어쩌면 더 — 중요한 산출물인데, 버전·검토·테스트·릴리스 파이프라인이 없습니다. 또 콘텐츠가 바뀌어도 학습 기록에 **버전**이 남지 않아 과거 데이터의 의미가 바뀝니다.

#### ③ 업계 표준

| 표준 | 핵심 |
|---|---|
| Docs-as-Code | Write the Docs 커뮤니티. 문서를 코드처럼: 텍스트 형식, git, 리뷰, CI 빌드. 콘텐츠에도 그대로 적용 |
| 콘텐츠 스키마·린트 | 구조(6장 계약)와 표기(LaTeX 괄호, 필수 필드, 금칙어) 검사를 커밋마다 |
| 콘텐츠 릴리스 분리 | 콘텐츠 번들을 **자체 버전**으로 배포. 앱은 최신 호환 번들을 받아옴 → 콘텐츠 수정이 앱 배포를 기다리지 않음 |
| 원자적 릴리스·롤백 | 매니페스트(버전·파일 해시 목록)로 전부 아니면 전무. 문제 시 직전 매니페스트로 되돌림 |
| 개정 번호 (revision) | ID는 불변(20장 I6), 내용이 바뀔 때마다 revision 증가. 응답은 (ID, revision) 쌍을 기록 |

**문항 파일 (YAML)**


콘텐츠 린트(`content_lint.py`, R21-01)는 커밋마다 모든 문항 파일에 대해 ① 6장 계약(Pydantic) 파싱, ② `$` 개수 짝수·중괄호 짝 맞음, ③ `stem_speech` 존재(R29-03), ④ `revision`이 이전 릴리스보다 작아지지 않음을 검사합니다. KaTeX 렌더 가능 여부는 22장 검사가 맡습니다.

> **YAML 큰따옴표가 LaTeX를 조용히 망가뜨린다 (실행 검증 중 발견)**
>
> YAML의 **큰따옴표** 문자열에서 역슬래시는 이스케이프 문자입니다. 그래서 `"$\frac{1}{2}$"`의 `\f`는 폼피드 문자로, `\theta`의 `\t`는 탭으로, `\neq`의 `\n`은 줄바꿈으로, `\alpha`의 `\a`는 벨 문자로 바뀝니다. 오류 없이 저장되고, 학생 화면에는 θ 대신 "heta"가 보입니다.
>
> 이 책의 KaTeX 검사(22장)를 실제로 돌려 보니 `\frac` 손상은 잡았지만 **`\theta`와 `\neq` 손상은 통과**했습니다(탭·줄바꿈은 수식에서 공백으로 처리되기 때문). 그래서 두 가지를 규칙으로 둡니다: ① 수식이 든 값은 **작은따옴표**(작은따옴표 자체는 두 번 `''`)나 블록(`|`)으로 쓴다. ② 린트가 수식 안의 제어 문자를 찾으면 실패시킨다(R21-04).

**손상된 수식 탐지 (Python)**

```python
# scripts/constitution/content_lint.py 일부 — YAML 이스케이프로 손상된 수식 탐지 (R21-04)
import re
import yaml

MATH = re.compile(r"\$([^$]*)\$")
CONTROL_IN_MATH = re.compile(r"[\x00-\x1f]")          # 수식 안에서는 탭·줄바꿈도 손상 신호
CONTROL_ANYWHERE = re.compile(r"[\x00-\x08\x0b-\x1f]")   # 수식 밖: 탭·줄바꿈만 허용

def strings(v):
    """YAML 값 속 모든 문자열을 꺼낸다."""
    if isinstance(v, str):
        yield v
    elif isinstance(v, dict):
        for x in v.values():
            yield from strings(x)
    elif isinstance(v, list):
        for x in v:
            yield from strings(x)

def damaged_math(path: str) -> list[str]:
    with open(path, encoding="utf-8") as f:
        data = yaml.safe_load(f)
    found = []
    for s in strings(data):
        if any(CONTROL_IN_MATH.search(m) for m in MATH.findall(s)) or CONTROL_ANYWHERE.search(s):
            found.append(repr(s[:40]))            # repr로 보여 줘야 보이지 않는 문자가 드러남
    return found
```
