# 부록 A. 증상 색인표

부록은 책을 **찾아 쓰는 도구**입니다. 새 문제를 만나면 A에서 증상으로 장을 찾고, 규칙과 이식 단계는 C에서, 헌법에 넣을 조문은 D에서 확인합니다.

파트 0의 5단계 절차 중 1단계(증상 → 장 찾기)에 쓰는 색인입니다. 여러 장이 적힌 경우 앞의 장이 주된 원인입니다. `*`는 해당 장의 일부 절이 관련됨을 뜻합니다. 색인에 없는 증상은 6축 표(파트 0)로 축부터 정한 뒤 해당 축의 장들을 살펴봅니다.
