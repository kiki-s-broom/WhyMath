# 리스크·대응

> **2026-05-14 보강**: MathScope PRD v1.1 §14("5개 핵심 가정"과 검증법)를 아래 "핵심 가정 검증" 섹션으로 통합. 기존 Top 7 리스크·게이트·윤리 리스크는 *유지*. PRD의 "MathScope" 표기는 "WhyMath"로 치환.

## Top 7 리스크

### 1. 콴다·메가스터디가 같은 방향 추격
**확률**: 중
**영향**: 매우 큼
**대응**: 
- 방법론·교수학은 자본으로 단기 복제 어려움 (1~2년 헤드스타트)
- 학회·정부·NRICH 협력으로 사회적 해자 구축
- Kiki의 메타인지 자산 *지속적 심화*

### 2. 입시 결과 검증에 1~2년
**확률**: 매우 높음
**영향**: 중
**대응**:
- 단기는 *진단·이해도*로 가치 입증
- Phase 1·2는 메타인지·사고력 (입시 무관)
- Phase 2 말~3에 수능 결과 데이터 누적

### 3. 학부모 "수능에 안 나오는 거?"
**확률**: 높음
**영향**: 큼
**대응**:
- 수능 모드 *반드시* 포함 (Phase 2)
- 사고력은 *부가* 포지셔닝
- 부모 보고서로 *진척* 가시화

### 4. LLM 환각
**확률**: 높음 (LLM 특성상)
**영향**: 매우 큼 (학생 학습 저해)
**대응**: 5중 검증
- PRM 단계 검증
- SymPy 수치 재확인
- 자기 일관성 (N회 → 다수결)
- 사람 수학자 검수 (샘플)
- *불확실하면 답 거부* 패턴

### 5. 정부 사업 변동성
**확률**: 매우 높음 (정권 영향)
**영향**: 중
**대응**:
- B2C 매출 안정성 *우선* 확보
- B2B는 다각화 (학교·교육청·자유학기)
- AI 디지털교과서 정책 변동 *모니터링*

### 6. Kiki의 수학 도메인 부족
**확률**: 사실
**영향**: 매우 큼
**대응**: **1순위 채용/영입**
- KAIST 영재교육원 출신
- 한국수학교육학회 활동가
- 영재교사 경력자
- 후보 3명 *Phase 0 마무리* 시점에 접촉

### 7. 미성년자 데이터 보호 사고
**확률**: 낮음 (대응 시)
**영향**: 매우 큼 (회사 존속)
**대응**:
- 14세 미만 부모 동의 미들웨어
- PII 분리 저장·암호화
- 보안 감사 (Phase 1 종료 시)
- 정기 침투 테스트 (Phase 2+)

## 게이트 미달 대응

각 Phase 게이트 미달 시 *Phase 연장*이 기본. *다음 Phase 진입 강행 금지*.

### 시그널
- 사용자 성장률 < 10% MoM
- LLM 비용 > 학생당 월 2,000원
- 학생 재방문율 < 20%
- 도메인 파트너 검수 실패

### 대응 액션
1. 1주 회고 (`/review` + MEMORY.md 분석)
2. 가설 재정립 (`/plan`)
3. 1개 우선순위로 좁히기 (병렬 작업 금지)
4. 2~4주 시도 → 재평가
5. 미달 지속 시 *피벗 또는 중단* 결정

## 핵심 가정 검증 (PRD v1.1 §14)

> WhyMath 전체 사업·제품 가설은 아래 5개 *핵심 가정* 위에 서 있다. 각 가정이 무너지면 그 위의 모든 계획이 흔들리므로, **가정마다 검증 지표·검증 방법·실패 시 대응을 미리 정의**한다. 이는 위 Top 7 리스크와 별개가 아니라, *리스크의 뿌리*에 해당하는 전제들이다.
> PRD의 "MathScope" 표기는 "WhyMath"로 치환. 모든 수치는 *목표 임계값 가설*이며 검증 전 확정값이 아님.

### 가정 ①: 한국 학생이 "답을 바로 주지 않는" 앱을 *계속* 쓸 것이다
이것이 가장 근본적이고 가장 위험한 가정이다. WhyMath의 정체성(답 미루기·Polya 4단계) 자체가 *한국의 답-즉시-의존 학습 문화와 정면으로 부딪힌다.*

| 항목 | 내용 |
|---|---|
| **검증 지표** | D7 retention ≥ 30% (β 사용자 기준). 보조 지표: 세션당 답 미루기 단계 평균 도달 깊이, "스스로 풀이 도달" 비율(MEMORY.md KPI 베이스라인) |
| **검증 방법** | Phase 1 β 코호트 retention 추적(코호트 크기 조건 없음 — 2026-11-06 Kiki 결정). 이탈 사용자 인터뷰("왜 답을 안 주냐"는 불만 빈도 측정). A/B: 답 미루기 강도(단계 깊이) 변주 |
| **실패 시 대응** | retention이 임계값 미만이면 — (a) 답 미루기 단계를 *학생이 조절*하게(점진 노출), (b) "오늘은 답까지" 같은 탈출 밸브 제공, (c) 그래도 안 되면 *타깃을 사고력 친화 학부모·상위권*으로 좁히는 피벗 |

### 가정 ②: 개념 그래프 기반 정밀 진단·학습이 *실제로* 성취도를 높인다
개념 그래프·단계별 진단이 단순 문제풀이보다 학습 효과가 크다는 것은 *교수학 이론상* 그럴듯하나, 한국 학생·한국 교과 맥락에서 *실측 증거*가 없다.

| 항목 | 내용 |
|---|---|
| **검증 지표** | 대조군 대비 개념 숙달도(BKT 확률) 증가율, 내신 점수 변화(고1 내신 트랙), 오개념 해소율 |
| **검증 방법** | **RCT(무작위 대조 시험)** 설계 — 개념 그래프 진단군 vs 일반 문제풀이군. 도메인 파트너·학회와 공동 설계(`partnerships.md` 1순위). 표본·기간은 통계적 검정력 확보 후 확정 |
| **실패 시 대응** | 효과가 미미하면 — 개념 그래프를 *진단 정밀도*가 아닌 *학습 경로 추천*에만 쓰는 등 역할 축소. RCT 자체가 "효과 입증" 마케팅·논문 자산이 되므로 음(-)의 결과도 학습 가치 있음 |

### 가정 ③: 수학 교육 도메인 인력(특히 검수 교사) 풀을 확보할 수 있다
콘텐츠 검수·교수학 자문·RCT 설계 모두 *수학 교육 전문가*에 의존한다. Kiki의 유일한 빈자리(위 리스크 6, `differentiation.md`)이자 *공급이 희소한* 자원이다.

| 항목 | 내용 |
|---|---|
| **검증 지표** | M1.3 게이트까지 도메인 파트너 1명 확정(MEMORY.md), 콘텐츠 검수 가능 인력 풀 규모, 검수 1건당 단가·소요시간 |
| **검증 방법** | Phase 1 중 후보 3명 접촉(`partnerships.md`). 검수 인력 시장 단가 조사. 파트타임·건당 계약 모델 시험 |
| **실패 시 대응** | 인력 확보 실패 시 — (a) 콘텐츠 *생산 속도*를 인력 풀에 맞춰 하향 조정(범위 축소), (b) LLM+SymPy 자동 검증 비중을 늘리되 *사람 최종 검수*는 샘플로 유지, (c) 학회·대학원과 *연구 협력* 형태로 검수 인력 우회 확보 |

### 가정 ④: LLM이 한국어 수학 풀이를 *충분히 정확하게* 생성·검증한다
WhyMath 콘텐츠·코칭의 신뢰는 LLM 출력 품질에 직결된다. 영어권 수학 벤치마크 성능이 *한국어·한국 교과 표기·한국식 풀이 관행*에 그대로 전이된다는 보장이 없다.

| 항목 | 내용 |
|---|---|
| **검증 지표** | 한국 교과 문항 풀이 정확도, PRM 단계 검증 통과율, 사람 수학자 검수 시 오류 발견율, 환각 발생 빈도 |
| **검증 방법** | M1.1 Qwen3-Math 벤치마크(MEMORY.md, 스크립트 준비 완료). 한국 교과 평가셋(`docs/data/eval_data.md`)으로 정확도 측정. 5중 검증(위 리스크 4) 각 단계 효과 측정 |
| **실패 시 대응** | 정확도 미달 시 — (a) 클라우드 LLM 비중 상향(비용↑, CLAUDE.md 의사결정 우선순위상 정확도 > 비용), (b) 도구 호출(SymPy·Wolfram) 의존도 강화, (c) *불확실하면 답 거부* 패턴을 더 보수적으로. 정확도가 회복 불가 수준이면 콘텐츠 범위를 *검증 가능한 단원*으로 한정 |

### 가정 ⑤: AI 디지털교과서 정책이 *위협이 아닌 기회*다
정부의 AI 디지털교과서 정책은 시장을 키울 수도(기회), 공교육이 직접 흡수해 민간 자리를 좁힐 수도(위협) 있다. *정권·정책 변동성*이 매우 크다(위 리스크 5).

| 항목 | 내용 |
|---|---|
| **검증 지표** | 정책 방향(민간 협력형 vs 공공 직접형), 시범사업 민간 참여 가능성, 교육청 시범 채택 건수 |
| **검증 방법** | 정책 공고·예산·체계 *상시 모니터링*(MEMORY.md 외부 의존성 모니터링). 교육청 담당자 접촉(`partnerships.md` 2순위)으로 민간 협력 여지 탐색 |
| **실패 시 대응** | 정책이 위협으로 작동하면 — (a) B2C·B2B 학원 등 *정책 비의존* 매출축으로 무게중심 이동(`business_model.md` 수익 3축), (b) 공공 직접형이면 *공교육 보완재*(교사 대시보드·진단)로 포지션 재조정, (c) 데이터 자산을 *공교육에 라이선싱*하는 B2G 모델 검토 |

## ⑥ 빠지기 쉬운 함정 (PRD v1.1 §14)

5개 핵심 가정과 별개로, *실행 과정에서* 반복적으로 과소평가하기 쉬운 함정들. 사전 인지 자체가 1차 방어선이다.

### 함정 1: 콘텐츠 인건비 과소평가
**내용**: "LLM이 콘텐츠를 생성하니 인건비가 적다"는 착각. 실제로는 *검수·교정·교수학 검증*에 사람 시간이 대량 소요된다. 문항 1개당 LLM 생성은 싸지만 사람 검수는 비싸다.
**대응**: `business_model.md` 인력 계획과 직결 — 콘텐츠 큐레이터·검수 인력 비용을 *초기 추정의 1.5~2배*로 책정. 자동 검증(PRM·SymPy)으로 사람 검수 *부담*은 줄이되 *최종 책임*은 사람에 둠.

### 함정 2: "3개월 안에 다 된다"는 일정 낙관
**내용**: PRD 원안의 Phase 1 3개월은 과부하(MEMORY.md 2026-05-14 결정 로그 보정 ①). 데이터 파이프라인·LLM 검증·교수학 프롬프트·앱 스캐폴딩을 동시에 3개월에 끝낸다는 가정은 비현실적.
**대응**: WhyMath는 Phase 1을 *6개월*로 확정(MEMORY.md). 게이트 미달 시 *Phase 연장이 기본*(위 "게이트 미달 대응"). 다음 Phase 진입 강행 금지.

### 함정 3: 범위 폭발 (multi-everything 동시 진행)
**내용**: 다국 커리큘럼 매트릭스·3개 앱·풀 K-12를 *초기에 동시* 추진하려는 유혹. PRD 원안에 이 경향이 있었음(MEMORY.md 보정 ②③).
**대응**: 다국 매트릭스 → Phase 3, 단일 앱(모드 분기), 1개 학년(고1 내신) 검증 후 확장. MEMORY.md 폐기 패턴 "처음부터 풀 K-12"와 동일한 함정.

### 함정 4: 개념 시퀀스 동치성 판정의 난이도 과소평가
**내용**: "두 풀이가 같은 개념 경로인가"를 자동 판정하는 것은 PRD 원안이 가정한 것보다 훨씬 어렵다(MEMORY.md 보정 ⑤).
**대응**: 휴리스틱 + *사람 검수* 병행. 완전 자동 판정을 게이트로 삼지 않음.

### 함정 5: 하이브리드 인프라 동기화 비용 미산정
**내용**: Phaiakes9(로컬) + 클라우드 하이브리드는 *데이터 동기화·지연·운영 복잡도* 비용이 든다. PRD 원안은 이를 명시하지 않음(MEMORY.md 보정 ⑦).
**대응**: 하이브리드 운영 비용을 인프라 예산에 *명시적 항목*으로 포함. Phase별 자금 계획(`business_model.md` §6)에 반영.

### 함정 6: 법률 리스크의 "괜찮겠지" 처리
**내용**: 교과서 학습목표 활용을 "페어유즈겠지"로 단정하거나, 정기결제·미성년자 환불·사이버학원 등록을 *나중에* 처리하려는 유혹(MEMORY.md 보정 ⑥).
**대응**: `docs/legal/` 3개 문서로 사전 정리. 단정 금지 — *변호사 자문 필수* 사항을 명시 표기. 결제·미성년자 관련은 Phase 1.5 출시 *전*에 검토 완료.
