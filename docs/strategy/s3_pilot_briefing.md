### 트리거 ③ 합격 판정 지시문 (2026-07-28 **사전 등록** — 실측 전 고정·사후 이동 금지)

측정: `run_demo.ps1`(verdict 캡처 내장) → 실기기 **자연 자유사용 15~30분(대본 금지·등호 방정식
변형 포함)** → `python -m whymath_backend.harness.wh1_shadow_harvest wh1_shadow_records.log` 출력
원문 회신. 판정·기록은 서기(claude) 수행 — 수확 도구는 의도적으로 판정선이 없다(분포 제시만).

- **모집단**: verify-대상 턴(verdict=correct/incorrect/unverifiable)만 분모. verdict 없음(풀이
  단계 미동봉 대화 턴)·구판 레코드(전이 카운트 없음·별도 표기분)는 제외.
- **유효성 전제**(하나라도 미달 → 판정 무효·재측정): V1 `parsed`≥1 · V2 verify-대상 턴 **n≥10**
  (권장 15~20) · V3 **등호 방정식 변형 턴 ≥5건**(89% 기준선의 주범 축이 실측돼야 대표측정).
- **합격**(둘 다): **P1 unverifiable ≤ 50%**(실작동 실질선 — 채택 판정선. 기대치 10~30%대) ·
  **P2** unverifiable 건수 ≤ Wilson 단측 95% 표(상한<기준선 89% 보증): n=10→7 · n=15→11 ·
  n=20→15 · n=25→19 · n=30→23. P2만 통과·P1 미달은 **불합격**.
- **즉시 환류**(비율 무관): **F1 거짓 incorrect ≥1건**(옳은 단계가 incorrect) → 신뢰 우선 버그
  환류(S3-02 "거짓 incorrect 0" 위반) · **F2 >50%** → 잔여 축 분석 후 후속 태스크 환류·모집
  착수 금지 유지.
- 합격 시 동반 결정 1건: 파일럿 동의서 변호사 검토를 "외부 작업 출시 전 연기"(2026-07-27 지시)의
  **예외로 앞당길지** — 법령 유래 절차라 기계 대체 불가·Kiki 결정.

> ⓘ **트리거 ① 정직 프레이밍**(2026-07-20 flip GA·#565): flip은 LLM *오케스트레이션*(도구 선택·오개념 가설 큐레이션·verify 강제) + **게이트된 발화**다 — 학생-대면 발화는 정답 억제 백스톱으로 결정론 소크라테스/폴백 템플릿(`wh1_loop.py:358/361`)이라 *반복은 완화되나 자유 산문은 아님*. 정서안전 KPI3 톤 측정 좌석(`tone_rewritten`/`tone_violations`)은 배선됨. 발화의 완전 LLM 프로즈화는 별건 **S4-04**(파일럿 하드 의존 아님). 비상 킬스위치 `WHYMATH_WH1_PRIMARY_ENABLED=false`.
