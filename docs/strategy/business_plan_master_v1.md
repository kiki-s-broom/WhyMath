## 제1부 — 현재까지 진행된 사업 (2026-07-05 실측)

### 1.1 사업 정체성 (확정)

- **앱명**: WhyMath (와이매스) · **슬로건**: "답이 아닌, 이유를 묻는 수학" / "The math that asks why."
- **정의**: 한국 중·고등학생을 위한 **메타인지 중심·사고력 우선·단계별 진단** 기반 AI 수학 학습 앱.
- **시장 자리**: "답 빠르게"(콴다)·강의(EBSi)·학습지(밀크티)가 포화한 시장에서 **메타인지·사고력·단계 진단이라는 공백**에 진입. 사교육의 대체재가 아닌 *보완재* (`market_positioning.md`).
- **타깃 시장**: 약 **52만 명** (고3 재학 32만 + N수 20만, `prd_v1.2.md` §3). 페르소나 5종 — **A 일반고 고3**(MVP·시장최대) · C 검정고시 N수(v1.5) · D 학종 고2(v1.5) · B 자사고 N수(v2.0) · E 홈스쿨링 영재(v2.0).
- **5중 해자** (`differentiation.md`): ①데이터(성취기준·교과서 매핑) ②방법론(메타인지·소크라테스) ③비용(Phaiakes9 로컬 LLM — 클라우드 대비 1/10) ④신뢰(PRM+수학자 검수+Lean) ⑤사회적(학회·정부·NRICH).

**수학 완성 로드맵 S축 진행 현황**:

### 1.4 정직한 자기 진단

> **"코어(L1–L4)는 과잉 성숙, 제품 루프(L5 E2E·L6 수능 모드)는 미성숙."** — 부품은 고급인데 자동차가 조립된 적이 없다. 지금 최대 리스크는 기술 부채가 아니라 **검증 부채**: 이 코어가 실제 고3의 30번 문제 앞에서 작동한다는 증거가 0건이다. (`status_roadmap_2026-07.md` §2.3)

**병목 Top 5**: ①이중 truth source(S0로 해소) ②Phaiakes9 라이브 검증(**Kiki 수동**) ③E2E 루프 미실증 ④도메인 파트너 미확보(**Kiki 수동**) ⑤L6 수능 모드 얇음. — 병목 5개 중 2개는 AI가 못 푸는 **사람 병목**이며, 이 둘이 크리티컬 패스를 결정한다.

## 제3부 — 수학앱 완성 로드맵: 초·중·고에서 대학까지 (M1~M6)

수학 완성의 순서는 "학년 순서(초→중→고)"가 아니라 **"wedge → 인접 확장"** 순서다. 결제 의향과 절박함이 최대인 고3에서 PMF를 증명한 뒤, 이미 구축된 원자 백본 4축(초·중·고+대학)을 따라 수평 확장한다. 신규 발명이 아니라 **커버리지 작업**이다.

### M1. 고3 수능 wedge — "한 명의 고3이 킬러 30번을 스스로 푼다" (Phase 1 · S1~S3 · 2026H2)

**목표**: E2E 루프 실증 → 콘텐츠 공장 가동 → 진짜 학생 파일럿. Phase 1의 산출물은 기능이 아니라 **증거**다.

| 항목 | 내용 |
|---|---|
| 핵심 과업 | ① S1: 실기기(패드)에서 온보딩→CAT 진단→동등문제→풀이 입력(MathLive/OCR)→WH-1 코칭→3-tier 검증 응답 **1루프 15분 내 완주** ② S2: 미적분 킬러 시그니처 기반 **검증 통과 동등문제 100문+**(SymPy 게이트→PRM→인간 검수) + WH-S 솔버 가동 ③ S3: L6 수능 모드 본격 엔진 + **시범 사용자 5~10명** 2주 이상 + 측정 하네스(답 미루기 깊이·오개념 해소율·BKT 숙달 증가율) |
| 필요 자원 | Kiki + AI 하네스. **Kiki 수동 크리티컬 패스**: Phaiakes9 라이브 키·비용 실측 / 도메인 검수 자문 1인(정규 파트너의 최소 요건 완화판) / 시범 사용자 채널 |
| 수익 모델 | 무료 β (매출 0 — 계획된 상태) |
| 자금 | 자기자본 + 예비창업패키지 (`business_model.md` §6) |
| 게이트 (Phase 1 종료 = Phase 2 진입) | 답 미루기 평균 2.5단계+ · LLM 비용 학생당 월 1,000원 이하 · 도메인 검수 통과 |
| 리스크 | **최상위 가정**: "한국 학생이 답 안 주는 앱을 계속 쓰는가"(`risks.md` 가정 ①). D7 30% 미달 시 이후 모든 매출 시나리오가 무너지므로, 이 게이트는 협상 불가 |

### M2. 고교 전체 — "미적분에서 고교 전 단원으로" (Phase 2 전반 · S4 전반 · ~2027H1)

**목표**: 파일럿이 검증한 루프를 고교 전 과목(공통수학·수학Ⅰ·Ⅱ·미적분·확통·기하)으로 수평 확장하고, **수익화를 시작**한다.

| 항목 | 내용 |
|---|---|
| 핵심 과업 | ① 단원별 최소 세트(동등문제·오개념·다중 풀이) 정의 후 S2 파이프라인 일괄 가동 ② 자동 커리큘럼 정렬 엔진(교과서 구조 메타데이터만) — 검정교과서 3종+ 작동 ③ 페르소나 C(검정고시)·D(학종 세특) 모드 = PRD v1.5 ④ **결제 시스템 출시**(토스페이먼츠/카카오페이) ⑤ L6 학교진도·메타인지 모드 활성화 |
| 필요 자원 | 12개월 시점 팀 목표: Kiki + 도메인 파트너 1 + 풀스택 1 + 콘텐츠 큐레이터 1 (`ROADMAP.md`). 콘텐츠 인건비는 초기 추정의 1.5~2배로 책정(`risks.md` 함정) |
| 수익 모델 | **가격 단일 결정 선행**(§5.2): β WTP 조사 + D7 데이터 입력으로 PRD 안(4,900/9,900) vs 정본 안(9,900/29,900/49,900) 확정 → 무료/보급/프리미엄 출시 |
| 자금 | TIPS 추천 + 초기 매출 + 엔젤/시드 + 데이터 바우처 |
| 게이트 | **결제 사용자 1,000명** · MoM 30%+ · **LTV/CAC > 3** · 고교 성취기준 100% 커버 |
| 리스크 | 무료→유료 전환율(가설 3~7%)이 1%p 빗나가면 매출선 전체 이동. 방학 이탈 주기 실측 필요 |

### M3. 중등 확장 — "TRACK=MID 활성화" (Phase 2 후반~3 · S4 중반 · ~2027H2)

| 항목 | 내용 |
|---|---|
| 핵심 과업 | ① 원자 백본 중등(MID) 축 콘텐츠 활성화 — 중1~중3 단원별 동등문제·오개념(기존 카탈로그가 중2~고1 핵심 30종에서 출발했으므로 중등이 오개념 자산의 원류) ② 자유학기제·사고력 모드 연계 ③ **학부모 주간 보고서**(L7 최소 착수) — 중등은 구매 결정자가 학부모이므로 부모 접점이 전환 트리거 ④ 고교 대비 발문 수준·LTHC 깊이 하향 조정(학년 축은 프롬프트 파라미터로, 구조 분기 금지) |
| 수익 모델 | 보급 티어 중심 + 부모 보고서가 프리미엄 업셀 트리거(`business_model.md` §2.2) |

## 제4부 — 전과목 확장 로드맵 (E1~E6): 물리에서 영어까지

### 4.0 확장의 구조적 토대 — 왜 "장대한 꿈"이 공학적으로 가능한가

확장은 소망이 아니라 이미 코드로 준비된 구조다 (`subject_expansion_readiness.md` 정본):

1. **과목 = 코드 패키지가 아니라 데이터 팩** — 신규 과목은 엔진 포크가 아니라 ①성취기준 코퍼스 ②원자·개념 팩 ③오개념 카탈로그(과목 접두 kebab: `phys-`·`chem-`·`bio-`) ④프롬프트 세트 ⑤AREA 니모닉 레지스트리의 **5종 데이터 팩 추가**다. 모노레포 재편·노드 subject 내장은 기각됨(확정 결정 C1·C3).
2. **Overlay subject 축** — 과목 스코프는 노드가 아니라 `CurriculumEntry (concept_id, country_code, subject)` 3-튜플 오버레이. 개념은 영속, 매핑만 교체.
3. **cross-subject 개념 점화 지도** — 물리 '순간속도'의 선수개념이 수학 '미분계수'인 연결은 기존 `prerequisite` 엣지가 그대로 담는다(관계 타입 신설 금지). **통합과학·통합사회 시대에 이 앱만의 해자**: 과목 간 개념 연결을 가진 학습 앱은 시장에 없다.
4. **검증기 plugin 슬롯** — SymPy 동치 커널은 유지하고 과목별 검증 축만 추가(물리: `dimensional_consistency`). 파이프라인 본체는 과목 중립.
5. **성취기준 파서가 이미 전과목 수용** — `[12물리01-01]`·`[10통과1-01-01]`·`[12화학02-03]` 등 과학과 코드 매치 실측 검증 완료(2026-07-02). 파서 개편 불요.
6. **하네스 재사용** — WH-1 튜터링·WH-S 솔버는 "재사용 + 도메인 도구만 교체"(`04a_wh1_tutoring_harness.md` §8.1). Polya 4단계·소크라테스·오개념 reactive retrieval·답 미루기는 과목 무관 교수학이다.

**공통 기회**: **2028 수능 대개편(2022 개정 교육과정)으로 통합과학·통합사회가 신설**된다 — 기출이 없는 첫 세대에게 "오개념 진단 + 개념 중심 학습"으로 진입하는 것이 전 확장의 시장 논리다(`subject_expansion_roadmap_review.md` §1 — "로드맵의 가장 강한 부분").

**저작권 위험 서열** (전 과목 확장의 순서를 규정하는 제약): **국어 ≫ 사회 > 과학 ≥ 수학**. 위험이 낮은 과목부터 진입하고, 국어는 법률 검토 예산을 선행 확보한다.

### 4.1 과목 팩 공통 실행 템플릿 (6단계 — 전 과목 반복 플레이북)

각 과목은 아래 6단계를 동일하게 밟는다. E1 물리에서 이 플레이북 자체를 검증하며, 이후 과목은 한계비용이 급감한다:

| 단계 | 내용 | 물리에서의 예 |
|---|---|---|
| ① 성취기준 수집 | NCIC 해당 교과 크롤·적재(파서 기존 재사용) + `SOURCE_CITATION` 과목 라벨 | 별책 9 과학 |
| ② 원자·개념 팩 | 과목 AREA 니모닉 등록 + 원자 백본 확장(교육적 압축 원칙 유지 — 전체 모델링 금지) | `MECH·ELEC·WAVE·THERMO·MODPHY` (예약 완료) |
| ③ 오개념 시드 | 과목 접두 kebab-id + 연구 문헌의 *분류 체계만* 참조(원문항 저작권 미사용) | `phys-` 접두, FCI 분류 체계 |
| ④ 검증 축 | SymPy 커널 유지 + 과목 검증 primitive 추가 | `dimensional_consistency(expr, expected_dim)` |
| ⑤ 시그니처 패턴·동등문제 | 수능 시그니처 방법론 재사용, 패턴 데이터만 과목 팩 | 통합과학·물리학Ⅰ 빈출 구조 |
| ⑥ 파일럿 | 측정 하네스 동일 지표(오개념 해소율·답 미루기 깊이 — 과목 중립 확인 완료)로 소규모 검증 | 물리 선택자 5~10명 |

### 4.2 E1. 물리 (2028~ · locked 1순위)

- **왜 첫 과목인가**: SymPy 동치 커널·수식 AST·그래핑 자산의 **재사용률이 전 과목 중 최대** — 확장 구조의 첫 검증은 엔진 재사용률이 가장 높은 과목으로 해야 seam의 결함이 드러난다(MEMORY 2026-07-02 확정, `subject_expansion_roadmap_review.md` §3 권장 채택).
- **신규 요소**: ①차원·단위 검증(`sympy.physics.units` 기반 형제 primitive — 커널 교체 아님) ②시각화 의존도 상승(벡터장·파동 — `VisualizationStyle` ADD VALUE, 기존 선언적 spec 체계) ③그림 중심 발문(회로도·자유물체도) OCR — 기존 하이브리드에 도해 프롬프트 축 추가 검토 ④2D 물리 시뮬레이션.
- **착수 트리거가 이미 대장에 예약됨**(`subject_expansion_readiness.md` §8): `dimensional_consistency` primitive·`Problem.subject_area` 컬럼·물리 오개념 시드·PHY AREA 실등록 — "예약된 착수 지점"이라 M6→E1 연결이 끊기지 않는다.
- **게이트**: 물리 파일럿에서 수학과 동일 지표(D7·오개념 해소율)가 수학 베이스라인 대비 유의미 열화 없음 + 과목 팩 6단계 소요 비용 실측(이후 과목 견적의 기준선).

### 4.3 E2. 화학 (2028H2~2029)

- **물리 다음인 이유**: 화학식·몰 계산·평형 상수는 SymPy 수식 검증의 연장선이고, 물리에서 검증된 과목 팩 플레이북을 **첫 재실행**하는 과목. 물리 대비 한계비용 급감을 실증하는 단계.
- **신규 요소**: 삼중 표상(거시·입자·기호) UI — 화학 교육의 핵심 표상 전환을 LearningScene DSL 과목 spec으로 수용. 분자 3D는 기존 three.js WebView 비상구 재사용.
- **오개념 자산**: `chem-` 접두. 화학은 오개념 연구 문헌이 풍부한 과목(입자 개념·보존 개념)이라 WhyMath 방법론과 정합이 높다.
- **게이트**: 과목 팩 6단계 소요가 물리 대비 50% 이하(플레이북 학습 효과 실증) + 통합과학 모드에서 물리·화학 cross-subject 진단 작동.

### 4.4 E3. 생물 (2029~) — 과학 팩 3부작 완성

- **전략적 의미**: 물리·화학·생물로 **통합과학 완전 커버**를 달성 — 2028 수능 세대의 과학 전 영역을 한 앱에서. B2B(학교) 관점에서 "수학앱"이 "수학·과학앱"이 되는 분기점.
- **구조적 특성**: 수식 검증 비중이 낮고 **개념 그래프·오개념 진단 비중이 전 과목 중 최대**(유전·진화·항상성의 오개념은 문헌상 가장 완고한 오개념군) — 계산기가 아니라 **메타인지 코어가 본체인 WhyMath에 오히려 유리한 과목**이다.
- **신규 요소**: ①검증 권위 보조 축 — 수식 동치 대신 **성취기준 근거 인용 기반 사실 검증**(RAG로 자체 코퍼스 내 근거 문장 인용 강제, 환각 시 unverifiable 보수 처리 — 3-tier 검증의 정직성 규약 유지) ②계통도·생태 네트워크 시각화 spec ③`bio-` 오개념 접두(예약 완료).
- **게이트**: 사실 검증 축의 unverifiable 비율이 허용선 이내(환각 0 원칙 유지) + 과학 3과목 통합 진단 리포트 출시.

### 4.5 E4. 역사·사회 (2029~) — 통합사회 진입

- **전략적 의미**: 2028 수능 **통합사회** 신설이 과학과 동일한 "기출 없는 세대" 기회를 제공. 저작권 위험이 국어보다 낮아(사료는 공공 저작물) 언어 과목보다 먼저 진입한다.
- **구조적 특성**: 역사 = **사건 네트워크**(원인·결과·동시성) — 새 엔진이 아니라 개념 그래프의 스키마 변형으로 소화 가능(`subject_expansion_roadmap_review.md` §1.4 판단 유지). 관계 타입 5~8개 제한 내에서 시간 축은 노드 속성으로.
- **교수학 변형**: Polya 4단계의 역사 탐구 대응 — **사료 읽기(이해) → 가설 수립(계획) → 근거 검증(실행) → 해석 성찰(반성)**. 소크라테스 발문이 "왜 그 사건이 일어났는가"에 그대로 작동 — 암기가 아닌 인과 추론 학습이 차별화.
- **신규 요소**: ①서술형 답안 평가(수식 동치 대신 근거-주장 구조 평가 — E6 영어의 선행 기술) ②사료 코퍼스(공공 아카이브·국사편찬위 라이선스 확인) ③`hist-` 계열 오개념 접두 신설(연대 혼동·인과 오귀속·현재주의).
- **게이트**: 서술형 평가의 검수자 일치율 실측 + 사료 라이선스 매트릭스 법무 확인.

### 4.6 E5. 국어 (2029H2~2030) — 최고 저작권 위험, 법률 선행

- **선행 조건 (착수 게이트)**: **법률 검토 예산·변호사 자문 선행 필수** — 문학 지문은 작가 저작물이며 위험 서열 최상(국어 ≫ 사회). 4트랙 지문 수급 전략(저작권 만료 고전·공공 텍스트·자체 창작 지문·라이선스 계약)을 법무 확인 후에만 착수.
- **진입 순서**: **비문학 독해·문법 먼저**(자체 창작 지문 가능·저작권 부담 최소) → 문학은 만료 고전부터 → 현대 문학은 라이선스 확보분만.
- **구조적 특성**: 국어 = **기능 숙련 모델**(위계 약함 — 수학의 prerequisite DAG와 다른 그래프 밀도). 오독 패턴 DB는 수식이 아닌 긴 한국어 텍스트 기반 — **임베딩 텍스트 규약의 국어판 재설계 필요**(`subject_expansion_roadmap_review.md` §6.3에 이미 등록된 항목).
- **교수학 정합**: "왜 그 답인가"를 묻는 소크라테스식 독해 코칭은 국어 사교육의 고질 문제(감으로 찍기)에 대한 정면 대안 — 브랜드 슬로건이 국어에서 가장 문자 그대로 작동한다.
- **게이트**: 지문 수급 4트랙 법무 승인 + 오독 진단의 검수자 일치율 + 독해 코칭 파일럿 D7.

### 4.7 E6. 영어 (2030~) — 최후순, 아키텍처 거리 최대

- **왜 마지막인가**: 검증 권위가 SymPy도 사실 인용도 아닌 **루브릭 기반 LLM 평가**(작문·화행의 정오가 아닌 적절성 판정) — "LLM 응답 검증 없이 학생 제공 금지" 금기와의 정합을 위해 평가자 LLM 자체의 검증 체계(PRM의 언어판)가 필요하다. 국어(E5)에서 구축한 언어 과목 인프라(지문 저작권 체계·서술 평가·텍스트 임베딩 규약)를 재사용한 뒤 착수하는 것이 한계비용 최소 경로.
- **시장 유의**: 영어는 Riiid Santa(TOEIC AI) 등 **검증된 경쟁자가 실재하는 유일한 확장 과목**(`market_positioning.md` 매트릭스) — 성인 어학이 아닌 **학교 영어(내신·수능) × 메타인지 오답 진단**으로 포지셔닝을 한정해 정면 충돌 회피.
- **신규 요소**: ①루브릭 평가 하네스(WH-1 변형 — 평가 근거 강제 인용) ②음성 축(듣기·말하기 — v3.0 음성 면접 시뮬레이션 자산 재사용) ③`eng-` 오개념 접두(모국어 간섭·문법 과잉일반화).
- **게이트**: 루브릭 평가의 인간 채점자 일치율(Cohen's κ 목표치 사전 정의) + 학교 영어 파일럿.

> **실행 명세**: 각 과목의 데이터 팩 상세·검증 축·게이트 지표·과목당 소요 모델은 `docs/strategy/subject_expansion_e_axis_v1.md`(E축 실행 로드맵)에 정본화.

### 4.8 E축 공통 원칙 (전 과목 협상 불가)

1. **순서는 게이트가 결정한다** — 연도는 추정이며, 직전 과목의 파일럿 게이트 미통과 시 다음 과목 착수 금지.
2. **과목마다 도메인 검수자 트랙 별도 확보** — 수학 파트너가 물리를 검수하지 않는다.
3. **오개념 카탈로그는 과목 접두로 단일 DB 공존**, cross-subject 코사인 검색은 거버넌스 테스트가 차단(임베딩 subject 축 — 구현 완료).
4. **교육적으로 압축된 인지 그래프만** — 과목이 늘어도 "전체를 모델링하지 말라"는 제1원칙과 Minimal Reasoning Subgraph 예산(depth ≤ 2·nodes ≤ 12~20·tokens ≤ 3000)은 불변.
5. **신규 과목의 저작권 매트릭스를 `licensing_safety.md`에 선행 등록** — 콘텐츠 1건 생성 전에.


### 6.2 구조적 리스크와 헤지의 논리

- **사람 병목 2건**(Phaiakes9 라이브 검증·도메인 파트너)이 현재 크리티컬 패스 — AI 개발 속도와 무관하게 Kiki 수동 시간을 여기에 우선 배정.
- **인구 절벽**: K-12 시장 축소는 구조적 상수 — 헤지가 곧 본 계획의 뼈대다: **① 대학 과정(M5, LTV 연장) ② 전과목 확장(E축, 학생당 커버리지 확대) ③ 글로벌(Phase 5 — 영문화·베트남·인도, 한국 데이터셋 라이선싱)**.
- **2028 수능 대개편**: 리스크이자 최대 기회 — v2.0이 대응하고, 통합과학·통합사회 신설이 E1~E4의 진입 논리. 평가원·교육부 공고 재확인을 전 Phase 상설 체크로.
- **저작권**: 유일하게 "나중에 못 고치는" 유형 — 현재 위험 소스 0건 유지, E축 과목별 매트릭스 선행 등록, 국어는 법률 예산 선확보.
- **정체성 리스크**: 확장 과정에서 "게임화·답 빠르게" 유혹은 상수 — CLAUDE.md 의사결정 우선순위(학생 안전 > 법 > 교수학 > 학습효과 > UX > 비용 > 속도)는 전 과목·전 Phase에서 협상 불가.

### 6.3 당장의 다음 액션 (이 문서 채택 직후)

1. **S1 탈출**: Phaiakes9 라이브 키 투입 → 비용 실측 → 실기기 1루프 완주 시연 (Kiki)

3. S2 동등문제 100문 파이프라인 가동 (AI 자동화 가능 구간)
4. 가격 WTP 조사 설계를 β 온보딩에 내장 (M2 가격 단일 결정의 입력)
