## §3. 60/90일 게이트 (정본 참조 — 재정의 금지)

게이트의 상세·체크리스트·탈출 조건은 `status_roadmap_2026-07.md` §3이 정본. 여기서는 순서만.

```
[현재] S1 E2E 수직 슬라이스 (진행 중·라이브 대기)
   └ 탈출: 실기기 1루프 15분 내 완주 시연 + 루프당 LLM 비용 실측 + 학생응답 전부 PRM/도구 검증 통과 증명
        ↓ (K1 선행)
[30~60일] S2 콘텐츠 공장
   └ 탈출: 검증 동등문제 100문+ + 검수자 1인 샘플 30문 검토 + 평가원 유사도 저작권 게이트 통과
        ↓ (K2 선행)
[60~90일] S3 수능 모드 심화 + 파일럿
   └ 탈출: KPI 베이스라인 실측 + 시범 사용자 재사용 의향 ≥ 60% + 세션당 비용 손익 범위 내
        ↓
[이후] S4 K-12 완성 → S5 타과목 확장 게이트(=M6)
```

**Phase 1 종료 게이트**(=M1, `ROADMAP.md`): **D7 재방문 ≥ 30%**(최상위 가정) · 답 미루기 평균 2.5+ · LLM 비용 학생당 월 1,000원 이하 · 도메인 검수 통과.
