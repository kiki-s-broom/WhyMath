## 폴더 구조

작업 하나 = 폴더 하나 = 세션 하나다. **폴더 이름 = 지시문 파일 이름 = 세션 이름**이다.

- `00_README.md` — 이 파일(순서·시작 조건·Kiki 결정 대기)
- `P3R-01_PED-17_학습단계404_생성폴백결정/`
  - `P3R-01_PED-17_학습단계404_생성폴백결정.txt` — 붙여넣을 지시문(파일 전체)
  - `README.md` — 상태·시작 조건·완료 판정·세션 종료 후 체크(Kiki용)
- `P3R-02_P3-44_4개념_보강은행/` … `P3R-10_통합재판정_판정전용/` — 같은 구성

`P3R`는 "P3 Release"의 약자다. 지시문 파일의 첫 줄이 `[세션 이름] P3R-…`이고, 지시문은 첫 단계로 **세션 제목을 그 이름으로 바꾼다**(세션 제목 도구가 있을 때 — 없으면 첫 보고 첫 줄에 이름을 적는다). 세션 목록에서 어느 지시문의 세션인지 바로 구분된다. 같은 작업을 결정 뒤에 다시 돌리면 같은 이름의 세션이 하나 더 생긴다 — 정상이다.

## 쓰는 법 (3단계)

1. 아래 표에서 **"지금 시작 가능"** 열이 예인 폴더를 연다.
2. 폴더 안의 `P3R-….txt` 파일을 열어 **전체를 복사**(Ctrl+A → Ctrl+C)한 뒤 새 세션 첫 메시지로 붙인다. 공통 프리앰블이 이미 파일 앞부분에 들어 있다. **한 세션 = 한 파일**이다.
3. 세션이 끝나면 같은 폴더의 `README.md` 체크리스트로 결과를 확인한다. **Kiki 결정 필요** 표시가 나오면 결정한 뒤 같은 파일을 새 세션에 다시 붙인다(지시문이 스스로 다음 단계를 고른다).

> ✅ P3R-10(재판정)은 반드시 P3R-01~09를 구현한 세션과 **다른 새 세션**에서 쓴다.
