## 쓰는 법 (3단계)

1. 아래 표에서 **"지금 시작 가능"** 열이 예인 파일을 연다.
2. 파일 안의 `text` 블록 **전체**를 복사해 새 세션 첫 메시지로 붙인다. 공통 프리앰블이 이미 앞에 합쳐져 있다. **한 세션 = 한 파일**이다.
3. 세션이 끝나면 파일 하단의 체크리스트로 결과를 확인한다. **Kiki 결정 필요** 표시가 나오면 결정한 뒤 같은 파일을 새 세션에 다시 붙인다(블록이 스스로 다음 단계를 고른다).

> ✅ 10번(재판정)은 반드시 01~09를 구현한 세션과 **다른 새 세션**에서 쓴다.
