## 2. 사용한 독립 계산 규칙 (발문 텍스트만 파싱, 한국 교과 통상 해석)

1. polynomial_arithmetic — `P(x)=…, Q(x)=…`를 SymPy로 파싱, 연산자(+,-,*) 적용(P-Q, 순서 보존) 후 Poly 계수 추출. "x의 계수"=1차항 계수, "x^n의 계수"=n차항 계수, "상수의 계수"=상수항(대안 해석 없음).
2. polynomial_factoring — 이차식의 근을 SymPy로 구해 (x+p)(x+q)에서 p=-근. p>q로 정렬해 "더 큰"=p, "더 작은"=q (부호 있는 값 비교; 발문이 (x+p)로 부호를 못박음). 정수 서로 다른 두 근이 아니면 발문 성립 불가.
3. linear_inequality_system — 각 부등식을 a x+b ⋛ c로 분해, a<0이면 부등호 반전, 경계=(c-b)/a. 해집합=(max 하한, min 상한) 열린구간. "더 큰 값"=상한, "더 작은 값"=하한. 두 부등식이 같은 방향이거나 공집합이면 "두 경계값" 정의 불가 → 발문 성립 불가로 별도 집계.
4. quad_ineq — (좌변-우변)의 이차 다항식에서 판별식>0 확인 후 SymPy solve로 두 실근을 구해 합산. 해 구간 위치(바깥/안쪽)=(선행계수>0)==(부등호가 ">")로 독립 도출해 answer_explanation의 "바깥쪽/안쪽"과 대조.
5. middle_function — f(x)를 파싱해 x=a 대입. "일차함수" 표기 시 기울기≠0 확인.
6. radian_conversion — 도→라디안: d/180·pi, 저장 answer와 SymPy 동치 비교 + 기약 표기(gcd=1) 확인. 라디안→도: 식×180/pi.
7. complex_number_arithmetic — z1,z2를 SymPy 복소수로 파싱, 연산 후 실수부 re / 허수부 im(계수 b, "bi"가 아님) 추출.
8. matrix_ops — 2x2 정수행렬 파싱, 합/차/AB/kA 계산, "(r행 c열)"=M[r-1][c-1]. 대안(전치 인덱스·BA·원소별 곱) 일치 여부는 불일치 시 태그로 기록.
9. 발문↔answer_explanation: 연산어(더하면/빼면/분배법칙/합/뺀/스칼라배), 설명 속 수식·숫자(인수분해 곱 전개 일치, 설명의 x>A/x<B가 발문 풀이와 일치, 설명 속 f식·대입값, 행/열 위치와 피연산자 값, 기약분수 표기, 실수부/허수부 지시)를 재계산과 대조. 전 코퍼스 설명 불일치 0건(초기 실행 시 matrix 80건 불일치는 감사 스크립트의 정규식 버그 — 설명문에 k가 두 번 등장 — 로 판명되어 스크립트를 고쳤고 재실행해 0건).

## 3. 불일치/모호 대표 예시

불일치 0건, 해석 모호 0건, 미검증 0건, 발문 성립 불가 0건이므로 제시할 예시가 없다. 근거 없는 "일치" 단정을 피하기 위해 아래 두 가지를 별도로 기록한다.

(a) 의미 일치와 별개인 표현상 관찰(오답 아님, 불일치로 계상하지 않음)
- polynomial_arithmetic: 706행(47%)이 "상수의 계수"를 사용. 교과서 표준 용어는 "상수항". 계산 결과는 상수항과 일치(대안 해석 없음). 예: "두 다항식 P(x) = 2x + 6, Q(x) = -3x에 대하여 P(x) + Q(x)에서 상수의 계수를 구하시오." 저장 6, 독립 계산 6.
- matrix_ops: "각 성분에 1를 곱한 행렬 1A"(조사 "1을" 오류, k=1 자명 문항 9행 포함), 설명 "6 - -1 = 7"(이중 부호 표기). 값은 일치.
- complex: 허수부=b(계수)로 저장(한국 교과 표기 a+bi의 b). 대안 해석 "bi"는 저장 형식(숫자)과 양립 불가하므로 모호로 계상하지 않음.

(b) 어휘는 있으나 데이터가 그 분기를 한 번도 밟지 않는 곳 — 대조 통과가 "그 분기 정확"의 증거가 아님
- linear_inequality_system: 600행 전부 (첫째 ">", 둘째 "<"), x 계수 전부 양수. 음수 계수로 부등호가 반전되는 분기·같은 방향 부등식·공집합 분기는 코퍼스에 0행. 대조기는 그 분기를 구현했지만(음수계수 태그 0건) 이번 데이터로는 검증되지 않음.
- quad_ineq: 200행 전부 선행계수>0, 우변 0, 판별식>0. 선행계수<0일 때 "바깥/안쪽" 뒤집힘 분기는 0행. 부등호 방향(>,<)은 각 100행씩 모두 존재하며 설명의 바깥쪽/안쪽 판정이 독립 도출과 200/200 일치. 참고: "두 경계값의 합"은 부등호 방향과 무관하게 같은 값이므로 answer 대조만으로는 방향 오해석을 못 잡고, 설명문의 바깥쪽/안쪽 대조가 유일한 방향 검사이다(아래 뮤테이션 참조).
- 해석 모호 후보 프로브: factoring의 "더 큰 값"을 절댓값으로 읽으면 302/600행이 달라지지만, 발문이 (x+p)(x+q),(p>q)로 부호 값을 명시하므로 AMBIG로 계상하지 않음.
