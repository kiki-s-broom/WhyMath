## 3. 사용한 독립 계산 규칙

- binomial: B(n,p) 평균 = np, 분산 = np(1−p).
- sample_mean: 표본평균의 평균 = 모평균, 분산 = 모분산/n. 발문 "모분산이 #"을 분산으로 읽음(표준편차 해석은 문구상 불가).
- discrete_ev: E(X) = Σ x·P(X=x). 확률합 = 1, X값 중복 없음도 함께 검사.
- probability_law: 합사건 a+b−c(프레셰 경계 max(0,a+b−1) ≤ c ≤ min(a,b) 실현성 검사 포함), "A일 때 B의 조건부확률"은 P(A)·P(B|A), 여사건 1−P(A).
- combination_binomial: "n가지 종류 중 중복 허락 r개를 고르는/택하는" = 중복조합 H(n,r)=C(n+r−1,r). (x+y)^n의 x^a y^b 계수 = C(n,a)(a+b=n 검사, 아니면 0).
- permutation_combination: 동시에 일어날 수 없는 A 또는 B = 합, A와 B가 연이어 = 곱, "서로 다른 n개에서 r개를 뽑아/택하여 순서대로 세우는/일렬로 나열" = nPr.
- probability_finite: 주사위 36가지·동전 2^n·주머니 C(N,k)를 itertools 로 전수 열거해 확률/경우의 수 계산. 발문의 "정확히 k번"은 ==, "N 이상"은 ≥. 기약분수 요구 문항은 저장 answer 가 기약분수 표기인지도 검사.
- coordinate: 거리 = √((Δx)²+(Δy)²), 직선 y=ax+b에서 a=Δy/Δx, b=y1−a·x1, 정답은 a+b.
- conic: 포물선 y²=kx의 초점 x좌표 = k/4, 타원 x²/a²+y²/b²=1(a²>b²)의 c=√(a²−b²), 쌍곡선 c=√(a²+b²).
- vector: AB = B−A의 성분 합. 선형결합은 계수식("−a − 2b", "4a − 4b" 등)을 직접 파싱해 x·y 성분을 각각 구해 합.
- 해설 대조: 템플릿 종류별 필수 어구(예: 평균은 np / 분산은 np(1-p) / 합의 법칙 / 곱의 법칙 / 덧셈정리 / 곱셈정리 / 여사건 / 중복조합 / "도착점 B의 좌표에서 출발점 A의 좌표를 빼" / 타원 "뺀"·쌍곡선 "더한")과 상충 어구 부재, 해설 속 결론 수치가 저장 answer 와 일치하는지, probability_finite 해설의 "전체 N가지·해당 K가지"가 독립 열거 (N,K)와 일치하는지.

## 4. 검사기 변별력 확인(`--selftest`)

- 저장 answer 를 +1 로 오염: 10개 코퍼스 전건에서 MISMATCH 또는 AMBIG 로 검출(compared 행 수와 동일). 이 중 combination_binomial 은 1행이 AMBIG 로 분류됐다. 오염값이 중복순열/조합 값과 우연히 같아진 경우이며 검출 자체는 됐다.
- 해설을 다른 행의 것으로 교체: 달라진 행의 90% 이상을 해설 불일치로 검출(최저 198/200, 대부분 100%).
- 즉 "불일치 0"은 검사기가 아무것도 못 잡아서가 아니라, 오염 주입 시에는 잡히는 검사기가 실제 데이터에서는 0건을 냈다는 뜻이다.

## 5. 불일치/모호 대표 예시

불일치 0건이라 제시할 불일치 예시가 없다. 대신 해석이 갈릴 수 있는 어구에 대해 "저장값이 어느 해석과 일치하는지"를 실측한 결과를 적는다.

1. 중복조합 vs 중복순열 (combination_binomial, "중복을 허락하여 r개를 고르는/택하는", 56행)
   - 예: "서로 다른 종류의 사탕 7가지 중에서 중복을 허락하여 4개를 택하는 경우의 수를 구하시오." → 저장 210, 독립 계산 H(7,4)=C(10,4)=210.
   - 중복순열 7⁴=2401, 조합 C(7,4)=35 로 읽으면 값이 갈리는 행이 49행(나머지 7행은 r=1 등으로 해석 간 값이 같음). 저장값이 중복순열/조합 값과 일치한 행은 0건, 전부 중복조합과 일치한다. 한국 교과서 관례("고르는/택하는"=조합 계열)에 부합.
2. "연이어" = 곱의 법칙 (permutation_combination, 60행): 예 "A 6가지, B 9가지, A, B가 연이어 일어나는 경우의 수" → 54(곱). 합 15 로 읽는 해석은 발문의 "그와 상관없이 … 연이어"로 배제됨. 저장 60/60 곱과 일치.
3. 동전 "앞면이 정확히 k번" (probability_finite, 9행): 예 3번 던져 정확히 0번 → 1/8 일치. "적어도 0번"(=1)로 읽은 저장값은 0건.
4. 합 "N 이상"(경우의 수, 8행): 예 합이 4 이상 → 33(≥) 일치. ">"(초과)나 주사위 비구별(순서 무시) 해석과 일치한 저장값은 0건.
5. 조건부확률 방향 (probability_law, "A가 일어났을 때 B가 일어날 조건부확률", 150행): 저장값 = P(A)·P(B|A) 와 150/150 일치. 해설도 "곱셈정리"로 일치.

## 6. 발문↔해설 불일치

- 전 코퍼스 0건 (필수 어구 누락 0, 상충 어구 0, 해설 속 수치와 저장 answer 불일치 0, probability_finite 해설 N/K 와 독립 열거 불일치 0).
- 해설이 담는 내용이 정형 문장 + 결론 수치뿐이라 구조적으로 어긋날 여지가 작다는 점은 한계에 적었다.

## 7. 부수 관찰(의미 불일치는 아님, 참고)

- `answer_format` 표기: coordinate_geometry 200행("실수")과 vector_operations 196행("실수")은 answer 가 정수 문자열이다. discrete_ev 28행은 answer_format="분수"인데 answer 가 정수 문자열이다. 계산 의미와 무관한 표기 메타데이터 불일치이며 의미 불일치 건수에는 넣지 않았다.
- QUAL-11 의 반올림 부류처럼 "자리 단위/방향/포함 여부" 어휘(반올림·올림·이상·초과 등 경계 포함 판정)가 걸린 템플릿은 이 10개 코퍼스에서 probability_finite 의 "N 이상" 1개뿐이었다.

## 8. 한계

- 독립 계산의 기준이 "한국 고교 통상 해석"이라 내가 같은 오개념을 공유하면 그 항목은 일치로 나온다. 이를 줄이려고 각 어구마다 대안 해석값(중복순열, 적어도, 초과, 비구별, A−B 방향, 합/곱 뒤바꿈, 모분산 그대로 등)을 같이 계산했고, 저장값이 대안 해석과 일치한 행이 0건임을 확인했다. 단, 이는 "대안 해석 목록에 든 것"에 한한다.
- 이 코퍼스들의 발문은 정형 템플릿(65종)에 어휘가 이미 고정돼 있어 자연어 변이가 작다. 파싱은 템플릿 정규식 기반이라 코퍼스에 새 문형이 추가되면 "미검증"으로 떨어지게 설계했다(공허 통과 없음).
- 해설 대조는 키워드·수치 일치 수준이다. 해설 문장의 논리적 정당성 전체를 검증하지는 않는다.
- `verify.conditions`(생성기가 SymPy 로 검증하는 조건식)는 이번 대조에서 쓰지 않았다. 발문→정답 독립 경로만 사용했다.
- 지정된 10개 코퍼스에 한정한다. 다른 코퍼스(예: 초등 어림 외 템플릿 코퍼스)는 이 슬라이스 범위가 아니다.
