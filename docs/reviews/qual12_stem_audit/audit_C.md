## 3. 사용한 독립 계산 규칙

공통: 수식 문자열은 직접 만든 토크나이저(`to_py`)로 암묵적 곱 삽입·`^`→`**` 변환 후 SymPy `sympify(rational=True)`. 저장 `answer` 는 정수/분수 문자열만 허용(7개 코퍼스 전부 해당). 해석이 갈릴 수 있는 곳은 통상 해석을 기준값으로 삼고 대안 해석도 함께 계산해 §4 에 기록했다.

### 적분 2종
- 부정적분 F(0)=c, F(m) = c + ∫₀ᵐ f.
- `정적분 [a,b]` / `(구간 [a,b]에서의)` = ∫ₐᵇ f. (a≥b 이면 비고 기록; 실제로 a≥b 인 행 0건 — 넓이·거리 문항의 두 직선/시각 끝점도 별도 확인해 a<b 전건)
- **넓이** = ∫ₐᵇ |f| (영점에서 구간을 쪼개 부호별 적분. 다항식은 실근, 사인은 π/2 격자 중 값이 0 인 점). 대안: 부호 있는 ∫f.
- **이동 거리** = ∫ₐᵇ |v| (총 이동 거리). 대안: 위치변화량 ∫v.
- 해설의 "항상 x축 위 / 속도가 항상 양수" 주장을 구간 부호 검사로 검증.

### 몫·곱·연쇄 미분
- f'(a) = (d/dx f)(a). 분모가 a 에서 0 이면 미검증으로 센다(0건).
- 해설의 "x=a에서 계산하면 f'(a)의 값은 V" 의 a, V 를 발문·answer 와 대조.

### 시그마
- 직접 합산 Σ_{k=1}^{N}(식), Σ(A·k+B), Σk², Σk³ 을 정수 루프로 직접 합산 (공식 사용 안 함). 발문 상한 N 과 `k=1부터 N까지` 상한, 해설 `1부터 N까지의 합은 V` 일치도 대조.

### P3 미분 (핸들러 157계열)
- 도함수 값 계열: 직접 미분 후 대입. 미지 상수(a, b, k, p, c, n …)가 있으면 방정식을 세워 `sp.solve`, 조건(양수·0이 아님·x>0 등)으로 해를 거르고 해가 정확히 1개가 아니면 "해 개수" 사유로 모호/불일치 처리.
- **극값**: f'=0 의 실근 중 **좌우 f' 부호가 바뀌는 점만** 극값. 극대=(+→−), 극소=(−→+). "x좌표 중 큰/작은 값", "두 극솟값 중 작은 값"은 해당 극점 값들에서 선택. "x=p에서 극솟값 v를 가질 때"는 f'(p)=0, f(p)=v 연립 해를 구한 뒤 p 가 실제 극소(극대)인지 부호변화로 재확인.
- **증가/감소 범위의 정수**: f'>0(<0) 구간을 만들고 열린구간·닫힌구간 두 해석 모두로 정수를 센다. 둘이 다르면 모호.
- **접선**: 기울기 f'(a), 접선 y=f'(a)(x−a)+f(a), y절편·x절편·삼각형 넓이 ½|x절편·y절편|, 평행(기울기 같음)/수직(기울기 곱 −1, 직선은 y 에 대해 풀어 기울기 추출), 외부점에서의 접선은 접점 a 에 대한 방정식 f(a)+f'(a)(px−a)=py. 발문의 점 (p,q)가 곡선 위에 있는지도 매번 확인.
- **평균값 정리/롤**: f'(c) = (f(b)−f(a))/(b−a) 의 해 중 **열린구간 (a,b)** 안의 해. 닫힌구간 포함 시 해 개수도 함께 기록. 롤은 f(a)=f(b) 전제를 먼저 검증. "f'(x)≥B, f(a)=v 일 때 f(b)의 최소/최대" 는 (b−a) 부호와 부등호 방향으로 하한/상한 존재 여부를 판정.
- **방정식 응용**: 서로 다른 실근의 개수 = 서로 다른 실근 수(중근 1개), "…임을 보이려 한다 최솟값" 은 문장에 명시된 최종 식을 직접 파싱해 정의역(전체/x≥0/x>0)에서 최소화하고 ①최솟값이 실제로 달성되는지(열린 정의역 경계 하한이면 불일치) ②전제 부등식(차 > 0)이 성립하는지를 검증.
- **속도/가속도**: v=x', a=x''. 평균속도=순간속도는 평균값 정리와 동일 처리. "운동 방향을 바꾸는 시각"은 v 가 부호를 바꾸는 t≥0 의 근을 오름차순으로 센다 (v=0 이지만 부호 불변인 근은 제외, t=0 근 존재 시 순번 해석 모호로 표기). "처음 방향 전환 시각의 위치/두 번째 방향 전환의 가속도"는 해당 t 를 x(t), x''(t) 에 대입.
- 객관식 84행: 독립 계산값이 정수·분수 보기 중 정확히 1개와 일치하고 `answer` 가 그 보기와 같은지(`8√3` 같은 무리수 보기는 오답 보기로 간주해 비교 대상에서 제외).

**대표 사례 5건** (불일치/모호는 0건이라 이 절에서는 "해석이 갈릴 수 있었는데 저장값이 통상 해석을 따른 행"을 든다):

1. P3-GRAPH-SHAPE — `함수 f(x) = -2x^3(x - 4)가 극값을 갖는 x좌표는?` 저장 `3`. 독립 계산: f'=−8x²(x−3), 근 {0,3}, x=0 은 중근이라 부호 불변이므로 극값 아님 → 3. 대안(f'=0 근 전부)이면 {0,3} 두 개라 단일 답 불가.
2. P3-GRAPH-SHAPE — `함수 f(x) = x^3(x + 4)가 극값을 갖는 x좌표는?` 저장 `-3`. f'=x²(4x+12), 근 {−3, 0}, x=0 은 부호 불변 → −3.
3. P3-GRAPH-SHAPE — `곡선 y = -2x^4 + 16x^3 - 4에서 증가·감소가 바뀌는 점의 x좌표는?` 저장 `6`. f'=−8x²(x−6), x=0 중근 제외 → 6.
4. P3-MEAN-VALUE-THEOREM — `수직선 위를 움직이는 점 P의 시각 t에서의 위치가 x = -t^3 + 6t^2 - 2t + 4일 때, t = 0에서 t = 6까지의 평균속도와 순간속도가 같아지는 시각 t (0 < t < 6)의 값을 구하시오.` 저장 `4`. 평균속도 −2, v=−3t²+12t−2=−2 → t∈{0,4}, 끝점 t=0 은 발문의 `0 < t < 6` 으로 제외 → 4.
5. P3-GRAPH-SHAPE — `함수 f(x) = 3x^4 - 4x^3 - 6이 극값을 갖는 x좌표는?` 저장 `1`. f'=12x²(x−1), 근 {0,1}, 부호 변화는 x=1 에서만 → 1.

## 6. 발문 ↔ 해설 불일치

- 정형 해설 코퍼스(적분 2종·미분 3종·시그마, 1,412행)는 최종값·평가점·상한을 발문/answer 와 대조해 **불일치 0건**.
- P3 해설 504행은 서술형이라 최종값 일치까지는 자동 대조하지 못하고, ①answer 숫자 토큰 포함 504/504 ②해설 속 `f'(x)=<식>` 252식이 실제 도함수와 일치 252/252 만 확인했다. 해설 서술(예: "a=6 또는 a=−6 이고 양수이므로")의 논리 전개는 자동 검증하지 않았다.
- 사소한 문면 관찰(의미 불일치 아님·미측정): 적분 코퍼스 부정적분 해설은 발문에 없는 기호 `m` 을 쓴다(`F(m)의 값은 F(0)에 x=0부터 x=m까지의 정적분을 더한 값…`), 시그마 일부 템플릿 문형이 어색(`…값들을 모두 합을 구하시오`), 해설의 "반도함수" 용어가 교과 표준(부정적분/역도함수)인지는 확인하지 않았다.

## 7. 한계

1. **독립성의 한계**: 계산 엔진이 생성기와 같은 계열(SymPy)이다. 막은 것은 "생성기가 만든 식과 발문 문장이 다르다"(문장→식 해석 불일치)이지 "SymPy 가 틀리다"가 아니다. 파서/규칙은 내가 새로 짰으므로 생성기의 문장 생성 코드와는 공유하는 코드가 없지만, **한국 교과 관례에 대한 내 해석(극값=부호 변화, 넓이=∫|f|, 거리=∫|v|, 평균값 정리의 c 는 열린구간, "서로 다른"은 중근을 한 번만 셈)이 틀렸다면 같은 방향으로 틀린 채 일치로 보일 수 있다.** 이 해석들은 §4 에서 대안 해석과 나란히 계산해 두었으므로 쟁점이 되면 즉시 갈아 끼울 수 있다.
2. **구간 부호가 한 방향뿐**: 적분 코퍼스 넓이·거리 문항(230행)은 피적분 함수가 구간에서 항상 양수라 "넓이=∫|f| vs ∫f", "거리 vs 변위" 해석이 갈리지 않는다. 즉 이 코퍼스는 그 어휘의 해석 일치성을 구별해 낼 수 없다 (일치하지만, 해석을 시험하는 데이터가 아님). 생성기를 구간 부호가 바뀌게 확장하면 해설 문구 "항상 x축 위"가 거짓이 되므로 별도 검사가 필요하다.
3. **미커버**: 이 슬라이스는 코퍼스에 이미 들어 있는 문항만 본다. 생성기가 다른 시드에서 만들 수 있는 문항(예: 몫 코퍼스의 분모 0 점, 방향 전환 근이 t=0 인 경우)은 현재 코퍼스에 없다.
4. **자동 대조 불가 영역**: P3 해설 서사(§6), `distractor_map` 의 `misconception_id` 가 실제 그 오개념 풀이로 얻은 값인지, 발문 한국어 문장의 문법/교과 용어 적합성은 측정하지 않았다 (`distractor_map` 은 `choice_index` 범위와 정답 비지목만 확인).
5. 파싱 불가/독립 계산 불가 행은 "통과"가 아니라 "미검증"으로 세도록 구현했고 이번 실행의 미검증은 0건이다. 핸들러가 미인식 발문을 만나면 `Unverified`, 예외는 모두 미검증으로 떨어지며 종료 코드 3 으로 알린다.
