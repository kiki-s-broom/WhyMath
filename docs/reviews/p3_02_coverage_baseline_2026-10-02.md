## 2. 정의 — 코드 한 곳이 정본이다

정본은 `phase3_coverage.py` 모듈 docstring 과 `_facts`·`_completeness_links` 이다. 아래는 그 요약이다.

기호: c = 분모의 핵심 개념 · skills(c) = c 의 원자 행동 스킬 ∩ 명세 스킬 · 적격 문항(c) = 검수 상태가 `approved` 이고

| 지표 | 정의 | 분모 | 목표(명세) |
|---|---|---|---|
| Content Coverage Rate | 개념 콘텐츠 행이 있고 ∧ 스킬 연결된 문항이 1건 이상인 개념 비율 | 핵심 개념 | ≥ 95% |

### 2.1 "스킬을 매개로" 이어져야 하는 이유

"개념에 스킬이 있다"와 "개념에 문항이 있다"를 따로 세면 서로 무관한 두 사실이 '연결'로 계상된다. 같은 스킬을 매개로
개념과 문항이 이어져야 연결이다. 문항의 스킬은 문제유형 코드가 가리키는 문제유형의 행동 스킬 합집합이다.

### 2.2 CONT-05 판정 — 택 ⓑ (연결과 공급 가능을 병기)

학생 공급은 `review_status == "reviewed"` 인 개념 콘텐츠만 통과한다(`l4/content_supply.py`). 개념 콘텐츠 437행이
전건 `ai_estimated` 이므로 검수 전 콘텐츠를 '연결됨'으로 세면 **"커버리지 95% 인데 학생 공급 0%"** 가 성립한다.

- Content Coverage Rate 는 검수와 **무관**하다 — P3-03 이 채우는 대상이 연결이므로, 사람 서명(검수 승격) 없이도 채움의
  진척을 잴 수 있어야 한다. 명세 목표 0.95 의 대상이다.
- 공급 가능 커버리지는 CONT-05 의 단일 정본 술어(`review_gate.is_supply_eligible`)를 그대로 쓴다. **명세에 목표가 없어
  exit code 에 영향을 주지 않는다** — 승격 시점은 Kiki 서명(`G-kg02-review-promotion-llm-session`)이 정한다.
- 두 수치가 벌어지면 출력이 경고 줄로 그 차이를 적는다.

ⓐ(검수 통과만 센다)를 택하지 않은 이유: P3-03 의 완료 판정(Content Coverage ≥ 95%)이 사람 서명에 막힌다. ⓒ(검수 무관으로
세되 이유만 명문화)를 택하지 않은 이유: 병기하지 않으면 두 수치의 벌어짐이 출력에서 안 보인다.

### 2.3 Concept Completeness 의 재설계 (acceptance ④ · ARCH-43)

원 문서의 정의("Prerequisite·Misconception·Solution·Hint·Pedagogy가 모두 연결된 비율")를 필드가 비어 있지 않은지로
구현하면 ARCH-43 이 이미 기각한 형태가 된다 — 임의 문자열을 받는 필드는 어떤 개념이든 채워지므로 성공/실패 양쪽에서
같은 값을 내고 반증력이 0 이다. 그래서 각 연결을 **다른 코퍼스에 실재하는 개체로 해석되는 관계**로 정의했다.

| 연결 | 정의 |
|---|---|
| prerequisite | 개념의 원자로 들어오는 선수 간선이 있고, 그 간선의 시작 원자가 원자 백본에 실재한다(자기 루프 제외) |
| misconception | 명세의 핵심 오개념 중 이 개념에 귀속된 M-id 가 오개념 코퍼스에 실재하고 귀속 성취기준이 일치한다 |
| solution | 적격 문항 중 해설과 풀이 단계가 둘 다 있는 문항이 있다 |
| hint | 힌트가 달린 적격 문항이 있다 — **현재 측정 불가**(좌석 부재, §6) |
| pedagogy | 이 개념의 원자를 목표로 삼는 단원 DSL 학습 목표가 있고 그 목표의 지식 유형에 stub 이 아닌 교수 팩이 있다 |

**반증력의 증거 4가지**: ① 기준선에서 이미 미충족을 낸다 ② 개념별로 무엇이 빠졌는지 적는다 ③ 연결을 하나씩 끊는
주입이 수치를 떨어뜨린다(§5) ④ **고립된 개념(코퍼스에 이웃이 없는 개념)이 5종 전부 missing 으로 나온다** — 필드 채움
검사가 통과시키던 바로 그 대조군이다(`test_isolated_concept_has_all_five_links_missing`).

연결 상태는 linked · missing · unmeasured 3가지이고 **측정 불가는 충족이 아니다**.

## 4. 이 기준선이 P3-03 에 넘기는 것

- **Content Coverage 를 올리는 길은 문항 연결이다.** 7개 개념(`-03`~`-06`·`-08`~`-10`)에 승인된 PRIMARY 문항이 0건이다.
  나머지 3개는 이미 연결돼 있다. 목표 95% 는 분모 10 에서 10/10 을 뜻한다(9/10 = 90%).
- **문항을 채울 때 스킬을 매개로 이어져야 센다.** 문항의 문제유형이 개념의 스킬과 겹쳐야 한다.
- **Pedagogy 는 0/10 이다.** 개념에 교수 경로가 붙는 간선이 단원 DSL 학습 목표뿐인데 `data/corpus/units_v1/` 에는 미분
  단원이 없다(1개 파일, `[10공수1-02-06]` 4개 목표).
- **공급 가능 커버리지는 Content 를 채워도 안 오른다** — 검수 승격은 사람 서명의 몫이다.

### 5.1 절 단위 뮤테이션 — 48종 전건 검출

계측기 소스의 절을 일부러 깨뜨렸다(순수 파이썬 하네스 · 치환 건수 1건 단언 · 변경 확인 · 컴파일 확인 · **바이트 동일 원복
sha256 단언** · 대조군 exit 0 선행 확인). 결과: **48종 중 검출 48 · 생존 0 · 하네스 결함 0.** 검출한 테스트는 각 변이를
겨냥해 쓴 것이다(예: 스킬 필터 제거 → `test_skills_outside_the_spec_do_not_link`).

이 숫자는 **내가 열거한 절**의 검출률이다. 열거하지 않은 절(출력 문구의 분기 일부 · JSON 키 순서 · `render` 의 서식)은
뮤테이션으로 확인하지 않았다. 또한 실제 데이터에서 효과가 없어 동등 변이가 될 절(스킬 필터 · 리프 원자 필터 · 오개념 개념
코드 일치)은 **그 절이 없을 때 통과하는 입력을 따로 만들어** 검출되게 했다(`TestDefinitionsBite`).

## 6. 정직한 공백

1. **힌트 연결은 측정 불가다.** 힌트의 저장 좌석이 없다 — ARCH-39 가 '영구 부재'로 판정했고, 지시문 [07] 의 Problem 필수
   7필드 중 hint strategy 의 좌석은 `P3-04` 가 정한다. 그래서 **Concept Completeness 는 좌석이 생기기 전에는 충족될 수
   없다**(측정 불가는 충족이 아니다). 후속: `P3-22-coverage-hint-source-wiring` 을 등재했다.
2. **Misconception → Pedagogy 간선이 코퍼스에 없다.** 오개념의 오류 유형 어휘와 교수 전략이 적는 적합 오류 유형 어휘의
   교집합이 0 이다(어휘 문자열 대조뿐 — 런타임 소비 경로는 보지 않았다). 그래서 Graph Connectivity 의 마지막 고리는
   개념 단위로 판정한다. 후속: `P3-23-misconception-pedagogy-edge-vocabulary`(간선 필요 여부 판정)를 등재했다.
3. **풀이의 수학적 정확성을 재검증하지 않는다.** solution 연결은 해설·단계의 존재와 문항의 검수 상태만 본다. 정답 검증은
   별도 권위의 몫이다(`P3-06`).
4. **Curriculum Coverage 와 Content Coverage 는 현재 명세에서 수치가 우연히 같다**(노드 ↔ 개념이 1:1 이고 전부 핵심).
   분모·조건이 다르게 정의돼 있어 명세가 확장되면 갈라진다 — 주입 표의 "개념 콘텐츠 행 삭제"·"개념 없는 노드 추가"가
   두 지표가 따로 움직임을 보인다.
5. **비율은 전수 계수다**(표본 추정이 아님) — Wilson 경계를 쓰지 않았다. 분모가 10 이므로 95% 목표는 사실상 '전부'다.
6. **문제 검수 상태 `approved` 의 의미를 이 계측기가 정하지 않았다.** 코퍼스의 기존 어휘를 그대로 쓴다. 범위 문항 413건은
   전건 `approved` 이고, 필드가 없는 행(14,034행 중 11,396행)은 승인이 아니므로 세지 않는다.
7. **로컬에서 재현하지 못한 CI 잡**은 PR 본문에 따로 적는다.
