## 0. 용어 풀이 (초보자용)

| 용어 | 뜻 |
|---|---|
| **프로브(probe)** | "이 길로 정말 검증이 되는가?"를 알아보려고 일부러 만든 시험 문항. 정답 1개 + 정답 값만 틀리게 바꾼 오답 1개를 한 쌍으로 쓴다 |
| **corpus_reverify** | 코퍼스(문제 모음)의 정답을 SymPy(수식 계산 라이브러리)로 다시 계산해 맞는지 보는 기존 도구. 틀린 문항이 **1건이라도 있으면 exit 1**, 아니면 exit 0 |
| **exit code** | 프로그램이 끝날 때 남기는 숫자. 0 = 문제 없음, 1 = 실패 있음 |
| **skip(unverifiable)** | "검증할 방법이 없어서 건너뜀". **통과가 아니다.** 그런데도 exit 0 이 나오므로 "exit 0 = 검증됨"으로 읽으면 안 된다 |
| **위장** | 정답도 오답도 둘 다 통과하는 프로브. 변별력(구별하는 힘)이 없으니 결과를 믿을 수 없다 |
| **표본 검증** | 수식에 숫자 몇 개를 넣어 보고 맞으면 통과시키는 방식. 증명이 아니라 "여러 점에서 맞았다"는 증거다 |

## 1. 판정 규칙 (태스크 acceptance ② ③ 그대로)

- **가능**: 정답 파일이 exit 0 + skip 0, 오답 파일이 exit 1 + 실패 수 == 오답 행 수.
- **일부 가능**: 정답은 통과하나 오답이 전부 실패하지는 않는다(한쪽만 만족).
- **불가**: 정답 행이 skip. (정답 skip + 오답 fail 이어도 '일부'가 아니라 '불가' — 정답이 검증되지 않으면 그 개념 문항을 코퍼스에 세울 수 없다.)
- **위장(무효)**: 정답·오답 둘 다 통과. **정답 오거부(무효)**: 정답이 fail(검증 경로가 정답을 오염으로 오판). 이 둘은 규칙 3상태 밖의 무효이며, 프로브 설계 결함이다. 이번 실측에서는 7개 개념 어디에도 없었다.

이 규칙은 테스트 안의 순수 함수 `judge_concept`로 동결했고, 3상태 + 무효 2종 전부에 반례 테스트를 뒀다.

- `-02-08` 정답이 skip 이라 "검증이 일어나지 않았다"까지만 확인했다. 개형 선택형 문항에 필요한 검증 방법 자체는 이번 프로브가 제시하지 않는다(처분안 나·다는 그 대안).

## 8. 정정 — `[12미적Ⅰ-02-06]` 구간 소속 판정 (P3-19, 2026-10-03)

§2 표·§4-②의 "구간 밖 근이 통과한다"는 **P3-19 이전 상태**의 기록이다(당시 값은 위 표에 그대로 둔다). P3-19가 `corpus_reverify`의 `verify.conditions`를 문자열 1개 또는 연립(문자열 목록·AND)으로 받게 해, 평균값 정리 문항이 `f'(c)=평균변화율` 방정식과 함께 c가 열린구간 (a,b) 안이라는 조건을 같이 검산한다. 새 필드는 없다 — 검증기(`verify_answer`)와 적재기(`populate.ProblemVerifyMeta`)가 이미 목록을 받았고 `corpus_reverify`만 문자열로 제한돼 있었다.

- 열린구간은 `c >= a`·`c <= b`·`c != a`·`c != b` 네 절로 쓴다. 엄격 부등식(`c > a`)은 끝점에서 '경계 모호'로 **skip**이 되어 끝점 오답이 fail이 되지 못하기 때문이다.
- 실측: 같은 보강 행(f=x³, [0,3], c=−√3)이 `corpus_reverify`에서 통과 1 → **실패 1**(exit 1)로 바뀌었다. 정답 행(f=x²+2x, [1,3], c=2)은 통과 1·skip 0을 유지하고, 근이 ±√3 둘이고 하나만 구간 안인 정답·오답 쌍(`interval-ok` √3 pass · `interval-leak` −√3 fail)이 추가됐다. 02-06 판정은 위장 후보에서 **가능**(무단서)으로 올라간다.
- 한계: fuzzer(`fuzz_answer`)는 단변수 등식 1개만 다루므로 연립 조건 문항은 fuzz 대상에서 빠진다(오염으로 보지 않고 건너뛴다). 처분 기록: 이 정정은 P3-19 PR kiki-s-broom/WhyMath#1442(2026-10-03 머지, head `f77f8882`)가 만들었다 — `[12미적Ⅰ-02-06]`은 이 PR로 '일부 가능'에서 '가능'이 됐다.
