- **수정 전 동어반복 비율 = 26/30 (86.7%)** — 재진술만 세면 17/30(56.7%)으로 acceptance ①의 "17건"과 일치.
- 통과 4건 중 3건(local)은 Kiki가 그대로 승인했거나 키 이름만 고치라고 한 식(`v = 4*3 + 7` 등)이다.

## 3. 수정 후 실측 (2026-11-02 · Kiki PC · EOS-203 탐침에 합쳐 수행)

판정 기준: main `910e7644`. 상세 조건·한계는 `docs/reviews/eos203_local_seat_thinking_probe_2026-11-02.md`.

- **표본**: EOS-197 A6 회차와 같은 스펙 4종(`docs/ops/eos197_a6_spec_plan.jsonl`) · 로컬 좌석 `qwen3:30b-a3b` · 타임아웃 180초 · 24회 시도(사고 모드 지시어 없음 12 · `/no_think` 12).
- **동어반복 거부 0건 · 교육과정 밖 거부 0건** — 조립 실패 종류에 `TautologicalConditionError`·`CurriculumScopeError`가 한 건도 없다(시도당 생성 1회 · 실패는 예외 타입명으로 기록).
- **수락률(같은 조건끼리)**: 수정 전 3/45(6.7% · EOS-197 로컬 좌석 · 지시어 없음 · 180초) → 수정 후 5/12(41.7% · 지시어 없음 · 180초). `/no_think`를 붙인 12건(7/12)은 다른 조건이라 이 비교에 넣지 않는다.
- **해석 범위**: 기준선도 180초에서 잰 값이라 타임아웃은 교란 변인이 아니다. 수정 후 출력이 짧아지고(중앙값 5,321 → 3,388.5토큰) ReadTimeout(25/51 → 2/12)·JSON 파싱 실패(11/51 → 0/12)가 줄었다. 다만 탐침은 시드 코퍼스 중복 대조를 하지 않아 수락 판정 경로가 EOS-197과 완전히 같지 않다.
- **"0건"이 말하는 범위**: 수락된 건이 모두 근거 판정에서 "근거 있음"을 받았다는 뜻은 아니다. 발문을 못 읽어 "판정 불가"면 거부하지 않고 경고만 남긴다. 실행 화면에 그 경고는 보이지 않았지만 원자료로 재확인하지 않았다. 가드에 실제로 도달한 표본도 생성 실패를 뺀 최대 20건이다.
- 수락되지 않은 시도 중 생성 실패가 아닌 8건은 게이트 거부 7(켬 3 · 끔 4) · 검수 필요 1(켬)이고 구조 중복은 0건이다(`data/runs/eos203-thinking-probe/summary.json`). 거부 사유별 내역은 Kiki PC의 rows.jsonl에만 있다.

## 4. 한계

- 발문 함수 추출은 다항·유리식 표기(`f(x) = …`·`y = …`·`… = 0`)만 읽는다. 못 읽으면 UNKNOWN(거부 안 함·경고 로그).
- 구조 일치는 "P에 a를 대입한 식이 검산식 안에 있다"까지만 보장한다. 대입식을 정답과 엮은 공식이 옳은지는 Tier1 대입 검산과 사람 검수 몫이다.
- 교육과정 범위 표는 미적분Ⅰ(이계도함수) 1행뿐이다 — 실측된 결함만 넣었다.
- 점이 0·1·−1인 대입식을 미리 약분해 쓰면(`3*1 + 3`) 구조가 사라져 거부된다 — 프롬프트가 대입 형태 그대로 쓰게 지시한다.
- 발문에 적힌 수는 허용되므로, 하드코딩한 중간값이 우연히 발문의 계수와 같으면 통과한다.
