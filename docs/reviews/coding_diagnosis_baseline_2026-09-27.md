## 4. 이 기준선이 말하지 못하는 것 (정직 고지)

- **저장소 코드를 실행하지 않았다** — pytest·mypy·ruff 미실행, `9^9^9` 재현도 하지 않았다. BL-004의 "가드 없음"은 역할 검색(`MAX_*LEN`·`signal.alarm`·`wait_for`·`evaluate=False`·지수 상한·`9^9^9`)으로 0건이라는 뜻이고, 서버 정지 자체는 KR-06 기록(E0)에 기댄다. 재현은 `CONST-09`의 첫 acceptance다.
- **import-linter 실측 불가** — 진단 환경에 설치돼 있지 않아 BL-012의 "기존 계약과 일치"는 pyproject 면제 목록과의 손 대조(정적)다. CI에서는 backend 잡이 실제로 돌린다.
- **층 분류는 이 세션이 만든 설정**이다 — 분류가 달라지면 위반 수도 달라진다. tests·scripts·docs·data-pipeline·infra 1,358파일은 의도적으로 미분류.
- **비밀값은 현재 트리만** 봤다(`--history` 미실행). 과거 커밋 속 비밀값은 모른다.
- **동결 항목(FZ-xx) 변경은 미측정**(`--freeze` 미지정) — 이 저장소용 동결 경로 정의가 아직 없다.
- BL-006(광범위 except의 "흔적 없음 44")은 except 뒤 8줄 정규식 휴리스틱이라 과대 계상될 수 있다. BL-009(흩어진 기준값)는 코드 미확인(E1)이다.
- 그래프: 원자 그래프는 선수 관계가 별도 edges 목록이라 변환본으로 쟀다. 공식·전략·문제유형 그래프 3종은 미측정.
- `diag_merge.py`(단계별 발견 병합)는 S10용이라 기준선에서는 돌리지 않았다.
- 비밀값·학생 데이터 실값은 이 문서에 옮기지 않았다(도구도 앞 4자만 남긴다).
