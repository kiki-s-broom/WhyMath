t를 두지 않을 때 쓸 수 있는 접점 후보는 주어진 점뿐이고, 그 결과가 교과서에서도 대표적인 "~에서의 접선" ↔ "~를 지나는 접선" 혼동이다.
기울기 질문에서는 P\*·P′가 같은 값 f'(p)를 내므로 판독이 갈리지 않는다 → **A 틀(기울기)을 핵심으로, B·C를 보조로** 둔다.

## 2. 틀 후보

공통 발문 골격: `점 (p, q)에서 곡선 y = f(x)에 그은 접선은 하나뿐이다. 이 접선의 ○○로 옳은 것은?` (f는 삼차, 정수 계수, p ≠ 0)

### 정답 절차 (3틀 공통)
접점을 (t, f(t))라 두면 접선 y = f'(t)(x − t) + f(t)가 점 (p, q)를 지난다 → **g(t) = f(t) + f'(t)(p − t) − q = 0**.
삼차 f = ax³ + bx² + cx + d이면 g(t) = −2a t³ + (3ap − b)t² + 2bp·t + (d + cp − q) (c는 상수항에만 들어간다).
g = −2a(t − t₀)(이차식)이고 이차식의 판별식 < 0이면 접선은 하나뿐이며 t = t₀. 이어서 m₀ = f'(t₀).

### 틀 A — `mc-outer-point-tangent-slope` (핵심)
- 질문: 접선의 **기울기**. 정답 m₀ = f'(t₀). **오개념 선택지 = f'(p)** (P\*).
- 일반 오답 보기(라벨 없음): f'(−t₀) · f(t₀)(접점의 y좌표) · f'(t₀±1) 중 서로 다른 값 2개.
- 검산 조건(Tier1, **미분을 쓰지 않는 독립 경로**): 직선 y = m(x − p) + q와 곡선의 차가 x에 대해 이중근 ⇔ 판별식 = 0 (m의 삼차식, 예 `-8*m**3 + 105*m**2 + 4296*m - 232192 = 0`). 실근이 정답 하나뿐이어야 하므로 보호 조건이 필요 없다.
- 풀이 단계: `Derivative(f, x).doit().subs(x, t₀) = m` → 대입 → 값 (기존 `mastery-tangent-from-point-on-y-axis`와 같은 한계: 접점 t₀를 고르는 앞 단계는 미지수가 바뀌어 연쇄에 싣지 못한다).

### 틀 B — `mc-outer-point-tangent-y-intercept` (보조)
- 질문: 접선의 **y절편**. 정답 k₀ = f(t₀) − t₀·f'(t₀). **오개념 선택지 = q − p·f'(p)** (P\*: 접선 y = f'(p)(x − p) + q의 y절편).
- 일반 오답: m₀(기울기를 절편으로 착각) · f(t₀) · k₀ + m₀ · −k₀ 중 2개.
- 거부 조건: P′ 값 f(p) − p·f'(p)가 정답과 같으면 그 파라미터를 버린다(P′ 학생이 우연히 맞히는 것을 막는다) + P′ 값은 일반 오답 보기에도 넣지 않는다.
- 검산: 직선을 y절편 k로 매개(기울기 (q − k)/p, p ≠ 0) → 판별식 = 0 (k의 삼차식).

### 틀 C — `mc-outer-point-tangent-line-value` (보조)
- 질문: 접선의 방정식을 y = g(x)라 할 때 **g(s)**. 정답 v₀ = f(t₀) + m₀(s − t₀). **오개념 선택지 = q + f'(p)(s − p)** (P\*). s ∉ {p, 0, t₀}.
- 일반 오답: m₀ · f(s) · v₀ + m₀ · f(t₀) 중 2개. P′ 값 f(p) + f'(p)(s − p) 거부·제외는 B와 같다.
- 검산: 직선을 g(s) = y로 매개(기울기 (y − q)/(s − p)) → 판별식 = 0 (y의 삼차식).

### 탈락한 틀 (이유가 있는 음성 결과)
- **D. 접선이 셋일 때 "접점의 x좌표가 양수인 것"으로 유일화** (`proto`의 `d_params_from_roots`): 접점 x 세 근이 서로 다른 정수가 되려면 근의 합 (3ap − b)/(2a)과 쌍합 −bp/a가 맞아야 하는데 둘 다 (a, b, p)로 정해진다 — 자유로운 것은 q뿐이다. 범위 `a ∈ {±1, ±2}, b ∈ [−3, 3], p ∈ [−4, 4]` 전수 후보 **18건**, 그중 수치 한도(|값| ≤ 99)를 넘지 않는 것 **0건**(접점 6 → 기울기 128 등). 정수 근이 아닌 유일화는 해설이 무리근을 버리는 서술을 해야 해서 학생 대면 해설이 무거워진다. → **유일화는 "접선이 하나뿐"(실근 1개)으로 한다.**
- **E. "접점의 x좌표"를 묻는 틀**: 오개념 선택지가 p 그 자체(발문의 숫자를 옮겨 적은 것)가 되어 변별이 약하고, 기존 `applied-tangent-passes-through-point`·`applied-cubic-tangent-through-origin`(양수 a)와 같은 수학 실체를 되풀이한다 — 검산 조건 중복·QUAL-07 위험.
- **F. 이차 곡선 외점 접선**: 판정기 `T05-quadratic-tangency`·`T05-quadratic-tangent-constant`가 거부(판별식만으로 풀린다).
- **G. 곡선 위의 점**(q = f(p)): M0673 상황이 발생하지 않는다(기존 은행의 문제). 빌더가 q ≠ f(p)를 강제한다.

## 3. 유일화 설계 (정답이 하나로 정해지는 조건)

"접선이 하나뿐"을 **발문이 선언**하고(기존 `mastery-tangent-from-point-on-y-axis` 선례), 빌더가 그 선언이 참임을 정수 연산으로 단언한다:

1. q = f(t₀) + f'(t₀)(p − t₀) — 접점 t₀는 구성으로 g의 근이다. 단 p ≠ 0, p ≠ t₀, **q ≠ f(p)**(곡선 밖), |q| ≤ 99.
2. g(t)/(t − t₀)의 이차 인수의 **판별식 < 0**(정수 계수로 직접 계산) — 이차 인수가 허근뿐이라 실제로 접선이 하나다(삼중근 배제 포함).
3. 독립 검증: 프로토가 발문 텍스트만 읽어 판별식(기울기 m 쪽) 경로로 접선을 다시 세어 **정확히 1개**임을 단언한다(주입 I6: 접선이 셋인 점에 "하나뿐이다"를 붙이면 거부).

해설은 "나머지 이차 인수는 판별식의 값이 음수이므로 실근을 갖지 않아 t = t₀뿐이다"로 맺는다(판정기 `E-excluded-root`는 버리는 근이 없어 비해당).

## 4. 문제유형 ↔ 스킬 정직성

- 유형: **`ptype.solve-for-unknown`** (graph.json: `behavior_skills` = linear-equation-solving · quadratic-equation-solving · **equation-rearrangement**) ↔ 02-05 개념 스킬 `skill.equation-rearrangement`·`skill.graph-sketching` → **equation-rearrangement로 겹친다.**
- 정직한 근거: 세 틀 모두 풀이의 핵심 인지 행동이 "미지의 접점 t를 두고 q = f(t) + f'(t)(p − t)를 t의 방정식으로 세워 푸는 것"이다. 최종 질문이 기울기·절편·값이어도 그 앞의 **미지수 구하기 단계 없이는 답이 없다**. 형제 틀 `mastery-tangent-from-point-on-y-axis`(기울기를 묻는 외점 접선)도 같은 유형으로 승인돼 있다.
- 사용하지 않은 것: `graph-sketching`을 행사하는 `optimize-extremum`·`sketch-graph`·`count-solutions`는 이 틀이 *진짜로* 요구하는 행동이 아니므로 달지 않는다. `ptype.determine-coefficient`도 미정계수 결정이 아니라 달지 않는다.
- 위험: B(y절편)·C(g(s))는 판정자가 "마지막 단계는 값 계산(evaluate-expression)"이라 볼 수 있다. 그래서 A를 핵심으로 두고 B·C 비중을 낮추는 선택지를 열어 둔다(§7).

## 6. 판정기 규칙 확장이 필요한가 — **필요(강한 권고, 빌드를 막는 필수는 아님)**

- 현행 판정기는 M0673 연결을 **전혀 검사하지 않는다.** 실측: 프로토 주입 I1(무관한 오답을 M0673으로 라벨)·I2(정답 자체를 M0673으로 라벨) 둘 다 **현행 `shortcut_violations` 위반 0건**이었다. 즉 이 부류의 거짓 라벨은 지금 코드에서 통과한다 — 02-05 재연결이 "라벨만 바꿔 지표만 올리는" 길을 구조적으로 열어 둔다.
- 시안(프로토 `m0673_link_violations`): 발문 텍스트만으로 곡선·점·질문 종류를 읽어 P\* 산출을 **독립 재도출**하고, M0673 귀속 선지가 그 값이 아니면 `M-link-procedure` 위반, 곡선 위의 점이거나 발문을 읽지 못하면(fail-closed) 위반. 변별: 주입 I1~I4 전건 검출.
- 확장 위치: `_misconception_rules`에 `if "M0673" in linked:` 절(M0674 절과 같은 모양) 하나. 코퍼스·명세·카탈로그 변경은 불필요.
- 별건 결정(Kiki): M0673은 MISC-40이 omission형으로 본 오개념이다. M0677은 같은 omission형인데 `M-link-undescribed`로 연결이 **금지**됐다. M0673을 허용하려면 "P\*가 M0673의 절차"라는 판단이 필요하다. 근거 있는 구분 — M0673 원문은 상황("곡선 밖의 점에서 그은 접선")과 빠진 단계("접점을 미지수로 두기")를 *구체적으로* 적었고, 그 단계를 빠뜨리면 학생이 쓸 수 있는 접점이 주어진 점뿐이다. M0677은 "관점을 못 쓴다"뿐이라 산출이 정해지지 않는다. 그래도 이것은 추론이며, 안전한 길은 M0673 설명에 한 문장("접점을 따로 두지 않고 주어진 점을 접점처럼 써서 f'(p)를 기울기로 삼는다")을 보강하는 코퍼스 정정(QUAL-14 계열, Kiki 몫)이다.

## 10. 위험과 확인하지 못한 것

감사 판정자가 결함으로 볼 만한 지점:
1. **P\*는 추론이다**(§1·§6). M0673은 omission형이라 판정자가 "이 오답이 M0673에서 나온다는 근거가 원문에 없다"고 볼 수 있다. 가장 큰 위험이며 코퍼스 설명 보강 또는 Kiki의 승인 판단이 필요하다.
2. **"접선은 하나뿐이다"**: 학생에게 접선 개수를 알려 준다(기존 선례와 같음). 거짓이면 치명적이라 빌더·프로토가 이중으로 단언한다.
3. **B·C의 P\* 판독**: 학생이 (p, q) 대신 (p, f(p))를 접점으로 읽으면(P′) y절편·g(s)의 값이 다르다. 선택지는 P\*만 라벨하고 P′ 값은 정답과 겹치면 거부하지만, P′ 값 자체가 선택지에 없으므로 P′ 학생은 일반 오답으로 흩어진다.
4. **수치 크기**: q·선택지가 두 자리(|값| ≤ 99). 기존 은행(한 자리 위주)보다 무겁다.
5. **미분 없이 풀리는 길(bad_tag 부류)**: 곡선 − 직선의 이중근 조건(삼차 판별식·계수 비교)으로도 풀린다. 이것이 Tier1의 독립 경로이기도 하다. 기존 형제 틀(`mastery-tangent-from-point-on-y-axis`)이 같은 구조로 승인돼 있고 판정기는 삼차 이상을 허용하지만, 판정자가 문제 삼을 수 있다.
6. **풀이 단계 연쇄는 마지막 단계(t₀ → 값)만** 싣는다 — 접점을 고르는 방정식 풀이는 미지수가 바뀌어 연쇄에 못 싣는다(기존 틀과 같은 한계).
7. **근사 중복**: 틀 A는 기존 `mastery-tangent-from-point-on-y-axis`(점이 y축 위, 6건)를 점 위치로 일반화한 것이다. 문면 골격·검산 조건은 겹치지 않았지만(p = 0 제외) 수학 구조는 같다.

확인하지 못한 것:
- 실제 판정자(LLM 감사)가 이 틀을 어떻게 판정할지 — 감사를 돌리지 않았다.
- 새 코퍼스가 n ≥ 200 요건을 어떻게 채울지(02-06·02-08·02-10 몫과 합산) — 이 개념의 공급 가능량만 §8에 있다.
- `ptype.solve-for-unknown`을 B·C에 다는 것에 대한 판정자의 동의.
- 전체 테스트 스위트·CI의 다른 잡(저장소를 수정하지 않았으므로 돌리지 않았다).
- 사람 학생에게 실제로 P\*가 가장 흔한 오답인지(경험적 빈도) — 이 설계는 논리적 귀결이지 측정이 아니다.
