## 6. 수정승인 문항 수정안

### 5번 (wm-gen-quad-3042ae26917e) — 해설 교체

양변을 3으로 나누면 x² − (1/3)x − 10/3 = 0 이다. 상수항을 우변으로 옮기면 x² − (1/3)x = 10/3 이다. 좌변을 완전제곱식으로 만들기 위해 양변에 (1/6)² = 1/36 을 더하면 (x − 1/6)² = 10/3 + 1/36 = 121/36 이다. 따라서 x − 1/6 = ±11/6 이므로 x = 2 또는 x = −5/3 이다. 두 근 중 작은 근은 −5/3 이다.

### 8번 (wm-gen-quad-9b306c4cdde3) — 문항 교체

가로의 길이가 세로의 길이보다 7 cm 더 긴 직사각형이 있다. 이 직사각형의 넓이가 120 cm²일 때, 세로의 길이를 구하시오. (해설은 그대로)

### 10번 (wm-gen-quad-f292a0d13aa0) — 해설 교체

양변을 6으로 나누면 x² + (5/6)x − 1 = 0 이다. 상수항을 우변으로 옮기면 x² + (5/6)x = 1 이다. 좌변을 완전제곱식으로 만들기 위해 양변에 (5/12)² = 25/144 를 더하면 (x + 5/12)² = 1 + 25/144 = 169/144 이다. 따라서 x + 5/12 = ±13/12 이므로 x = −5/12 + 13/12 = 2/3 또는 x = −5/12 − 13/12 = −3/2 이다. 두 근 중 작은 근은 −3/2 이다.

### 25번 (선택) — 해설에 한 줄 보완

4x² − 4x = (2x − 1)² − 1 이므로, 4x² − 4x − 3 = 0 은 (2x − 1)² − 1 − 3 = 0, 즉 (2x − 1)² = 4 이다. 2x − 1 = ±2 이므로 x = 3/2 또는 x = −1/2 이다. 두 근 중 작은 근은 −1/2 이다.
