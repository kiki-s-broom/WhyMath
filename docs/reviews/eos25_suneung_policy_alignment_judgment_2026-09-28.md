# EOS-25 판정 — 수능 모드 추천에도 설명·콘텐츠 정렬(EOS-124)을 적용하는가

판정 기준: main `78a8edff` · 작성 2026-09-28 · 태스크 `EOS-25-suneung-policy-selection-alignment`

> **결론 한 줄**: 적용한다. 단 재선택 후보는 **수능 모드의 게이트·가중·선택기를 그대로** 탄다
> (기본 CAT의 후보 조회를 빌려 쓰지 않는다). 목표 개념에 수능 적격 문항이 없으면 모드를
> 벗어나지 않고 정직 강등한다. 정렬 면제 경로(`intent_resolution=None`)는 소비처가 사라지므로 닫는다.

---

## §0 무엇을 정해야 하나

`GET /v1/me/next-problem?mode=suneung`은 `api/_next_problem_policy.py::SuneungRecommendationPolicy`가
처리한다. EOS-124는 기본 CAT의 "설명(action·target)과 콘텐츠(problem_id)가 따로 계산되는" 결함을
고쳤지만 수능 정책은 일부러 건드리지 않았다(EOS-124 acceptance ⑥ — "별도 판정이 필요하다").
이 문서가 그 별도 판정이다. 판정할 질문은 둘이다.

1. 기본 CAT이 채택한 구조(1차 선택 → 앵커 → 정책 의도 → 정렬 재선택 → 정직 강등)를 수능 정책에도
   적용하는가, 아니면 수능 모드에 고유한 규칙이 필요한가.
2. 적용한다면 재선택이 수능 모드의 세 장치(L6 적격 게이트 · persona_fit · 수능 우선순위 가중)와
   어떻게 맞물려야 하는가.

## §1 결함 실재 확인 (acceptance ①)

main 코드 그대로의 수능 정책을 대역 세션으로 돌리고, 산출에 정렬 판정기(`check_intent_alignment`)를
걸었다. 1차 선택 문항이 그대로 나가므로 "전달 문항의 대표 개념"은 앵커다.

| 형태 | 입력 | main 산출 | 판정 |
|---|---|---|---|
| (가) 전진 제자리 | 앵커 숙달 0.98 | `advance_next` · target = 앵커 | **R3 위반** — 전진을 선언하면서 같은 개념 |
| (나) 낡은 선수 설명 | 앵커 0.12 · 선수 숙달 1.0 | `practice_prerequisite` · target = 선수 | **R2 위반** — 목표(선수) ≠ 받은 문항(앵커) |
| (다) 미측정 선수 | 앵커 0.12 · 선수 미측정 | `practice_prerequisite` · target = 앵커 | **R3 위반** — 선수 복귀를 선언하면서 제자리 |

세 경우 모두 `intent_resolution=None`이라 산출 검증기가 면제했고, 응답은 200으로 나갔다.
원인은 EOS-124 이전 기본 CAT과 같다. 문항을 수능 CAT으로 고른 **뒤** 그 문항 개념의 숙달 구간으로
행위를 붙이고, 목표는 `resolve_target_concept`(측정된 선수 중 최저 숙달 — 1.0이어도 고름 · 미측정이면
문항 개념으로 폴백)로 따로 계산한다. 두 축이 서로를 보지 않는다.

**학생에게 닿는 피해**: 수능 모드 학생이 "다음 개념으로 넘어가세요"와 함께 방금 숙달한 개념의
문항을 받고, "선수 개념을 연습하세요"와 함께 원래 개념 문항을 받는다. 설명이 콘텐츠와 어긋나면
추천 이유가 신뢰를 쌓지 못하고 오히려 깎는다(EOS-124 ②와 같은 피해).

## §2 선택지

| 안 | 내용 | 약점 |
|---|---|---|
| **A** | EOS-124 구조를 적용하되 재선택 후보는 **수능 게이트·수능 가중·수능 선택기**로 고른다. 목표에 적격 문항이 없으면 1차 선택을 내보내고 정직 강등(`target_unavailable`) | 선수 개념(특히 하위 학년)에 수능 적격 문항이 적어 강등이 잦을 수 있다 |
| **B** | 재선택하지 않는다. 수능 선택 축은 그대로 두고, 관계 행위가 나오면 **항상** 앵커 연습으로 강등 | 콘텐츠가 있어도 관계 의도를 한 번도 집행하지 않는다. "작동한 비율"이 콘텐츠 사정과 무관하게 **구성상 0**이 된다 |
| **C** | 목표 개념에 수능 적격 문항이 없으면 **기본 CAT 풀**(수능 신호 없는 문항)에서 가져온다 | 수능 모드의 진실 게이트(L6)를 우회한다. 학생이 고른 모드의 계약이 깨지고, 페르소나 게이트(D·E 비대상)도 함께 우회된다 |

## §3 판정 — 안 A

**의도의 정본은 정책 축이다.** 숙달 구간 규칙(계획서 §8 · `select_reason_type`)은 학습자 상태에 대한
규칙이지 출제 모드에 대한 규칙이 아니다. 선수가 약한 학생은 수능 모드에서도 선수가 약하다. 모드가
바꾸는 것은 *어떤 문항을 보여줄 수 있는가*이지 *학생에게 무엇이 필요한가*가 아니다. 그래서 규칙
자체(`resolve_policy_intent`)는 기본 CAT과 **같은 함수**를 그대로 쓴다 — 모드별 사본을 만들면 한쪽만
고쳤을 때 두 모드가 같은 학생에게 다른 진단을 낸다.

**콘텐츠의 정본은 선택 축이고, 수능 모드에서 선택 축의 진실 게이트는 L6다.** 기본 CAT의 재선택
후보 조회(`load_target_candidate_rows`)는 수능 게이트를 모른다. 그것을 빌려 쓰면 재선택이 1차
선택이 막는 문항(수능 신호 없음 · 비대상 페르소나)을 꺼내 온다. 이것이 안 C의 결함이고, 안 A가
재선택 조회를 수능 쪽에 따로 두는 이유다.

**안 B를 버린 이유**: 수능 모드의 관계 의도를 구조적으로 0% 집행하게 된다. 강등 자체는 정직하지만,
"콘텐츠가 없어서 못 했다"와 "처음부터 안 한다"가 같은 값으로 보인다. 그러면 수능 코퍼스에 선수
개념 문항을 채워도 추천이 달라지지 않는다 — 콘텐츠 투자가 추천에 닿는 경로가 없다.

**안 C를 버린 이유**: CLAUDE.md 의사결정 우선순위 #2(법적·윤리적 준수)와 #5(사용자 경험)가 겹친다.
저작권·검수 게이트는 기본 CAT 풀에도 있으니 법적 누출은 없다. 그러나 학생이 명시적으로 고른 모드의
계약("수능 적격 문항만")이 깨지고, `recommend_suneung_index`의 설계 원칙("사전필터가 느슨해도
부적격이 새지 않는다")이 재선택 경로에서만 무너진다.

### 수능 장치와의 맞물림 (acceptance ② 명시 항목)

| 장치 | 1차 선택 | 재선택 | 판정 |
|---|---|---|---|
| SQL 사전필터(난이도 보유 · 저작권 · 수능 신호 OR) | 적용 | **같은 조건 함수**로 적용 | 한 곳에서만 정의한다(REC-06 원칙). 두 조회가 갈라지면 재선택이 1차가 막는 문항을 꺼낸다 |
| L6 진실 게이트 `is_suneung_eligible`(페르소나 · 저작권 · 검수 · 수능 신호) | `recommend_suneung_index` 안에서 재수행 | **같은 함수**로 재수행 | 재선택도 `recommend_suneung_index`를 부른다 |
| persona_fit(사전필터의 OR 신호 · 게이트의 임계 0.5) | 요청 페르소나 | **같은 페르소나** | 페르소나가 정책 생성자 인자라 두 경로가 공유한다 |
| 수능 우선순위 가중(`1 + 권위×2 + 시그니처 + 난이도`) | 곱 결합 | **같은 곱 결합** | 목표 개념 안에서도 수능>모평>학평·시그니처 순서가 유지된다 |
| 약점·학습 밴드·형제 가중 | 곱 결합 | **같은 함수·같은 순서**로 곱 결합 | 기본 CAT의 `_combine_axes`와 같은 규율 |
| 대표 개념 한정(PRIMARY) | — | 목표 개념이 **PRIMARY**인 문항만 | EOS-124와 같다. 다개념 수능 문항을 TESTED 개념의 연습이라 부르면 설명이 다시 어긋난다 |
| 개념별 후보 상한 | 전체 50 | **개념마다** 50(윈도 함수) | 전체에 한 번 걸면 θ에 가까운 개념이 풀을 채워 우선순위가 높은 개념(가장 약한 선수)이 잘린다 |
| 학습 상태 머신 | 읽지 않음 | 읽지 않음 | EOS-24 판정문 §7-3 유지 — 이 태스크 범위 밖 |

**예상되는 결과(정직 표기)**: 선수 개념이 하위 학년이면 수능 적격 문항이 드물다. 그래서 수능 모드의
선수 복귀는 `target_unavailable` 강등이 기본 CAT보다 잦을 것이다. 이것은 결함이 아니라 **콘텐츠
공백 신호**다. `intent_resolution`이 응답·처치 기록 양쪽에 남으므로 그 비율을 셀 수 있고, 그것이
수능 코퍼스의 선수 개념 보강 우선순위를 정하는 재료가 된다.

## §4 집행 (acceptance ③)

- 수능 정책은 1차 선택 뒤 `resolve_policy_intent`로 의도를 세우고, 재선택이 필요하면 수능 전용
  목표 후보 조회(같은 사전필터 · PRIMARY · 개념별 상한 · 미응답·형제 배제)로 읽은 뒤 묶음 순서대로
  `recommend_suneung_index`를 부른다. 못 고르면 1차 문항 그대로 `target_unavailable`로 강등한다.
- 산출은 `intent_resolution`·`delivered_concept`를 채운다. 그러면 `NextProblemOutcome`의 생성 시점
  검증기(`_aligned_when_declared`)가 수능 응답에도 걸린다. 핸들러는 그 객체를 응답·처치 기록으로
  옮기기만 하므로, 검증은 실제 서빙 응답이 반드시 지나가는 자리에 있다.
- **면제 경로를 닫는다.** 검증기의 `intent_resolution is None → 면제`는 수능 정책 하나를 위해 있던
  것이다. 그 정책이 정렬을 선언하면 면제의 소비처가 0이 된다. 남겨 두면 다음 정책(또는 수능 정책의
  회귀)이 None을 내는 순간 **조용히** 검증을 건너뛴다. 그래서 `NextProblemOutcome.intent_resolution`을
  필수로 바꾼다 — 정렬 선언은 모든 정책의 의무가 된다. HTTP 응답 필드는 API 계약을 바꾸지 않으려고
  선택형으로 두되, 설명을 "항상 채워진다"로 고친다.
- 선택 규칙이 바뀌므로 REC-11 규약대로 `policy_version`을 `suneung_v1` → `suneung_v2`로 올린다.
  소급 평가가 두 규칙의 로그를 섞지 않게 하기 위함이다.
- `resolve_target_concept`는 소비처가 0이 된다(기본 CAT은 EOS-124에서 옮겼다). 알려진 결함을
  품은 채 공개 함수로 남겨 두면 다음 사람이 다시 쓴다 — 제거한다.

## §5 회귀 동결 (acceptance ④)

- `tests/backend/api/test_me.py`의 수능 후보 0 응답(`intent_resolution: None` 단언)은 이 변경으로
  실패한다 → `no_candidate`로 승격한다. 수능 응답 키 집합 테스트는 키가 바뀌지 않아 실패하지 않는다.
  주석에 "수능은 null"만 적혀 있고 값 단언이 없었기 때문이다 → 값 단언(`direct`)을 추가한다.
- 새 오케스트레이션 테스트가 세 형태를 대역으로 재주입해 정렬이 성립하는지 본다.
- 새 SQL(수능 목표 후보 조회)은 실 PG 통합 테스트로 PRIMARY 한정·개념별 상한·사전필터 적용·
  미응답 배제를 확인한다.

## §6 정직한 공백

- **선택과목 미모델링(기존 결함 · 이 변경이 체계화한다)**: 수능 수학은 공통(수학Ⅰ·Ⅱ) + 선택
  (미적분·확통·기하)이다. 그런데 학습자 프로필에 선택과목이 없고, 수능 사전필터도 과목을 거르지
  않는다. 1차 선택부터 이미 확통 선택 학생에게 기하 문항을 낼 수 있다. 전진 재선택은 이 노출을
  **체계화**한다 — 수학Ⅱ 개념을 숙달하면 그 후행(미적분 개념)으로 간다. 이 태스크가 만든 결함은
  아니지만 방향을 강화하므로 후속 태스크로 분리 등재한다.
- **검수 게이트가 사전필터에 없다(기존)**: 기본 CAT은 `review_status=approved`를 SQL에서 거르는데
  수능 사전필터는 L6 게이트에서만 거른다. 미검수 문항이 상한 50의 자리를 차지하면 검수된 문항이
  밀려날 수 있다. 1차 선택과 같은 정의를 쓰기 위해 재선택 조회에도 넣지 않았다. 사전필터 보강은
  1차 선택 결과를 바꿀 수 있으므로 이 태스크 범위 밖이다.
- **후행 준비도(EOS-124와 같음)**: 전진 목표는 1-hop 후행 중 미숙달 전부다. 그 후행의 *다른*
  선수가 준비됐는지는 보지 않는다.
- **정렬 대상 = 대표 개념 하나**: 수능 문항은 여러 개념을 엮는 경우가 많다. 앵커는 대표 개념
  (PRIMARY→TESTED 폴백) 하나다. 다개념 문항의 설명 정밀화는 이 판정의 범위 밖이다.
