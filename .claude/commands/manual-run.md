# /manual-run — 매뉴얼대로 일하기

## 임무
`manuals/<id>/MANUAL.md` 하나를 기준으로 작업을 끝까지 수행한다. 매뉴얼이 정본이며, 매뉴얼과 다른 즉흥 판단을 하지 않는다.

## 절차
1. 매뉴얼 전체를 읽는다. `readiness: draft` 이면 실행하지 말고 `/manual-interview <id>` 를 권한다.
2. §2 입력을 모은다. 없으면 표의 "없으면" 칸대로 한다.
3. §3 절차를 순서대로 수행한다. 애매하면 §4 기본 행동을 따르고, §4 가 "묻는다"라고 한 경우에만 사용자에게 묻는다.
4. 도구는 머리말 `toolbox` 에 있는 것만 쓴다. 목록에 없는 도구가 필요하면 멈추고 `/manual-fix` 를 제안한다.
5. **자체 검사** — `python3 scripts/manuals/manual.py verify <id> --arg k=v ...` 를 돌린다.
   - ❌ 가 있으면 고치고 다시 돌린다. 고칠 수 없으면 완료라고 말하지 않고 무엇이 실패했는지 보고한다.
   - ⏳ 항목은 증거를 직접 확인해 보고서에 적는다.
6. 보고서 첫 줄에 결과, 그다음 완료 조건 표(항목 · 결과 · 증거)를 적는다.
7. 작업 중 매뉴얼 때문에 헤맸거나 틀렸으면 마지막에 `/manual-fix <id>` 를 제안한다(어느 절이 문제였는지 1줄).
