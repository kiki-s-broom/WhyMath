# /manual-fix — 오류를 매뉴얼에 반영하기

## 임무
이번 오류가 **다음 실행에서 다시 나지 않도록** 매뉴얼 자체를 고친다. 채팅에서 "다음엔 조심"으로 끝내지 않는다.
정본: `docs/standards/agent_manual_method.md` §5.

## 절차
1. **증상 확인** — 무엇이 기대와 달랐나, 실측 증거(명령 출력·파일)를 확보한다.
2. **분류** (하나 이상)
   - 절차 누락 → §3 · 분기 기본값 부재 → §4 · 금지 누락 → §5 · 도구 부재·오용 → 툴박스
   - 완료 조건이 못 잡음 → `verify` 에 항목 추가 (**결과가 틀렸는데 자체 검사가 통과했다면 이 분류는 필수**)
3. **수정** — 해당 위치를 고친다. 가능하면 `how: cmd` 완료 조건으로 막는다.
4. **카탈로그** — §8 에 행 추가: 증상 | 원인 | 분류 | 매뉴얼 수정 위치(§N·VN·툴박스) | 새 버전
5. **버전** — 머리말 `version` +1 · `updated` 오늘 · §9 에 같은 버전 행
6. **재검사** — `manual.py lint` exit 0 → `manual.py verify <id>` 로 이번 오류가 이제 ❌ 로 잡히는지(또는 절차상 생길 수 없는지) 확인
7. **반복이면 승격** — §8 에 같은 원인이 이미 있으면 문장 수정으로 끝내지 않는다: `cmd` 완료 조건이나 코드 가드로 바꾸고, 저장소 차원 실수면 사고 대장(`backlog.py incident add`)에도 등재한다.

## 하지 않는 것
- 매뉴얼 밖(CLAUDE.md 등)에 새 산문 규칙을 추가하지 않는다 — 업무 규칙은 매뉴얼에 둔다.
- 오류 하나 때문에 다른 매뉴얼·시스템 전체를 바꾸지 않는다. 이 매뉴얼만 고친다.
