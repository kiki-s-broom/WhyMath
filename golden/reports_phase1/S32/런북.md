# S32 런북 — Kiki 머신 서버·러너의 숙련도 플래그 기본값 (F-06)

> **지금 할 일은 없다.** 이 문서는 서버(`golden.api:app`)나 러너(`golden.sim.run`)를 Kiki 머신에서 돌릴 때 지킬 기본값을 적어 둔 참조용이다(지시서 S32 할 일 4).

## 기본값

| 플래그 | 기본값 | 뜻 |
| --- | --- | --- |
| `GOLDEN_MASTERY_ENGINE` | **설정하지 않는다** (= `simple`) | 판정 응답의 `mastery`가 공유 계약 값(맞으면 +0.10 · 틀리면 −0.05)이다. 앱 화면에 보이는 숫자가 이것이다 |

- 값이 정확히 `bkt`일 때만 응답 `mastery`가 bkt 값이 된다. 그 밖의 값(빈 값·오타·`BKT`)은 전부 simple로 처리된다.
- **화면에 bkt 값을 보여 주지 않는다**(지시서 S32 하지 말 것). 그래서 Kiki 머신의 서버와 러너는 이 플래그를 켜지 않는다.
  - 켜면 생기는 일: 앱 결과 화면이 bkt 값을 보여 준다. 세션 시작 값은 simple이라, 첫 판정의 변화량이 두 엔진을 섞은 숫자(예: 0.00 → 0.67이면 "+0.67")로 나온다.
  - bkt 값은 플래그와 무관하게 DB 표 `golden.mastery_shadow`에 쌓인다(판정 1건마다 simple 1행 + bkt 1행).
  - S33이 비교할 숫자는 그 표에서 읽는다.
- **새 표는 손으로 만들지 않는다.** 서버나 러너가 시작될 때 `ensure_schema()`의 `create_all`이 없는 표만 만든다. 기존 표 `students`·`sessions`·`turns`·`eval_log`는 건드리지 않는다. 마이그레이션 명령도 없다.

## 확인 블록(선택 · 읽기 전용)

**실행 환경:** Kiki 머신 Windows PowerShell(새 창 · 이 창은 끝나면 닫아도 된다).

이 블록은 지금 이 창과 사용자 환경변수에 플래그가 없는지 확인한다. 아무것도 바꾸지 않는다.

```powershell
# Kiki 머신 · Windows PowerShell · 읽기 전용(아무것도 바꾸지 않는다)
cd C:\Users\kiki\Desktop\__AI\WhyMath
$ProcValue = $env:GOLDEN_MASTERY_ENGINE
$UserValue = [Environment]::GetEnvironmentVariable("GOLDEN_MASTERY_ENGINE", "User")
if ([string]::IsNullOrEmpty($ProcValue) -and [string]::IsNullOrEmpty($UserValue)) { "MASTERY_FLAG=default-simple (통과 — 할 일 없음)" } else { "MASTERY_FLAG=SET proc='$ProcValue' user='$UserValue' (기본값 아님 — 아래 정리 블록을 붙여 넣으세요)" }
```

성공 기준:

- `MASTERY_FLAG=default-simple`이 보이면 통과다.
- `MASTERY_FLAG=SET`이 보이면 플래그가 남아 있는 것이다. 아래 정리 블록을 붙여 넣는다.

정리 블록(위에서 `SET`이 나왔을 때만):

```powershell
# Kiki 머신 · Windows PowerShell · 이 창과 사용자 환경변수에서 숙련도 플래그를 지운다
Remove-Item Env:GOLDEN_MASTERY_ENGINE -ErrorAction SilentlyContinue
[Environment]::SetEnvironmentVariable("GOLDEN_MASTERY_ENGINE", $null, "User")
$After = [Environment]::GetEnvironmentVariable("GOLDEN_MASTERY_ENGINE", "User")
if ([string]::IsNullOrEmpty($env:GOLDEN_MASTERY_ENGINE) -and [string]::IsNullOrEmpty($After)) { "MASTERY_FLAG=default-simple (정리됨)" } else { "MASTERY_FLAG=STILL_SET — 시스템 환경변수에 있을 수 있음, 세션에 알려 주세요" }
```
