### 2. 연결(다섯 걸음 ④) — GP-4 뒤 · 기록만

- `api.py` `answer()`: 튜터 되묻기를 `record_turn`으로 남긴 직후 `if rubric_enabled(): await _record_t1_eval(...)`. 응답 dict는 그 뒤에 원래대로 만든다 — 평가 결과가 응답에 들어가지 않는다.
- `_record_t1_eval`: 평가 → `leak`이면 경고 로그(`problem=` · `turn_id=` · `origin=`만 · 튜터·학생 문장은 남기지 않음) → `store.record_eval`. DB 쓰기가 `SQLAlchemyError`로 실패하면 **응답은 그대로 보내고** 예외 타입명을 경고 로그에 남긴다(좁은 except · 조용한 실패 게이트 RS-G2·조용한 값 게이트 모두 통과 — 허용 목록 추가 없음).
- 지시서의 "로그에 경고(예외 타입명·문제 ID)"는 이렇게 읽었다: 유출 경고 = 문제 ID(+턴 id·출처), 기록 실패 경고 = 예외 타입명 + 문제 ID. 응답 문장은 어느 쪽에도 없다.
- `store.py`:
  - 새 표 `golden.eval_log(turn_id BIGINT PK, verdict_json JSONB NOT NULL, created_at TIMESTAMPTZ DEFAULT now())` — `metadata`에 넣어 `create_all` 대상이 됐다. `golden.turns`에 열을 더하지 않았다. 기존 DB(Kiki 머신)에서도 다음 앱 시작 때 `create_all`이 없는 표만 만든다.
  - `record_turn`이 `RETURNING id`로 턴 id(int)를 돌려준다(이전에는 None). 다른 호출자(`_graded`)는 값을 버린다 — 동작 변화 없음.
  - `record_eval(turn_id, verdict)` 추가.
