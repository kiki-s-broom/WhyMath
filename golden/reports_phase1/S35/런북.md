# S35 런북 — 게이트 ⑤ 숫자: Kiki 머신 야간 스모크 보고서 세기 (읽기 전용)

> 이 런북은 **읽기만** 한다. 파일을 만들거나 지우지 않고, DB·Docker·서버를 건드리지 않는다. 결과 몇 줄을 클립보드에 담아 세션에 붙여넣으면 끝난다.

## 사전 브리핑 (6항목)

1. **과제 명칭:** 게이트 ⑤ 세기 — 야간 스모크가 치명 실패 없이 끝난 날 세기
2. **목적:** 1단계 게이트 ⑤의 정의는 "야간 스모크 120이 S20 이후 치명 실패(M1·M3·M4·M5) 0건으로 끝난 날이 전체의 90% 이상"이다. 지시서는 이 숫자를 **Kiki 머신 보고서 파일 수**로 세라고 한다. 그 파일(`sim_report.json`)은 Kiki PC에만 있어서 클라우드 세션이 셀 수 없다.
   - 1단계 판정은 이 숫자와 상관없이 정해져 있다. 게이트 ③이 "아니오"라 판정 규칙상 "반복"이다. 이 숫자는 GATE.md ⑤ 칸을 채우는 데만 쓴다.
3. **구체적 절차:** 아래 블록 하나를 붙여넣는다(10초 안팎).
   - 블록이 하는 일: `C:\Users\kiki\Desktop\__AI\sim-nightly\out\` 아래 날짜 폴더를 2026-11-24부터 오늘까지 하나씩 본다.
     - S20 판정(통과)이 2026-11-23이라, 그다음 날부터 센다.
   - 날짜마다 `sim_report.json`이 있는지, 실행 모드(live/fake), M1·M3·M4·M5가 통과했는지를 한 줄로 낸다.
   - 마지막에 요약 줄 `S35_GATE5`를 내고, 결과 전체를 클립보드에 담는다.
4. **성공 기준:**
   - 성공: 맨 끝에 `S35_GATE5 days=… report_days=… ok_days=…` 줄과 `CLIPBOARD=True`가 보인다. 그다음 이 대화창에 Ctrl+V로 붙여넣는다.
   - 실패: `S35_GATE5_REFUSED`가 보이면 그 줄의 이유를 그대로 세션에 알려 준다. 폴더가 없으면 야간 작업이 한 번도 돌지 않았다는 뜻이다.
5. **실행 환경:** Kiki 머신(Phaiakes9) · Windows PowerShell · 작업 디렉터리 `C:\Users\kiki\Desktop\__AI\WhyMath`(읽기만 한다) · 선행 조건 없음(Docker·서버 불필요).
6. **창 구분:** 새 PowerShell 창 하나(창 라벨: "S35 세기"). 끝나면 닫아도 된다.

## 블록 G — 야간 보고서 세기 (읽기 전용)

```powershell
# [창 S35 세기] Kiki 머신 · Windows PowerShell · 읽기 전용 — 야간 스모크 보고서를 날짜별로 세고 결과를 클립보드에 담는다
cd C:\Users\kiki\Desktop\__AI\WhyMath
$NightOut = "C:\Users\kiki\Desktop\__AI\sim-nightly\out"
$Start = [datetime]"2026-11-24"
$Today = (Get-Date).Date
$Lines = New-Object System.Collections.Generic.List[string]
if (Test-Path $NightOut) {
  $Days = 0; $ReportDays = 0; $OkDays = 0
  for ($d = $Start; $d -le $Today; $d = $d.AddDays(1)) {
    $Days++
    $Tag = $d.ToString("yyyy-MM-dd")
    $Rep = Join-Path $NightOut "$Tag\sim_report.json"
    if (Test-Path $Rep) {
      $ReportDays++
      $J = Get-Content -Path $Rep -Raw -Encoding UTF8 | ConvertFrom-Json
      $Fatal = @("M1","M3","M4","M5") | Where-Object { -not $J.$_.pass }
      $Ok = ($J.mode -eq "live") -and ($Fatal.Count -eq 0)
      if ($Ok) { $OkDays++ }
      $Lines.Add("S35_NIGHT date=$Tag report=True mode=$($J.mode) M1=$($J.M1.value) M3=$($J.M3.value) M4=$($J.M4.value) M5=$($J.M5.value) fatal=$($Fatal -join ',') ok=$Ok")
    } else {
      $Lines.Add("S35_NIGHT date=$Tag report=False ok=False")
    }
  }
  $Lines.Add("S35_GATE5 days=$Days report_days=$ReportDays ok_days=$OkDays from=2026-11-24 to=$($Today.ToString('yyyy-MM-dd'))")
} else {
  $Lines.Add("S35_GATE5_REFUSED — 폴더 없음: $NightOut (야간 작업 WhyMath-sim-nightly가 한 번도 결과를 쓰지 않았다)")
}
$Lines | ForEach-Object { $_ }
$Text = $Lines -join "`n"
Set-Clipboard -Value $Text
$Clip = (Get-Clipboard -Raw)
"CLIPBOARD=$([bool]($Clip -and $Clip.Contains('S35_GATE')))"
```

- 붙여넣을 것: 클립보드 전체. 숫자와 날짜뿐이며 학생·튜터 문장은 없다.
- 세는 규칙(세션이 GATE.md에 적는 방법)
  - 분모 `days`는 2026-11-24부터 오늘까지의 **모든 날**이다. 보고서가 없는 날(PC 꺼짐·실행 거부)은 실패로 센다. 기준을 낮추지 않기 위해서다.
  - 분자 `ok_days`는 보고서가 있고, 실제 모드(`live`)이며, M1·M3·M4·M5가 모두 통과한 날이다.
  - 참고로 `report_days`(보고서가 있는 날)만 분모로 한 비율도 함께 적는다.
