## 6. 재생성 명령 (원본 JSON은 커밋하지 않는다 — 백엔드 0.99MB · 테스트 1.72MB)

`src/backend`가 아니라 저장소 뿌리에서 돌린다. `node`는 `/opt/node22/bin`.

```bash
npx --yes jscpd@4 src/backend/whymath_backend --min-lines 12 --max-lines 100000 --max-size 10mb --reporters json --silent --output /tmp/rs.jscpd.full ; echo "EXIT=$?"
```

```bash
npx --yes jscpd@4 tests --min-lines 12 --max-lines 100000 --max-size 10mb --reporters json --silent --output /tmp/rs.jscpd.tests ; echo "EXIT=$?"
```

지시문 원래 명령(`--max-lines` 기본값)은 `--max-lines 100000 --max-size 10mb`를 빼고 `--output /tmp/rs.jscpd`로 돌린다. 이번 세션에서 세 실행 모두 `EXIT=0`, 각각 1분 안에 끝났다.
