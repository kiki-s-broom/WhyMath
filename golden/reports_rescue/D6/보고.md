## 재생성 도구 (머지하지 않음)

  그런데 로컬 CI 미러에서 `tests/infra/test_lint_coverage.py::test_every_python_source_is_linted`가 실패했다.
  저장소 루트 `golden/` 아래 `.py`는 어떤 CI 린트도 덮지 않기 때문이다. `tests/infra`는 읽기 전용이다.

  재생성 명령: 그 커밋을 체크아웃한 뒤 `python3 golden/reports_rescue/D6/client_ledger.py`.
  화면→서버 대조는 먼저 `cd src/backend && python -m pip install -e ".[dev]"`를 하고
