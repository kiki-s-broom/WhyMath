## ① 하는 일

학생 발화 한 줄과 지금의 Polya 상태(4단계 중 어디인가)를 받는다. 그리고 튜터가 **다음에 할 말의 방향**을 정한다. LLM은 부르지 않는다. 정하는 것은 다섯 가지다.

1. 단계 전이 — 다음 단계로 갈지(`next`), 머무를지(`stay`). 한국어 낱말 목록과 글자 수 기준으로만 판정한다.
2. 질문 종류 — 소크라테스 6카테고리 중 하나(명료화·가정 탐색·근거·관점·함의·메타인지).
3. 프롬프트 — 단계별 학생용 발화 본문과 시스템 프롬프트(학년에 따라 "중학생"/"고등학생" 문구만 바뀐다).
4. 답 미루기 단계(1~4)와 노출량 라벨 — 옛 모듈 `l4/hint_deferral.py`에 맡긴다(본문 미열람).
5. 단계별 보조 행동 라벨(예: "조건 나열", "검산").

모아서 `PedagogyDecision` 한 개로 돌려준다. 상태를 저장하지 않는다(stateless). 단계 이동 뒤의 상태 갱신(`turn_count` 0으로 되돌리기 등)은 부르는 쪽이 한다.

## ② 공개 함수

### `PolyaCoach().decide(student_input, state, *, mastery_level=None, misconception_hypotheses=None, pack=None, recent_categories=(), grade=None, standard_code=None)`

| 인자 | 형식 | 범위·뜻 |
| --- | --- | --- |
| `student_input` | `str` | 학생 발화. 빈 문자열 가능 |
| `state` | `PolyaState` | `current_stage`(기본 UNDERSTAND) · `history: list[PolyaStage]` · `turn_count: int ≥0` · `prev_hint_level: int 1~4 또는 None` (pydantic · 모르는 필드 금지) |
| `mastery_level` | `"초보"` · `"발전 중"` · `"숙달"` · `None` | 숙련도 라벨(한국어 · `발전 중`은 띄어 쓴다) |
| `misconception_hypotheses` | `Sequence[MisconceptionHypothesis]` 또는 `None` | 각 항목 `misconception_id: str` · `confidence: float 0~1` · `turns_since_evidence: int ≥0` · `evidence_count: int ≥1` |
| `pack` | `PedagogyPack` 또는 `None` | 교수법 팩. `None`이 아니고 설정 플래그가 켜져 있을 때만 시스템 프롬프트를 다시 조립한다 |
| `recent_categories` | `Sequence[SocraticCategory]` | 직전 AI 턴들의 질문 종류(시간순). 기본 `()` |
| `grade` | `int` 또는 `None` | 한국 학년 정수(아래 ⑤) |
| `standard_code` | `str` 또는 `None` | 성취기준 코드. 팩 조립 때만 쓴다 |

- 반환: `PedagogyDecision`(pydantic). 이 함수가 채우는 필드 — `polya_stage_to_advance`(`"stay"`·`"next"`) · `hint_level`(1~4) · `socratic_category`(**문자열** — 예 `"clarification"`, enum이 아니다) · `prompt` · `system` · `suggested_actions: list[str]` · `reveals: str` · `base_hint_level`(1~4) · `applied_mastery_level`(넘긴 값 그대로). `recommended_cost_tier`는 채우지 않아 모델 기본값 `CostTier.LOCAL`이 들어간다(`l4/models.py` 141~144행).
- 흐름: `should_advance` → 다음 단계(`next`면 한 칸 앞, REVIEW에서는 제자리) → 그 단계의 `STAGE_PROMPTS`·보조 행동 → `select_category` → `decide_hint_level` · `decide_base_hint_level` → `base_system_for_grade(grade)` → (`pack`과 플래그가 있으면) `build_system_prompt`.
- 예외: 이 함수가 직접 던지는 예외는 없다. `student_input`이 `str`가 아니면 `should_advance`의 `.strip()`에서 `AttributeError`가 난다 **[추측]**.

### `PolyaCoach().coach(student_input, state, *, llm)` (async)

- `decide`(기본 인자만) → `llm.generate(prompt, system)` → `filter_tone`. 반환 `(PedagogyDecision, str, ToneReport)`.
- **LLM 호출이 있어 특성화 테스트에서 뺀다**(공유 계약 X 4번 · "부작용으로 제외").
- 참고: `coach`는 `decide`에 `mastery_level`·`grade` 등을 넘기지 않는다. 기본값으로만 결정한다.

### `should_advance(state, student_input, *, mastery_level=None) -> "stay" | "next"`

먼저 `student_input.strip()`을 한다. 판정은 `state.current_stage`로 나뉜다. 모호하면 항상 `stay`이고, `previous`는 절대 돌려주지 않는다.

| 단계 | `next` 조건 | 숙련도에 따른 차이 |
| --- | --- | --- |
| UNDERSTAND | 글자 수 ≥ 20 **그리고** `.` `?` `,` 중 하나가 들어 있음 | `숙달`은 15, `초보`는 25 |
| PLAN | 전략 낱말 20개 중 하나가 **부분 문자열로** 들어 있음(공식·정리·접근·방법·전략·생각·시도·그려·그림·표·도형·예시·작은·비슷한·유사·대입·치환·인수·전개·양변) | `초보`는 글자 수도 10 이상이어야 함 |
| EXECUTE | `=` 있음 **그리고** 답 낱말(답·따라서·그러므로·결론·정답·최종) 있음 **그리고** 줄바꿈 1개 이상 | `숙달`은 줄바꿈 조건을 면제 |
| REVIEW | 없음(마지막 단계라 항상 `stay`) | — |

- 예외: `student_input`이 `None`이면 `AttributeError` **[추측]**.

### `select_category(stage, transition, student_input, hypotheses=None, recent_categories=()) -> SocraticCategory`

규칙은 위에서부터 적용하고, 먼저 맞는 것이 이긴다.

0. `transition == "next"` → 다음 단계의 기본 카테고리(아래 규칙 무시).
1. 발화 신호(`stay`·`previous` 공통 · 부분 문자열) — {가정 · 라고 치 · 라고 하면 · 라고 두} → `ASSUMPTION`, {왜 · 이유 · 근거 · 증명 · 보장} → `EVIDENCE`. 가정 쪽을 먼저 검사한다.
2. 가설 중 `confidence ≥ 0.65` **그리고** `turns_since_evidence ≤ 2`인 것이 있으면 → `ASSUMPTION`.
3. `recent_categories`의 끝 3개가 모두 이번 단계의 기본 카테고리와 같으면 → 단계별 차선 카테고리.
4. 단계 기본 카테고리.

| 단계 | 기본 | 차선(3연속일 때) |
| --- | --- | --- |
| UNDERSTAND | CLARIFICATION | EVIDENCE |
| PLAN | PERSPECTIVE | ASSUMPTION |
| EXECUTE | IMPLICATION | CLARIFICATION |
| REVIEW | META | PERSPECTIVE |

- 이 함수는 `student_input`을 `strip`하지 않는다(`should_advance`와 다르다).
- 예외: `student_input`이 `None`이면 `in` 검사에서 `TypeError` **[추측]**.

### `base_system_for_grade(grade) -> str`

- 공통 시스템 프롬프트(원칙 6개 · 금지 표현 목록 · "한 발화에 질문 1개 · 3문장 이내")에 학년 문구 하나를 끼워 넣는다.
- `grade`: 1~6 → "초등학생" · 7~9 → "중학생" · 10~14 → "고등학생"(N수 포함) · 15~16 → "대학생" · `None`이나 범위 밖 → "중·고등학생"(기본).
- 예외: `grade`가 문자열이면 `lo <= grade` 비교에서 `TypeError` **[추측]**.

### 상수·형식

- `StagePrompt(system: str, prompt: str)` — pydantic · 모르는 필드 금지.
- `STAGE_PROMPTS: dict[PolyaStage, StagePrompt]` — 4단계 학생용 발화. 시스템 프롬프트는 4단계 모두 기본 문구("중·고등학생")다.
- `BACKTRACK_PROMPT = "잠깐, 한 발 뒤로 가서, "` — 정의만 있고 이 자산 안에서는 쓰지 않는다.
- `SocraticCategory(str, Enum)` 6개 · `KOREAN_LABEL`(한국어 이름) · `EXAMPLE_QUESTION`(예시 질문 한 줄).
- `STAGE_DEFAULT`·`INPUT_SIGNAL_TOKENS`는 옛 `l4/turn_meta`도 쓰는 공개 상수다(주석 기준).

## ⑤ 헷갈리는 값

- **단계 ID**: `PolyaStage` 값은 영어 소문자다(`"understand"`·`"plan"`·`"execute"`·`"review"`). 옛 `DialogueTurn.targeted_step`은 **1부터 세는 번호**를 쓴다(`l4/models.py` 주석). 서로 다른 표기다.
- **질문 종류**: `select_category`는 enum을 돌려준다. `decide`는 `.value` 문자열(`"meta"` 등)을 넣는다. 화이트리스트(`INPUT_SIGNAL_TOKENS`)의 순서가 가정 → 근거라서, 두 신호가 함께 있으면 `ASSUMPTION`이 이긴다.
- **숙련도**: 한국어 문자열 3개다. `"발전중"`(붙여 씀)이나 영어는 맞지 않는다. 전이 판정에서는 `None`처럼 취급된다 **[추측]**. `hint_deferral`에서의 취급은 미확인이다.
- **신뢰도**: `confidence`는 0~1 실수다(0~100 아님). 경계 0.65와 `turns_since_evidence` 2는 **둘 다 포함**(`≥`·`≤`)이다.
- **가설 정렬 가정**: 가설 목록이 `confidence` 내림차순이라고 가정한다. 0.65 미만을 만나면 거기서 멈춘다. 정렬되지 않은 목록을 넘기면 뒤쪽의 고신뢰 가설을 놓칠 수 있다 **[추측]**.
- **글자 수**: 파이썬 `len`이다. 한글 한 글자도 1이다. `should_advance`는 앞뒤 공백·줄바꿈을 지운 뒤에 센다. 그래서 끝의 줄바꿈 하나는 "여러 줄"로 치지 않는다.
- **부분 문자열 일치**: "표"는 "표시"에도, "답"은 "대답"에도, "왜"는 "왜곡"에도 걸린다 **[추측 · 의도된 동작인지 미확인]**.
- **문장 부호**: UNDERSTAND의 문장 부호는 `.` `?` `,` 셋뿐이다. `!`·`。`·`？`(전각)은 세지 않는다.
- **학년**: `UserProfile.grade` 실값은 10~14(고1~N수2)다. 골든 경로(중2)는 `grade=8` → "중학생"이 된다. 13~14는 대학 1~2학년이 아니라 N수다(`prompts.py` 주석).
- **답 미루기 단계**: `hint_level`은 1~4 정수다. `reveals`는 `"next_concept_to_focus"`·`"step_flow"`·`"partial_steps_demo"`·`"full_solution"` 중 하나다.
- **설정 플래그**: `pedagogy_pack_prompt_enabled`의 기본값은 `True`다(`config.py` 294행).
