## 후처리 스크립트(재생성용 · 저장소 밖에서 실행)

진단 세션이라 도구 코드를 저장소에 더하지 않았다. 아래를 파일로 저장해 `python <파일> /tmp/rs.ledger.raw.csv golden/reports_rescue/D5/모듈별_테스트수.tsv golden/reports_rescue/D1/ledger.csv`로 돌린다.

```python
"""D1 후처리 — R1 대장 CSV의 '단위 테스트가 실행' 칸을 D5 정적 대응표로 채운다.

사용: python fill_unit_static.py <대장 원본 CSV> <D5 모듈별_테스트수.tsv> <출력 CSV>
- D5 5번째 칸(직접 import하는 테스트 파일 수)이 1 이상이면 '예(정적)', 0이면 '아니오(정적)'.
- 정적 근사다(실행 아님). D5에 없는 모듈(골든)은 '기록 없음' 그대로 둔다.
- 등급 칸이 '섬/잔해(실행 기록 없음)'인 행만 '섬'·'잔해'로 가른다(공유 계약 「등급 판정」).
"""
import csv
import sys

raw, tsv, out = sys.argv[1:4]
# D5: 모듈 이름 → 직접 import 테스트 파일 수
static = {}
with open(tsv, encoding="utf-8-sig") as f:
    rows = list(csv.reader(f, delimiter="\t"))
for r in rows[1:]:
    static[r[0]] = int(r[4])
with open(raw, encoding="utf-8-sig") as f:
    ledger = list(csv.reader(f))
head, body = ledger[0], ledger[1:]
i_mod, i_g, i_l, i_unit = 0, head.index("골든 등급"), head.index("옛앱 등급"), head.index("단위 테스트가 실행")
filled = 0
for r in body:
    if r[i_mod] not in static:
        continue  # 골든 모듈 — D5 범위 밖
    unit = static[r[i_mod]] > 0
    r[i_unit] = "예(정적)" if unit else "아니오(정적)"
    for i in (i_g, i_l):
        if r[i] == "섬/잔해(실행 기록 없음)":
            r[i] = "섬" if unit else "잔해"
    filled += 1
# D5 모듈 수와 채운 수가 다르면 실패(조용히 넘어가지 않는다)
if filled != len(static):
    sys.exit(f"채운 행 {filled} ≠ D5 모듈 {len(static)}")
with open(out, "w", encoding="utf-8-sig", newline="") as f:
    csv.writer(f).writerows([head, *body])
print(f"채움 {filled}행 · 출력 {len(body)}행")
```
