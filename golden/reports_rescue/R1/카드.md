## 명령 예

① 정적 대장(실행 기록 없음 · 이 카드의 숫자):

```bash
cd src/backend
python -m golden.rescue.ledger --entry golden.api --entry whymath_backend.app --csv /tmp/rs.ledger.csv > /tmp/rs.ledger.txt 2>&1; echo "EXIT=$?"
```

② 실행 기록 셋 + 고아 게이트(D1·G1용 — coverage JSON 만드는 법은 아래):

```bash
cd src/backend
python -m golden.rescue.ledger --entry golden.api --entry whymath_backend.app --journey-golden /tmp/cov_golden.json --journey-legacy /tmp/cov_legacy.json --unit /tmp/cov_unit.json --csv /tmp/rs.ledger.csv --baseline ../../golden/reports_rescue/G1/orphan_baseline.txt --gate-package golden; echo "EXIT=$?"
```

coverage JSON은 `python -m coverage run --source=whymath_backend,golden -m pytest <대상>` 다음 `python -m coverage json -o <파일>`로 만든다(coverage 7.x · 함수별 `functions` 영역이 있어야 한다 — 없으면 도구가 종료 코드 2로 거부).

## 열 · 값 규칙(CSV · `utf-8-sig`)

| 열 | 값 |
| --- | --- |
| 골든 등급 / 옛앱 등급 | 첫째 `--entry` = 골든 열, 둘째 = 옛앱 열. `가동`·`대기`·`섬`·`잔해`, 기록이 없으면 `대기(실행 기록 없음)`·`섬/잔해(실행 기록 없음)` |
| 골든에서 닿음 / 옛앱에서 닿음 | `예`·`아니오` (부모 `__init__.py`와 그것이 import하는 모듈 포함) |
| 경로 테스트가 실행 | `예(골든)`·`예(옛앱)`·`예(골든·옛앱)`·`아니오`·`기록 없음` |
| 단위 테스트가 실행 | `예`·`아니오`·`기록 없음` |
| 이 모듈을 import하는 모듈 수 | 같은 두 패키지 안에서 직접 import하는 모듈 수. 그래프 밖 모듈은 빈칸 |
| 비고 | `그래프 밖(__init__ 없는 폴더)` · `문자열로 불러옴(골든)`(경로 테스트는 실행했는데 정적으로 안 닿음) |

- 실행 판정: 함수(메서드 포함) 안에서 실행된 줄이 1줄 이상이면 실행. 함수가 없는 모듈만 맨 위 코드로 본다(`__init__.py`·상수 모듈은 import되면 실행으로 잡힌다).
- 고아 게이트: `--gate-package`(기본 `golden`) 안에서 모든 진입점으로 섬·잔해인 모듈이 기준선에 없으면 종료 코드 1. `--update`는 기준선을 다시 쓰고 0. 기준선 파일이 없으면 2.
- 종료 코드: 0 정상 · 1 게이트 실패 · 2 입력 오류(진입점 없음·coverage 형식·경로 0건 일치).
