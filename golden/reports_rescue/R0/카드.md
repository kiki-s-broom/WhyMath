# 카드 R0 — 목차 도구 `golden.rescue.outline`

- 기준 커밋: main `39d8c890` · 작성일 2026-11-17
- 한 줄 결론: 파이썬 파일을 import하지 않고 `ast`로만 읽어 목차(모듈 한 줄 / 함수·클래스 한 줄)를 뽑는 도구가 생겼다. C1~C8·P1~P3는 큰 파일을 통째로 열지 말고 이것부터 돌린다.

## 사용법 3줄

1. `cd src/backend && python -m golden.rescue.outline whymath_backend/l2 --level 1 --out /tmp/rs.outline.txt` — 모듈마다 `경로 · 줄 수 · 함수 N · 클래스 N · 설명 첫 줄 · 큼/-`
2. `python -m golden.rescue.outline whymath_backend/api/coach.py --level 2 --out /tmp/rs.coach.txt` — 함수·클래스마다 `def 이름 · 시작~끝 · N줄 · 설명 첫 줄`(데코레이터 줄부터 센다 · 메서드는 `클래스.메서드`)
3. 종료 코드로 판정한다: 0 정상 · 2 대상 0개(경로 없음·.py 없음) · 3 출력 2,000줄 초과인데 `--out` 없음(화면 50줄만 보임). `--out`을 주면 화면에는 앞 50줄 + `출력 N줄`만 나온다.

## 숫자 표

| 대상 | 명령 | 출력 줄 | 종료 코드 |
| --- | --- | ---: | ---: |
| `whymath_backend/l2` (41모듈) | `--level 1` | 41 | 0 |
| `whymath_backend/api/coach.py` (4,570줄) | `--level 2` | 80 (머리 1 + 함수·클래스 79) | 0 |
| `whymath_backend` 전체 (교차 확인) | `--level 1` | 844 · "큼" 27 · 파싱 실패 0 | 0 |
| `whymath_backend/l3` | `--level 2` (`--out` 없음) | 3,318 → 화면 50줄 + 경고 | 3 |

- 위 "출력 줄"은 끝의 `출력 N줄` 꼬리 줄을 뺀 수다.
- 전체 844모듈·큼 27개는 지시서 사전 실측(844 · 1,500줄 초과 27)과 같다.

## 다음 세션이 알아야 할 것

- **출력은 읽기 상한에 들어간다.** `--level 1`은 모듈 수만큼, `--level 2`는 함수·클래스 수만큼 줄이 나온다. 패키지에 `--level 2`를 그대로 돌리면 금방 수천 줄이다(l3 = 3,318줄). 파일 단위로 돌린다.
- **본문은 안 나온다.** 이름·줄 범위·설명 첫 줄(80자에서 자름)뿐이다. 설명이 없으면 `-`다.
- **함수 수**는 파일 안의 모든 `def`(메서드·중첩 함수 포함)를 센다. `--level 2`는 모듈·클래스 몸체의 정의만 낸다(함수 안 중첩 함수는 본문으로 보고 뺀다).
- 숨김 폴더·`__pycache__`는 건너뛴다. `__init__.py`가 없는 폴더(`l1/rights/`)도 파일 시스템으로 보므로 빠지지 않는다.
- 문법 오류 파일은 `파싱 실패: SyntaxError` 한 줄로 나온다(건너뛰지 않는다).
