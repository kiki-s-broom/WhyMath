2026년 11월 8일 · @ik-ki kim

0. 이 문서 사용법

이 문서는 Claude Code 세션에 그대로 붙여넣는 지시문 모음이다. 3주(작업 세션 15회, 세션당 2~4시간) 안에 경로 하나를 완성한다: 실제 학생 1명이 Flutter 앱에서 중2 일차함수 문제 1개를 소크라테스 대화로 끝까지 풀고, 숙련도 숫자 하나가 PostgreSQL에 갱신된다. 이것이 완료 정의이고, 이 밖의 모든 것은 §5에 있다.

세 가지 원칙은 15세션 내내 바뀌지 않는다.

  1. 옛 코드는 import만, 수정 금지. 고쳐야 돌아가는 코드는 golden/ 아래로 복사해서 거기서 고친다.
  2. 범위는 중2 일차함수 한 단원, 문제 30개. 넓히고 싶은 충동이 들면 §5를 다시 읽는다.
  3. 완료 기준은 골든 패스 e2e 테스트 하나뿐. 이 테스트가 빨간불이면 어떤 PR도 머지하지 않는다.

용어 세 개만 알면 된다.

  • 골든 패스: 학생이 앱에서 밟는 핵심 경로 1개 (§1의 GP-1~GP-6)
  • 스켈레톤: 그 경로를 최소 코드로 끝까지 잇는 뼈대. 못생겨도, 하드코딩이어도 된다.
  • 수확 장부: 옛 코드에서 무엇을 가져왔고 무엇을 버렸는지 한 줄씩 적는 golden/HARVEST.md

세션 운영은 단순하다. 각 세션은 §3의 시작 템플릿으로 열고 종료 템플릿으로 닫는다. 한 세션에 산출물 하나. 산출물이 안 나오면 다음 세션으로 넘기되, 범위를 넓혀서 만회하려 하지 않는다. 코드 상태를 모른 채 쓴 계획이므로 S1(상태 측정) 결과에 따라 S3~S5의 세부는 바뀔 수 있다. 원칙 세 개와 완료 정의는 바뀌지 않는다.

1. 골든 패스 6단계

학생이 앱을 켜서 끄기까지 밟는 경로는 여섯 단계다. 각 단계의 "최소 구현"이 스켈레톤이고, "금지" 열은 3주 안에 그 단계에 끌어오면 안 되는 것이다. GP-6이 끝나면 GP-2로 돌아가 다음 문제를 낸다.

여섯 단계 전부를 잇는 HTTP 호출은 세 개면 된다: POST /golden/session(GP-1), POST /golden/answer(GP-3~GP-6을 한 번에 처리해 튜터 응답 또는 판정 결과를 돌려줌), GET /golden/next(GP-2). 엔드포인트가 늘어나려 하면 범위가 새고 있다는 신호다.

옛 코드에서 가져올 수 있는 것은 GP-2의 문항 데이터(기존 문항 자산에 중2 일차함수가 있으면 추출, 없으면 S3에서 직접 작성)와 GP-4의 LLM 호출 래퍼뿐이다. 나머지는 새로 쓰는 쪽이 빠르다.

1-A. 스트랭글러 피그가 작동하는 자리

[embed: node/5babe07b-28c5]

새로 쓰는 곳은 색 상자 셋뿐이다: Flutter의 lib/golden/, 백엔드의 golden/, PostgreSQL의 schema golden. 옛 코드는 같은 프로세스·같은 DB 안에 그대로 남지만 아무도 부르지 않고, golden/이 필요한 모듈만 import한다. 고전적 스트랭글러 피그의 "파사드"는 여기서 Flutter 앱 진입점과 FastAPI 라우터다. 진입점이 새 화면만 열고 /golden/*만 호출되는 순간 옛 코드는 실행 경로에서 떨어지고, 린트가 역방향 import를 막아 다시 엉키지 않게 한다. 3주 뒤 한 번도 import되지 않은 모듈이 /legacy로 가고, 과목 2개째가 생겨 golden/이 app/으로 이름을 바꾸는 날 옛 나무는 사라진다.

3-2. S1 전문 — 상태 측정

세션 S1 시작. 오늘은 코드를 한 줄도 고치지 않는다. WhyMath 저장소의 현재 상태를 측정해서 golden/STATE.md 한 파일만 만든다.

1단계 — 30분 테스트.
현재 코드로 "학생이 중2 일차함수 문제 1개를 소크라테스 대화로 끝까지 푸는" 경로가 실제로 도는지 확인한다. 백엔드를 띄우고, 가능한 가장 짧은 방법(curl, 테스트 스크립트, Flutter 앱 중 하나)으로 시도한다. 30분 안에 안 되면 멈추고, 어느 단계(GP-1~GP-6)에서 끊기는지와 왜 끊기는지를 적는다. 고치려 하지 않는다.

2단계 — 질문 8개에 답한다. 모르면 "모름"이라고 적는다.
  Q1. 백엔드 프레임워크와 진입점 파일 경로는? (예: FastAPI, app/main.py)
  Q2. PostgreSQL 연결 설정은 어디 있고, 테이블은 몇 개인가?
  Q3. 튜터 LLM 호출은 어느 파일의 어느 함수에서 하는가? 어떤 모델·API를 쓰는가?
  Q4. 문항 데이터는 어디에 어떤 형식으로 있는가? 중2 일차함수 문항이 몇 개 있는가?
  Q5. Flutter 앱은 어느 폴더이고, 백엔드와 통신하는 API 클라이언트 파일은 어디인가?
  Q6. 현재 테스트 수, 마지막 CI 통과 커밋, CI 설정 파일 경로는?
  Q7. 사용자 진입점(HTTP 라우트, Flutter 화면)에서 호출 그래프를 따라 도달 가능한 Python 모듈 수와 전체 모듈 수는? (대략이면 된다. 예: 전체 210개 중 도달 가능 60개)
  Q8. 최근 PR 20개를 무작위로 골라, 그 PR이 추가한 코드가 Q7의 도달 가능 집합에 들어 있는 비율은?

네 개 파일이 "아직 필요 없다"고 말하는 역할을 자동화한다. S2에서 전부 심고, 이후 세션에서는 손대지 않는다. 백엔드가 Python/FastAPI가 아니면 S1의 STATE.md Q1에 맞춰 4-3과 4-4만 바꾼다. 나머지 둘은 언어와 무관하다.

4-4. e2e 테스트 뼈대 tests/golden/test_golden_path.py

S2에서는 이대로 두어 빨간불을 만들고, S4~S5에서 pytest.fail 줄을 지워가며 초록으로 바꾼다.

"""골든 패스 e2e — 학생 한 명이 문제 하나를 끝까지 푼다.
이 테스트가 빨간불이면 어떤 PR도 머지하지 않는다."""
import pytest
from fastapi.testclient import TestClient

# golden/api.py가 생기기 전까지는 import 자체가 실패한다 — 그것이 S2의 의도된 빨간불
from golden.api import app

client = TestClient(app)


def test_student_solves_one_problem_end_to_end():
    # GP-1 세션 시작: 닉네임만으로 익명 세션
    r = client.post("/golden/session", json={"nickname": "테스트학생"})
    assert r.status_code == 200
    session_id = r.json()["session_id"]

    # GP-2 문제 제시: 30문항 중 첫 문제
    r = client.get(f"/golden/next?session_id={session_id}")
    assert r.status_code == 200
    problem = r.json()
    assert problem["id"].startswith("LF-")  # 일차함수(Linear Function) 문항 접두사

    # GP-3 + GP-4: 틀린 답을 내면 튜터가 되묻는다 (판정이 아니라 질문이 와야 함)
    r = client.post("/golden/answer", json={
        "session_id": session_id,
        "problem_id": problem["id"],
        "text": "모르겠어요",
    })
    assert r.status_code == 200
    assert r.json()["kind"] == "tutor_turn"  # 'graded'가 아니라 'tutor_turn'
    assert len(r.json()["message"]) > 0

    # GP-5 + GP-6: 정답을 내면 판정과 숙련도 갱신이 온다
    r = client.post("/golden/answer", json={
        "session_id": session_id,
        "problem_id": problem["id"],
        "text": problem["_test_answer"],  # 테스트 모드에서만 노출되는 정답 필드
    })
    assert r.status_code == 200
    body = r.json()
    assert body["kind"] == "graded"
    assert body["correct"] is True
    assert 0.0 <= body["mastery"] <= 1.0
    assert body["mastery"] > 0.0  # 맞았으니 0에서 올라가야 한다

    # 다음 문제로 돌아간다 (GP-6 → GP-2 루프)
    r = client.get(f"/golden/next?session_id={session_id}")
    assert r.json()["id"] != problem["id"]

    pytest.fail("S2: 아직 구현 전. 이 줄은 S5에서 지운다.")
