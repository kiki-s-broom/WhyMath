# 학생 세션 관찰 기록 양식 (S8 작성 · S9~S12가 복사해서 쓴다)

이 파일은 **양식**이다. 실제 기록은 이 파일을 복사해 `golden/logs/<날짜>_<가명>.md`로 저장한다(`golden/logs/`는 `.gitignore` 대상이라 저장소에 올라가지 않는다 — 양식만 밖에 둔다).

기록 규칙(공통 규칙 9 · 미성년자 데이터):
- 학생 식별자는 **가명(닉네임)뿐**이다. 실명·학교·학년·연락처는 어디에도 적지 않는다. 성인 지인도 같다.
- 가명 접두로 출처를 구분한다 — 본인 `self-*` · AI 시뮬레이션 `sim-*` · 성인 지인 `adult-*` · 실제 학생(원본 묶음 S9 이후) `stu-*`. 집계는 항상 출처별로 나눈다.
- 학생이 소리 내어 말한 것은 들은 그대로 적는다(고치지 않는다). 개발자 메모는 따로 적는다.
- 한 문제가 끝날 때마다 바로 적는다(세션이 끝난 뒤 기억으로 채우지 않는다).

## 세션 정보

| 항목 | 값 |
| --- | --- |
| 학생 가명(닉네임) | `self-` / `sim-` / `adult-` 중 하나로 시작 |
| 출처 | 본인 / AI 시뮬레이션(페르소나 번호) / 성인 지인 / 실제 학생 |
| 날짜 | YYYY-MM-DD |
| 시작·종료 시각 | HH:MM ~ HH:MM (목표 20분) |
| 실행 환경 | 기기(에뮬레이터·안드로이드 패드·폰) · 서버(Kiki 머신 LAN IP:8000) · LLM 모드(가짜 `GOLDEN_FAKE_LLM=1` / 실제 OpenRouter) |
| 서버 커밋 | `git log -1 --oneline` 출력 한 줄 |
| 시작 숙련도 → 끝 숙련도 | 0.00 → 0.xx (앱 위쪽 숫자) |
| 관찰자 | 역할만(개발자 / 보호자 동석 여부) — 이름 없음 |

## 문제별 기록

문제 하나에 표 한 줄. 판정은 앱 결과 화면의 "맞음"/"틀림"을 그대로 적는다.

| 문제 ID | 시작 시각 | 튜터 턴 수(0~3) | 판정(맞음/틀림) | 막힌 지점 | 학생이 소리 내어 말한 것 | 개발자 메모 |
| --- | --- | --- | --- | --- | --- | --- |
| LF-01 | HH:MM | 0 | 맞음 | 없음 | "" | |
| LF-02 | HH:MM | | | | "" | |
| LF-03 | HH:MM | | | | "" | |
| | | | | | | |

열 설명:
- **막힌 지점** — 어디서 손이 멈췄는지(예: 문제 뜻을 못 읽음 / x에 값 넣기 / 음수 곱셈 / 답 입력 형식 / 튜터 말을 이해 못 함 / 앱 조작). 없으면 "없음".
- **학생이 소리 내어 말한 것** — 들은 그대로. 따옴표 안에.
- **개발자 메모** — 앱·서버의 이상(오류 띠·느림·수식 깨짐·튜터가 정답을 말함 등)과 학생 반응에 대한 해석. 해석은 "추정"이라고 표시한다.
