# 자동 진행 기본방침 — 추천안이 곧 결정이다

> Kiki 지시 2026-11-26: "건건이 나의 결정이 필요하다고 하는 것이 과다한 개발 지연을 초래한다. 최대한 자동화를 위한 환경을 만들 것."
> 이 문서가 정본이다. `CLAUDE.md`와 `golden/AUTO_RUN.md`는 이 문서를 가리킨다.
> 적용 대상: 이 저장소에서 일하는 모든 AI 세션(대화 세션·예약 실행·지시문 세션).

## 1. 원칙 세 줄

1. **묻지 않고 진행한다.** 선택지가 있으면 추천안을 고르고 그대로 한다. "어느 쪽으로 할까요"로 턴을 끝내지 않는다.
2. **고른 것은 적는다.** `golden/DECISIONS_AUTO.md`에 한 줄 — 무엇을 · 무엇으로 정했나 · 근거 · 되돌리는 법. Kiki는 나중에 읽고 뒤집을 수 있다.
3. **되돌릴 수 없는 것만 멈춘다.** 아래 2절의 여섯 가지에 해당할 때만 사람을 기다린다. 그때도 나머지 일은 계속한다.

## 2. 멈추는 여섯 가지 (이 밖에는 멈추지 않는다)

| # | 멈추는 일 | 왜 | 멈춘 동안 |
| --- | --- | --- | --- |
| 1 | **지우기·덮어쓰기** — 옛 패키지 삭제(3단계 S74), DB 데이터 삭제, 남의 브랜치 강제 푸시, 기록 삭제 | 되돌릴 수 없다 | 삭제 목록과 증거까지 만들어 둔다 |
| 2 | **실제 사람과 법** — 학생·보호자 동의, 법률 판단, 실제 학생 데이터를 저장소 밖으로 보내기 | 기계가 대신할 수 없는 의사표시다(CLAUDE.md 절대 금기) | 합성 데이터로 계속한다 |
| 3 | **돈과 바깥 계정** — 유료 서비스 새 가입·요금제 변경, 시크릿·권한·저장소 보호 설정 변경, 앱 배포·공개 | 저장소 밖에 흔적이 남는다 | 설정 초안과 런북을 만들어 둔다 |
| 4 | **Kiki 머신에서만 되는 실행** — 로컬 LLM·실기기·로컬 DB가 필요한 단계 | 클라우드 세션이 닿지 못한다 | 런북까지 쓰고, 안 닿아도 되는 다음 작업을 한다 |
| 5 | **코딩 헌법** — `constitution/` 수정 | 가드 훅이 막는다. 우회하지 않는다 | `docs/constitution_proposals/`에 초안을 둔다 |
| 6 | **기준을 낮추는 일** — 완료 기준·게이트 숫자·검사 강도를 통과시키려고 완화 | 측정이 위장으로 바뀐다 | 기준 그대로 "미달"로 적고 다음 일을 한다 |

멈출 때는 한 줄로 말한다: 여섯 가지 중 몇 번인지 · 무엇을 기다리는지 · 그동안 무엇을 하는지.

## 3. 이제 묻지 않고 하는 일 (종전에는 멈추던 것)

| 종전에 멈추던 곳 | 이제 |
| --- | --- |
| 방법이 둘 이상이다(도구를 새로 만들까 / 기존 것을 넓힐까 등) | 추천안으로 진행 · 기록 |
| 지시문과 저장소 사실이 다르다 | 저장소 사실을 따른다 · 지시문 원본을 고친다 · 기록 |
| 다른 문서와 결론이 어긋난다 | 측정 근거가 있는 쪽을 따른다 · 기록 |
| 지시문이 "Kiki 결정" "Kiki 확인"을 요구한다(2절이 아닌 것) | 추천안으로 진행 · 기록 |
| 관문(go/no-go) 판정 | 지시문의 숫자 기준으로 판정한다. go면 다음으로, no-go면 지시문의 no-go 조치를 한다. 기준이 숫자가 아니면 추천안 · 기록 |
| 계약 변경 제안(공유 계약의 모양을 바꿔야 한다) | 기준을 낮추는 것이 아니면 원본을 고쳐 진행 · 기록 |
| 작업이 "일부 완료"로 끝났다 | 다음 실행이 남은 대상부터 이어서 한다 |
| 단계 경계(1단계 → 2단계) | 앞 단계 게이트 보고가 go면 넘어간다 |
| PR을 열었다 | CI가 전부 초록이면 자동 머지를 켠다(머지 큐 · SQUASH) |
| CI가 빨갛다 | 원인을 찾아 고친다. 테스트를 끄거나 건너뛰지 않는다 |
| 범위 밖 파일을 고쳐야 한다(골든 밖) | `backlog.py amend --path … --reason …`으로 이유를 선언하고 고친다. 옛 코드(`whymath_backend`)는 여전히 고치지 않고 복사해서 고친다 |
| 구독·점검·알림 예약 같은 세션 운영 | 묻지 않고 한다 |

## 4. 기록 형식 — `golden/DECISIONS_AUTO.md`

표 한 줄에 다섯 칸이다. 길게 쓰지 않는다.

`날짜 · 세션(작업 번호) · 무엇을 정했나 · 근거 한 줄 · 되돌리는 법`

- "되돌리는 법"을 적을 수 없으면 그것은 2절 1번이다. 멈춘다.
- 같은 결정을 두 번 적지 않는다. 뒤집혔으면 새 줄에 "뒤집음 — 이유"를 적는다.
- Kiki가 읽는 곳은 이 파일 하나다. PR 본문·보고에는 이 파일의 줄 번호만 적는다.

## 5. Kiki가 개입하는 법

- **뒤집기:** 세션에 "DECISIONS_AUTO 몇 번째 줄 뒤집어"라고 하면 된다. 그 세션이 되돌리고 새 줄을 적는다.
- **잠시 멈추기:** 예약 실행을 끄면 자동 진행이 멈춘다(예약 작업 목록에서 "WhyMath 골든 지시문 자동 실행"을 끔).
- **멈춤 목록 바꾸기:** 2절 표를 고치는 PR을 낸다. 이 문서가 정본이다.

## 6. 화면에서 한 번 해 둘 설정 (세션이 대신할 수 없다)

- 클라우드 세션의 권한 모드는 입력창 옆 목록에서 고른다. **Auto**를 고르면 대부분의 도구 호출을 묻지 않고 실행한다(조직이 허용하고 모델이 지원할 때만 보인다). 설정 파일로는 바꿀 수 없다.
- 저장소 `.claude/settings.json`의 기본 모드가 "계획 승인 대기"(`"defaultMode": "plan"`)로 되어 있다. 이것을 "편집 수락"(`"acceptEdits"`)으로 바꾸고 `permissions.allow`에 자주 쓰는 명령(`git add`·`git commit`·`git push`·`python3` 등)을 더하면 승인 대기가 줄어든다. **이 파일은 AI 세션이 고치지 못한다** — AI가 자기 권한을 스스로 넓히는 변경이라 권한 검사가 막는다(2026-11-26 실측). Kiki가 직접 고친다. 지우기·강제 푸시·DB 삭제를 묻는 `ask` 목록은 그대로 둔다.

## 7. 이 방침이 바꾸지 않는 것

- `CLAUDE.md`의 절대 금기(저작권·미성년자 데이터·검증 없는 LLM 응답 제공 등)와 의사결정 우선순위.
- 검사: 완료 기준은 `tests/golden` 초록, 판정은 종료 코드, 보호 장치는 일부러 어겨서 확인.
- 정직한 보고: 돌리지 못한 검증·확인하지 못한 사실은 그대로 적는다. 자동으로 진행한다고 해서 "확인했다"고 적지 않는다.
