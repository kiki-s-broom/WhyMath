# S12 성인 지인 2명 런북 (Kiki 머신 · 1회 · 약 60분)

성인 지인 2명이 **조작 설명 없이 혼자** 골든 앱으로 문제 5개(LF-01~LF-05)를 푼다. 닉네임은 `adult-1`·`adult-2`다. 끝나면 두 사람에게 질문 2개("어느 순간이 제일 답답했어요?" · "다시 할래요?")를 묻고 기록한다. 관찰 기록 2건과 서버 대화 기록 CSV 2건을 S12 AI 세션에 붙여 넣으면, 세션이 그것을 읽어 `golden/reports_no_students/S12/보고.md` 2차 판을 쓴다.

S9 런북(`golden/reports_no_students/S9/런북.md`)의 창 A·창 B 구성과 자가검증을 그대로 잇는다. S9와 다른 점은 다섯 가지다.
- **역할 규칙이 없다.** 지인은 평소대로 푼다. Kiki는 옆에서 보기만 하고 조작을 알려 주지 않는다.
- **S10 수정이 들어간 서버인지 앱 실행 전에 검사**한다. 창 B가 떠 있는 서버에 LF-05 정답을 말꼬리를 붙여(`8이요`) 보내 보고, 정답으로 채점되지 않으면 앱을 띄우지 않는다(S10 항목 4).
- **닉네임을 블록이 정한다.** DB에 `adult-1` 기록이 없으면 `adult-1`, 있으면 `adult-2`, 둘 다 있으면 거부한다. 두 번째 사람은 앱을 `q`로 끈 뒤 같은 앱 블록을 다시 붙여넣으면 된다.
- 작업 폴더는 `C:\Users\kiki\Desktop\__AI\WhyMath-s12adult`이다(S9 폴더와 섞이지 않게).
- CSV는 두 사람 것을 한 번에 꺼내고, 세션에 전달할 4개 파일을 **한 번의 붙여넣기**로 묶는다.

## 6항목 브리핑

1. **과제 명칭**: 골든 앱 S12 성인 지인 세션 — `adult-1`·`adult-2`가 혼자 5문제씩
2. **목적**: S10이 고친 앱(판정 조사 · 튜터 말투·마지막 되묻기 · 말풍선 수식 · 채점 말꼬리)을 **처음 보는 사람**이 쓸 때 어디서 멈추는지 본다. 본인(S9)은 앱을 알고, AI(S11)는 화면을 보지 않는다. 성인 지인은 앱을 모르는 사람이 화면을 보는 유일한 출처다. 결과는 S13 집계에 `adult-*` 출처로 따로 들어간다. **성인이 쉽게 푼 것을 "학생도 쉽다"로 해석하지 않는다.**
3. **구체적 절차**(총 약 60분)
   - 창 A(서버 전용 · 3~5분): 작업 폴더 → 자가검증 5개 → 시연 DB → 골든 서버(실제 LLM). 이 창은 그 뒤 건드리지 않는다.
   - 창 B 준비(1분): "0. 기록 파일 준비" 블록이 `golden\logs\<오늘 날짜>_adult1.md`·`_adult2.md`를 만들고 메모장 2개로 연다.
   - 창 B 앱 — 첫 사람(첫 빌드 3~6분): 블록이 `NEXT_NICKNAME=adult-1`을 출력하고 폰에 앱을 띄운다. **닉네임은 Kiki가 직접 넣고**(`adult-1`) 첫 문제 화면에서 폰을 건넨다.
   - 첫 사람 풀이(약 15분): 5문제를 혼자 푼다. Kiki는 메모장 `_adult1.md`에 문제마다 한 줄씩 적는다. 5번째 결과 화면이 나오면 폰을 돌려받고 **질문 2개를 묻고** 답을 그대로 적는다.
   - 창 B 앱 — 두 번째 사람(1~3분): 창 B에서 `q`로 앱을 끄고 앱 블록을 다시 붙여넣는다. `NEXT_NICKNAME=adult-2`가 보이고 앱이 다시 뜬다. 닉네임 `adult-2`를 넣고 건넨다.
   - 두 번째 사람 풀이(약 15분): 첫 사람과 같다. 메모장은 `_adult2.md`.
   - 기록 꺼내기(1분): 앱을 `q`로 끈 뒤 창 B에서 CSV 2개를 뽑는다.
   - 세션에 전달(1분): 블록 하나가 관찰 기록 2개 + CSV 2개를 한꺼번에 클립보드에 넣는다 → S12 세션 대화창에 붙여 넣는다.
   - 정리(1분): 창 A를 Ctrl+C로 멈춘 뒤 창 B에서 시연 DB를 지운다(CSV 2개가 있을 때만).
4. **성공 기준**
   - 창 A: `WORKTREE_HEAD`와 `EXPECTED`가 같고 `CODE_BASE_OK=True` · `S12_PR_PRESENT=True` · `PORT_8000_FREE=True` · `DB_READY=True` · `LLM_MODE=live`가 보인 뒤 마지막 줄이 `Uvicorn running on http://0.0.0.0:8000`이다.
   - 창 B(앱 블록): `SERVER_REACHABLE=200` · `S10_TAIL_GRADED=True` · `WRONG_TAIL_REJECTED=True` · `NEXT_NICKNAME=adult-1`(두 번째엔 `adult-2`) · `ADB=…adb.exe` · `PHONE=…` · `ADB_REVERSE_OK=True`가 보인 뒤 빌드가 시작되고, 폰에 닉네임 화면이 뜬다.
   - 기록 꺼내기: `EXPORT_OK=True` · `ROWS_ADULT1=`·`ROWS_ADULT2=`가 각각 5 이상(문제 5개 × 최소 1행) · `CSV1_ROWS`·`CSV2_ROWS`가 같은 수 · `NO_ID_COLUMNS=True`.
   - 실패 시 대처 1개: 어느 블록이든 `RUN_REFUSED=True`(또는 `EXPORT_REFUSED`·`COPY_REFUSED`·`CLEANUP_REFUSED`)가 보이면 그 블록은 아무것도 실행하지 않은 것이다. 함께 출력된 이유를 해결한 뒤 같은 블록 전체를 다시 붙여넣는다.
5. **실행 환경**

     - 성인 지인 2명. 실명·연락처는 어디에도 적지 않는다(공통 규칙 9). 시간은 한 사람당 약 20분.

## 관찰 규칙 (Kiki가 지킨다)

1. **조작 설명을 하지 않는다.** "이거 어떻게 해요?"라고 물으면 "편하게 해 보세요"라고만 하고, 그 질문을 메모장에 그대로 적는다. 막힌 채 3분이 지나면 그때만 한 문장으로 알려 주고, 알려 준 시각과 내용을 적는다.
2. **답을 알려 주지 않는다.** 튜터 말이 이상해도 끼어들지 않는다.
3. **한 문제가 끝날 때마다 메모장 그 줄을 채운다.** 소리 내어 말한 것은 들은 그대로 적는다.
4. **5문제가 끝나면 바로 질문 2개를 묻는다.** "어느 순간이 제일 답답했어요?" · "다시 할래요?" 답을 고치지 않고 적는다.
5. **세션 중 코드를 고치지 않는다**(지시서 "하지 말 것"). 앱이 이상해도 시각과 함께 메모만 한다.

막히면
- **앱이 5분 이상 멈추면** 그 사람의 세션을 끝내고 그 지점을 "가장 먼저 끊긴 지점"에 적는다. 그다음 두 번째 사람으로 넘어간다.
- **성인 2명을 못 구하면** 이 런북을 쓰지 말고 S12 세션에 알린다. 지시서대로 Kiki가 `self-2`로 S9 역할 규칙을 한 번 더 하는 블록을 세션이 따로 드린다(보고에 "본인 2회차"로 적는다).

- 커밋 한 줄은 관찰 기록 두 파일의 "서버 커밋" 칸에 옮겨 적는다.
- `DB_REUSED=True`면 이전 시연 컨테이너가 남아 있던 것이다. 그 안의 다른 닉네임(`self-1` 등)은 그대로 있지만, CSV는 `adult-1`·`adult-2`만 뽑으므로 섞이지 않는다.
- **이 창은 이후 조작 금지.** 정리 단계에서만 Ctrl+C를 누른다.

## 창 B — 1. 앱 실행 (포코 X3 NFC · USB 연결 · 사람마다 한 번씩)

폰은 S9와 같이 **USB 역방향 연결**(`adb reverse`)로 서버에 붙는다. 폰 준비는 S9 런북 "폰 준비"에서 이미 해 두었다. 케이블만 꽂고 화면 잠금을 푼 상태에서 붙여넣는다.

```powershell

cd C:\Users\kiki\Desktop\__AI\WhyMath-s12adult\src\mobile

$Health = try { (Invoke-WebRequest -UseBasicParsing -Method Post -ContentType 'application/json' -Body '{"nickname":"ping-s12"}' "$Base/golden/session").StatusCode } catch { "FAIL" }
Write-Host ("SERVER_REACHABLE=" + $Health)
$TailSid = try { (Invoke-RestMethod -Method Post -ContentType 'application/json' -Body '{"nickname":"ping-s12-tail"}' "$Base/golden/session").session_id } catch { $null }
$TailResp = try { Invoke-RestMethod -Method Post -ContentType 'application/json' -Body ([System.Text.Encoding]::UTF8.GetBytes((@{ session_id = $TailSid; problem_id = 'LF-05'; text = '8이요' } | ConvertTo-Json))) "$Base/golden/answer" } catch { $null }
$TailGraded = ($TailResp.kind -eq 'graded') -and ($TailResp.correct -eq $true)
```

자가검증
- 다음 줄이 보인 뒤 빌드가 시작된다. 폰에 "닉네임" 화면이 뜨면 성공이다.
  - `SERVER_REACHABLE=200`
  - `S10_TAIL_GRADED=True  (… 응답 kind=graded)`, `WRONG_TAIL_REJECTED=True  (… 응답 kind=tutor_turn)`
  - `NEXT_NICKNAME=adult-1  (adult-1 행 수=0 · adult-2 행 수=0)` — 두 번째 붙여넣기에서는 `NEXT_NICKNAME=adult-2  (adult-1 행 수=1 · adult-2 행 수=0)`
  - `ADB=C:\…\platform-tools\adb.exe`, `PHONE=…  (id=…)`, `ADB_REVERSE_OK=True`
- 앱이 뜨면 **Kiki가** 닉네임 칸에 `NEXT_NICKNAME`에 나온 글자를 그대로 넣고 시작한다. 위쪽에 "LF-01 · 1/30 · 숙련도 0.00"이 보이면 폰을 건넨다.
- `S10_TAIL_GRADED`·`WRONG_TAIL_REJECTED`는 **지금 떠 있는 서버**에 실제로 답을 보내 S10 항목 4(채점 말꼬리)가 동작하는지 본다. 틀린 답 검사는 실제 LLM 튜터를 1회 부른다(문제 본문과 `9이요`만 간다). 확인용 닉네임 `ping-s12*`는 `adult-` 접두가 아니라서 집계에 섞이지 않는다.
- 한글 본문은 UTF-8 바이트로 보낸다(Windows PowerShell 5.1이 문자열 본문을 다른 인코딩으로 보낼 수 있어서다 · 클라우드에서 실측 못 함 → 아래 "세션 AI가 미리 확인한 것").
- 첫 사람이 끝나면: 창 B에서 `q`를 눌러 앱을 끄고(폰 앱도 닫힌다), **이 블록 전체를 다시** 붙여넣는다. 두 번째 빌드는 1~3분이다.
- **풀이 도중 USB 케이블을 뽑지 않는다.** 뽑혔으면 S9 런북의 "USB 다시 잇기" 블록(새 창 C)을 그대로 쓴다. 끊긴 시각과 문제를 메모한다.

## 창 B — 2. 기록 꺼내기 (두 사람이 끝나고 앱을 `q`로 끈 뒤 · 창 A 서버는 켜진 채로)

- 다음 줄이 차례로 보인다.
  - `SQL_PRESENT=True`
  - psql이 낸 `COPY n` 두 줄, `ROWS_ADULT1=n`, `ROWS_ADULT2=n`(각각 5 이상)

  - `CSV1_ROWS=n  CSV2_ROWS=n` (위 ROWS와 같은 수)
  - `NO_ID_COLUMNS=True`
