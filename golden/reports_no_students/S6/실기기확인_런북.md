# S6 실기기 확인 런북 (Kiki 머신 · 1회 · 약 15분)

S6 세션(클라우드)에는 안드로이드 에뮬레이터·실기기가 없어, 같은 Dart 코드를 **Flutter 웹 빌드 + 헤드리스 크롬(휴대폰 크기)** 으로 실제 서버에 붙여 확인했다(캡처 2장이 이 폴더에 있다). 완료 기준 ①②의 "에뮬레이터/실기기" 확인만 이 런북으로 Kiki 머신에서 한 번 한다.

## 6항목 브리핑

1. **과제 명칭**: 골든 앱(S6 화면) 실기기 1회 확인
2. **목적**: 패드(안드로이드)에서 문제 본문이 수식 포함으로 보이고, "모르겠어요"를 보내면 튜터 되묻기가 같은 화면에 쌓이는지 본다. 결과는 S6 보고의 결과를 "일부 완료 → 완료"로 바꾸는 근거가 된다.
3. **구체적 절차**
   - 창 A: 골든 서버를 띄운다(가짜 LLM — 키 불필요, 튜터는 고정 문장 + 힌트를 돌려준다). 1~2분.
   - 창 B: 패드에 골든 앱을 설치·실행한다(`flutter run -t lib/main_golden.dart`). 첫 빌드 3~6분.
   - 패드에서 닉네임 `self-s6-check` 입력 → 시작 → 문제 1 화면 확인 → 입력창에 `모르겠어요` → 보내기 → 튜터 말풍선 확인 → 화면 캡처.
4. **성공 기준**: ①패드 화면 위쪽에 "일차함수 f(x) = −3x + 3에 대하여 f(5)를 구하시오." 가 수식 글꼴로 보인다 ②보내기 뒤 "튜터" 말풍선 1개가 학생 말풍선 아래에 생긴다 ③빨간 띠("서버에 연결할 수 없어요…")가 **없다**. 빨간 띠가 보이면 실패 — 창 A의 서버가 살아 있는지, 패드와 PC가 같은 Wi-Fi인지 먼저 본다.
5. **실행 환경**: Phaiakes9(이 PC)의 Windows PowerShell 2개 · 작업 디렉터리 `C:\Users\kiki\Desktop\__AI\WhyMath` · 선행 조건: S6 PR이 main에 머지됨 · Docker Desktop 실행 중(`whymath-pg` 5433) · 패드 USB 디버깅 연결 · 패드와 PC 같은 Wi-Fi.
6. **창 구분**: 창 A = **새 창, 서버 전용**(마지막 명령 실행 뒤 이 창은 건드리지 않는다. Ctrl+C는 복사가 아니라 서버 중단). 창 B = 새 창(Flutter 실행).

공유 작업 사본(여러 세션이 쓰는 클론)을 건드리지 않도록 **별도 워크트리**에서 실행한다. 확인이 끝나면 맨 아래 정리 블록으로 지운다.

## 창 A — 서버 전용 (새 창)

```powershell
# [창 A · 서버 전용] Windows PowerShell — 이 블록 실행 후 이 창은 조작 금지(Ctrl+C = 서버 중단)
cd C:\Users\kiki\Desktop\__AI\WhyMath
git fetch origin main
git worktree add --detach C:\Users\kiki\Desktop\__AI\WhyMath-s6check origin/main
cd C:\Users\kiki\Desktop\__AI\WhyMath-s6check
Write-Host ("S6_FILES_PRESENT=" + (Test-Path src\mobile\lib\main_golden.dart) + " / " + (Test-Path src\backend\golden\api.py))
docker start whymath-pg
$env:WHYMATH_DATABASE_URL = "postgresql+asyncpg://whymath@127.0.0.1:5433/whymath"
$env:GOLDEN_FAKE_LLM = "1"
cd src\backend
C:\Users\kiki\Desktop\__AI\WhyMath\src\backend\.venv\Scripts\python.exe -m uvicorn golden.api:app --host 0.0.0.0 --port 8000
```

자가검증: `S6_FILES_PRESENT=True / True` 가 보이고, 마지막에 `Uvicorn running on http://0.0.0.0:8000` 이 보이면 성공. `False`가 보이면 S6 PR이 아직 main에 없는 것이다 — 서버 줄까지 가지 말고 Ctrl+C 후 머지를 기다린다.

## 창 B — 앱 실행 (새 창)

```powershell
# [창 B · 앱] Windows PowerShell — LAN IP를 스스로 찾아 API_URL에 넣는다
cd C:\Users\kiki\Desktop\__AI\WhyMath-s6check\src\mobile
$cfg = Get-NetIPConfiguration | Where-Object { $_.IPv4DefaultGateway -and $_.NetAdapter.Status -eq 'Up' } | Select-Object -First 1
$LanIp = $cfg.IPv4Address.IPAddress | Select-Object -First 1
Write-Host ("LAN_IP=" + $LanIp)
$Health = try { (Invoke-WebRequest -UseBasicParsing -Method Post -ContentType 'application/json' -Body '{"nickname":"self-s6-ping"}' "http://${LanIp}:8000/golden/session").StatusCode } catch { "FAIL" }
Write-Host ("SERVER_REACHABLE=" + $Health)
if ($LanIp -and $Health -eq 200) { flutter pub get --enforce-lockfile; dart run build_runner build --delete-conflicting-outputs; flutter run -t lib/main_golden.dart --dart-define=API_URL=http://${LanIp}:8000 } else { Write-Host "RUN_REFUSED=True — LAN_IP가 비었거나 서버에 닿지 않음. 창 A의 Uvicorn running 줄과 Wi-Fi 연결을 확인" }
```

자가검증: `LAN_IP=` 뒤에 192.168.x.x 같은 주소, `SERVER_REACHABLE=200` 이 보인 뒤 빌드가 시작된다. `RUN_REFUSED=True`면 앱은 실행되지 않는다(위 이유를 먼저 해결).

패드에서 확인 후 캡처를 `golden/reports_no_students/S6/`에 `S6_capture_device.png`로 넣거나 세션에 올려 주면 보고의 결과를 "완료"로 바꾼다.
