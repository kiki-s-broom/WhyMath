## 창 A — 서버 전용 (새 창)

```powershell
# [창 A · 서버 전용] Windows PowerShell — 이 블록 실행 후 이 창은 조작 금지(Ctrl+C = 서버 중단)
cd C:\Users\kiki\Desktop\__AI\WhyMath
git fetch origin main
if (Test-Path C:\Users\kiki\Desktop\__AI\WhyMath-s8check) { git worktree remove --force C:\Users\kiki\Desktop\__AI\WhyMath-s8check }
git worktree add --detach C:\Users\kiki\Desktop\__AI\WhyMath-s8check origin/main
cd C:\Users\kiki\Desktop\__AI\WhyMath-s8check
git log -1 --oneline
git merge-base --is-ancestor f4894ef3 HEAD; $CodeBaseOk = ($LASTEXITCODE -eq 0)
Write-Host ("CODE_BASE_OK=" + $CodeBaseOk + "  (기대: S7 머지 f4894ef3 포함)")
$Port8000Free = -not (Get-NetTCPConnection -LocalPort 8000 -State Listen -ErrorAction SilentlyContinue)
Write-Host ("PORT_8000_FREE=" + $Port8000Free)
docker compose -f docker-compose.demo.yml up -d
$DbReady = $false; foreach ($i in 1..30) { docker compose -f docker-compose.demo.yml exec -T demo-db pg_isready -U whymath -d whymath *> $null; if ($LASTEXITCODE -eq 0) { $DbReady = $true; break }; Start-Sleep -Seconds 2 }
Write-Host ("DB_READY=" + $DbReady)
$env:WHYMATH_DATABASE_URL = "postgresql+asyncpg://whymath@127.0.0.1:55432/whymath?ssl=disable"
if ([string]::IsNullOrEmpty($env:WHYMATH_OPENROUTER_API_KEY)) { $env:GOLDEN_FAKE_LLM = "1"; Write-Host "LLM_MODE=fake" } else { Remove-Item Env:GOLDEN_FAKE_LLM -ErrorAction SilentlyContinue; Write-Host "LLM_MODE=live" }
cd src\backend
if ($CodeBaseOk -and $Port8000Free -and $DbReady) { C:\Users\kiki\Desktop\__AI\WhyMath\src\backend\.venv\Scripts\python.exe -m uvicorn golden.api:app --host 0.0.0.0 --port 8000 } else { Write-Host "RUN_REFUSED=True — CODE_BASE_OK가 False면 main에 S7이 없는 것, PORT_8000_FREE가 False면 다른 서버(좀비 uvicorn)가 8000을 쓰는 것(작업 관리자에서 python 종료), DB_READY가 False면 Docker Desktop을 켜고 다시" }
```

자가검증
- 성공: `CODE_BASE_OK=True`, `PORT_8000_FREE=True`, `DB_READY=True`, `LLM_MODE=…`가 차례로 보이고 마지막 줄이 `Uvicorn running on http://0.0.0.0:8000`이다.
- `RUN_REFUSED=True`면 서버는 뜨지 않는다. 출력된 이유를 해결한 뒤 이 블록 전체를 다시 붙여넣는다(워크트리는 블록이 지우고 다시 만든다).
- **이 창은 이후 조작 금지.** ⑪ 단계에서만 Ctrl+C를 한 번 누르고, 그 뒤 "서버 다시 켜기" 블록을 이 창에 붙여넣는다.

## 창 B — 앱 실행 (새 창 · 패드 USB 연결 뒤)

```powershell
# [창 B · 앱] Windows PowerShell — LAN IP를 스스로 찾아 API_URL에 넣는다(실기기는 localhost가 기기 자신이라 실패)
cd C:\Users\kiki\Desktop\__AI\WhyMath-s8check\src\mobile
$LanIp = (Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -like "192.168.*"}).IPAddress | Select-Object -First 1
Write-Host ("LAN_IP=" + $LanIp)
$Health = try { (Invoke-WebRequest -UseBasicParsing -Method Post -ContentType 'application/json' -Body '{"nickname":"self-s8-ping"}' "http://${LanIp}:8000/golden/session").StatusCode } catch { "FAIL" }
Write-Host ("SERVER_REACHABLE=" + $Health)
$Device = (flutter devices) | Select-String -Pattern "android" -CaseSensitive:$false
Write-Host ("DEVICE_READY=" + [bool]$Device)
if ($LanIp -and ($Health -eq 200) -and $Device) { flutter pub get --enforce-lockfile; dart run build_runner build --delete-conflicting-outputs; flutter run -t lib/main_golden.dart --dart-define=API_URL=http://${LanIp}:8000 } else { Write-Host "RUN_REFUSED=True — LAN_IP가 비었으면 Wi-Fi 연결을, SERVER_REACHABLE이 200이 아니면 창 A의 Uvicorn running 줄을, DEVICE_READY가 False면 패드의 USB 디버깅 허용 팝업을 확인한 뒤 이 블록을 다시 붙여넣기" }
```

자가검증
- `LAN_IP=192.168.x.x`, `SERVER_REACHABLE=200`, `DEVICE_READY=True`가 보인 뒤 빌드가 시작된다. 패드에 "닉네임" 화면이 뜨면 성공.
- `RUN_REFUSED=True`면 앱은 실행되지 않는다. 출력된 이유를 먼저 해결한다.
- 기기가 둘 이상 잡히면 flutter가 고르라고 묻는다 — 패드를 고른다.
