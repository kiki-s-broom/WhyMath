## 앱 확인 12항목 (제안 — S5 작성 · S8이 Flutter 앱으로 확인)

서버 쪽 경로(GP-1~GP-6)는 `tests/golden` e2e가 확인한다. 아래는 사람이 앱 화면에서 직접 보는 목록이다. 칸은 S8이 채운다.

| 번호 | 확인할 것 | 통과 기준 | 결과 | 세션 |
| --- | --- | --- | --- | --- |
| ① | 닉네임 입력 후 세션 생성 | 닉네임을 넣고 시작을 누르면 문제 화면으로 넘어간다 | | |
| ② | 첫 문제 LaTeX 렌더 | `$...$` 구간이 수식으로 보인다(달러 기호가 그대로 보이면 실패) | | |
| ③ | "모르겠어요" → 되묻기 표시 | 입력창에 "모르겠어요"를 보내면 튜터 말풍선이 하나 생긴다 | | |
| ④ | 되묻기가 정답을 말하지 않음 | 튜터 말풍선에 그 문제의 정답 문자열이 없다 | | |
| ⑤ | 3턴 뒤 강제 판정 | 같은 문제에 오답 4번째에서 "판정: 틀림"과 정답 안내 한 줄이 나온다 | | |
| ⑥ | 정답 입력 → 맞음 표시 | 정답을 보내면 "맞음" 판정이 나온다 | | |
| ⑦ | 숙련도 숫자 증가 | 맞음 판정 뒤 숙련도가 0.10 오른다 | | |
| ⑧ | 오답 → 숙련도 감소(0 아래로 안 내려감) | 틀림 판정 뒤 0.05 내려가고, 0.00에서는 0.00 그대로다 | | |
| ⑨ | 다음 문제 버튼 → 다른 문제 | 판정 뒤 다음 문제의 번호(LF-xx)가 바뀐다 | | |
| ⑩ | 앱 재시작 후 같은 닉네임 → 숙련도 유지 | 앱을 껐다 켜고 같은 닉네임으로 들어가면 숙련도가 그대로다 | | |
| ⑪ | 서버 꺼진 상태 → 오류 문구(앱이 죽지 않음) | 서버를 끄고 보내면 "서버에 연결할 수 없어요…" 한 줄이 보이고 앱은 계속 켜져 있다 | | |
| ⑫ | 문제 3개 연속 완료 | 문제 3개를 판정까지 연달아 끝낼 수 있다 | | |
