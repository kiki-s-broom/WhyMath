# WhyMath 5단계 2027 봄 공개 AI 작업 지시문

계획서: `plan_phase5_launch_8weeks.docx` (2026-11-15 Kiki 계획서 원본 · Kiki 보관 원본(저장소 미포함 — office·PDF 문서는 `.gitignore`와 `scripts/ops/check_source_document_binaries.py`가 커밋을 막는다 · 저장소 안 정본은 지시서)) · 지시서 원본 `golden/prompts_src/spec_phase5.md` · 선행 묶음 `golden/prompts/`(S1~S15)·`golden/prompts_phase1/`(S16~S35)·`golden/prompts_phase2/`(S36~S55)·`golden/prompts_phase3/`(S56~S75)·`golden/prompts_phase4/`(S76~S105)

작업 하나에 파일 하나다. **파일 이름이 곧 세션 이름**이다. 각 파일은 그것만 붙여 넣어도 AI가 작업할 수 있도록 배경, 실행 방식, 공통 규칙, 용어, 작업 지시, 보고 형식을 모두 담고 있다.

## 사용법

1. 실행할 단계 폴더를 연다(단계01부터).
2. 폴더 안의 파일마다 새 세션을 하나씩 연다. 세션 이름은 파일 이름 그대로다(예: `LA-단계07-S125-심사제출-5월28일`) — 파일을 붙여 넣으면 AI가 첫 행위로 제목을 그 이름으로 바꾸고(클라우드: `set_session_title`), 저장소 훅이 `golden/SESSIONS.md`에 자동 기록한다. 터미널 Claude Code에서는 AI가 안내하는 `/rename` 한 줄만 쳐 주면 된다.
3. 파일 맨 위 "작업 환경"이 맞는지 보고(저장소 위치는 미리 채워져 있다), 파일 전체를 붙여 넣는다.
4. 그 단계의 모든 세션이 `golden/reports_phase5/<작업번호>/보고.md`를 남기면 다음 단계로 넘어간다.

- **폴더 이름이 "병렬"이면** 그 안의 세션들을 동시에 돌려도 된다.
- **폴더 이름이 "순차"이면** 그 작업 하나만 실행하고, 끝난 뒤 다음 단계로 간다.
- 단계 번호는 "가장 빨리 시작할 수 있는 순서"다. 정확한 조건은 선행 작업이므로, 선행 작업만 끝났으면 다음 단계 작업을 먼저 시작해도 된다.

**시작 조건이 있다.** 4단계 S105 게이트 첫 줄(4주 리텐션 40%)이 "예"여야 S106을 연다. S106 첫 단계가 4단계 산출물을 실측해 없는 것이 있으면 멈춘다.
